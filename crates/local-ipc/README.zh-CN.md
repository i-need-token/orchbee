# 私有本地 IPC

为原生 Client、Server 和 Worker 提供 Windows 字节流传输。本模块把本地命名管道
适配为有界读写、取消和就绪观察，不改变 OBLC、OBWP、OBAP、OBCS、OBCN 或
Terminal Host 帧格式。不启动进程、不选择运行目录、不拥有协议状态，也不授予终端权限。

## Windows 传输细化

用户授权的 Windows 原生交付保留现有进程和协议所有者。双方在交换协议字节前验证
对端进程令牌的用户身份。监听器拒绝远程连接，使用受保护的当前用户 DACL，且禁止
句柄继承。知道名称不构成授权。现有 Terminal Host 保留独立拥有的端点命名与对端验证。

| 字段     | 契约                                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 输入     | 已验证的本地管道名称、当前令牌用户、非阻塞管道结果、可选单调截止时间、显式关闭                                                     |
| 状态     | 一个共享连接所有者、最多一个预读字节、关闭标志、调用者选择的读写超时                                                               |
| 输出     | 精确有序字节、暂不可用、EOF、超时或类型化系统错误；不重试协议                                                                      |
| 所有权   | 克隆共享同一连接；关闭终止全部克隆的传输并唤醒有界轮询；最后一次释放关闭句柄                                                       |
| 不变量   | 预读恰好消费一次；无阻塞管道 I/O 或 flush；无脱离所有者的 I/O 线程；身份验证前无应用字节                                           |
| 转移     | 连接/接收 → 身份证明 → 非阻塞准入；就绪观察可保留一个字节；读取先消费保留字节；关闭/最后释放 → 已关闭                              |
| 截止时间 | 超时限制每次传输调用；协议所有者继续跨调用持有原有的整个操作绝对截止时间                                                           |
| 依赖     | `interprocess` 提供安全命名管道绑定，`winsafe` 提供安全进程令牌查询，`widestring` 提供描述符 UTF-16 编码；仅 Windows，无异步运行时 |
| 证据     | 原生双进程往返、首实例/名称拒绝、就绪预读后的精确字节顺序、满缓冲超时、关闭和句柄释放                                              |

就绪仅为提示：可写通知允许一次有界非阻塞尝试，不保证整个记录放得下。
管道写入不构成协议 ACK。关闭会放弃未确认字节，不启动 flush 线程；各协议所有者
必须保留现有的结果未知行为。内核调度不在单调预算的实时保证内。现有本地提交与
中继模型继续负责请求身份、至多一次提交和反馈语义。

直接实现的挑战检查了管道抢占、远程客户端、句柄继承、不完整记录、预读重复、
写入阻塞和克隆取消。这是显式对抗性阅读，不是独立评审。原生证据通过后，才能
声明此传输已交付。
