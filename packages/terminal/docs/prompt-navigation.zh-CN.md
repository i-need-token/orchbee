# 提示符导航

## 范围

在主屏幕上，上一个／下一个导航从当前可见顶部跳到请求方向上最近的严格 `PROMPT_START` 行。默认键为 `Ctrl+Shift+Z` 和 `Ctrl+Shift+X`。不包含持久提示符记忆、可配置提示符数量、滚动偏移、像素滚动、输出分页器、自动注入 Shell Integration 或备用屏幕导航。

## 领域契约

使用 OSC 133 Shell Integration 的终端用户需要在先前命令边界之间移动，而无需手动搜索或翻页。
`ProjectedTerminal` 拥有这个本地历史导航工作流。Terminal Host 继续权威拥有保留行、生成和修订，
以及从 OSC 133 得出的行 `promptClass`；浏览器永远不会重新解析转义序列，也不会从文本推断提示符。

操作消费：

- `previous` 或 `next` 方向；
- 主屏幕当前绝对可见起始行，作为排他锚点；或者在该物理视口修订追赶期间，采用同一意图的临时请求
  可见起始锚点；
- 一个生成/修订/总行数快照；
- 当前本地历史意图时期；
- 一个中止信号和现有通用缓冲区行读取能力。

它返回 `target`、`cancelled` 或一个有意的 `unchanged` 原因。只有当屏幕仍为主屏幕，固定的生成、
修订与总行数仍为当前值，本地历史意图时期仍匹配，且选中的锚点权威未改变时，才会提交目标。可见
锚点要求可见 Host 快照与当前 Host 快照准确匹配。临时锚点要求本地意图时期、生成、总行数和当前
视口边界一致；每次调用仍扫描最新 Host 修订。该临时值仅用于修复修订滞后，且永远不会取代当前
物理视口，因此并未实现 持久记忆上次提示符状态。提交请求现有保留历史视口所有者显露目标行；
它不会修改 Host 历史或提示符语义。

## 决策与不变量

| 决策     | 上一个                                       | 下一个                                       |
| -------- | -------------------------------------------- | -------------------------------------------- |
| 搜索域   | 严格小于可见起始锚点的行                     | 严格大于可见起始锚点的行                     |
| 顺序     | 最新页优先，行降序                           | 最旧页优先，行升序                           |
| 合格行   | `promptClass === prompt`                     | `promptClass === prompt`                     |
| 目标     | 遇到的第一个合格行                           | 遇到的第一个合格行                           |
| 视口结果 | 目标成为请求的可见顶部，并受现有底部边界约束 | 目标成为请求的可见顶部，并受现有底部边界约束 |

工作流保持这些不变量：

- 提示符续行和未标记行永远不会成为导航目标；
- 备用屏幕、空域、边界、无匹配、来源上限、不可用、格式错误、过时和已取消情况不会改变视口；
- 一次扫描最多有一个通用缓冲区行请求在途，且永远不会占用独立的视口或搜索通道；
- 每页固定生成/修订、连续，并受协议行、单元格和字节上限约束；
- 完整扫描最多接纳 16 MiB 编码行窗口来源，每个请求都受剩余预算约束；
- 替换、另一个历史意图、处置或扫描期间更新的 Host 快照会撤销提交权威；
- 成功扫描最多发布一个视口意图，且永远不会提交来自旧调用的目标。

确定性定位器每页最多请求 1,024 行，并进一步受当前列数和协议单元格上限约束。`too-large` 页面会以
一半行数重试，同时保持最近优先顺序。若单行无法放入剩余来源预算，则以 `source-limit` 结束；操作
永远不会跳过未经检查的间隙。

## Action 与快捷键

Workbench 拥有语义 Action `terminal.history.prompt-previous` 和
`terminal.history.prompt-next`。Web 使用替换最新的历史导航执行方式注册它们，并暴露终端聚焦快捷键。
Apple 与标准平台的默认值都是 `Ctrl+Shift+Z` 和 `Ctrl+Shift+X`，不会
把 Apple `Mod` 映射为 Command。只有当 Action 在已聚焦主屏幕终端可用时才会消费绑定。短暂的视口
flight 或 Host 历史刷新期间，如果物理锚点快照准确，则调用使用当前物理锚点。如果只有物理修订
滞后，而生成、总行数、视口边界与历史意图时期仍匹配，则可从同一意图的临时锚点重新扫描最新
修订。否则调用会作为不播报的无操作完成。产品组合键绝不会泄漏到 PTY；找不到目标的执行同样保持
不变且静默。

新增两个快捷键 ID 会扩展 Web 的严格持久键盘目录。版本 6 会把准确有效的 v5 记录迁移到扩展目录，
移除等于当前默认值的覆盖，拒绝迁移冲突，并保留 v5 作为回滚快照。无效当前记录不会回退到更旧版本。

## 工作流与取消

| 状态     | 事件                                               | 守卫                                                         | 结果                                           |
| -------- | -------------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------- |
| 就绪     | 调用                                               | 主屏幕、存在可读非空域，且有当前可见锚点或同一意图的临时锚点 | 捕获快照、锚点权威与历史意图时期；请求最近页面 |
| 读取中   | 页面包含提示符                                     | 页面与捕获权威仍为当前                                       | 返回最近的严格目标                             |
| 读取中   | 页面不含提示符                                     | 仍有搜索域和来源预算                                         | 无重叠、无间隙地向外推进                       |
| 读取中   | 页面过大                                           | 请求了多于一行                                               | 在保持同一最近边界的情况下把页面减半           |
| 读取中   | 中止、过时来源、格式错误页面、通道不可用或预算耗尽 | 任意                                                         | 返回已取消或不变，不产生视口意图               |
| 目标就绪 | 提交                                               | 快照、选中的锚点权威、时期与主屏幕仍为当前                   | 正好发布一个即时视口意图                       |
| 目标就绪 | 替换或权威变化                                     | 提交守卫失败                                                 | 返回已取消或不变，不发生变更                   |

通用缓冲区通道现有的中止监听器会结算被替换的读取。Action 取消只作为已取消 Action 结果可观察；
边界与不可用结果保持静默，因此键盘导航尝试不会产生状态噪音。
