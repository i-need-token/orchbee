# 统一搜索

## 权威与范围

该参考负责维护 Workbench 搜索交互模型、提供者协调、结果投影和正确性声明。`@orchbee/actions` 负责注册、已准备调用、执行、确认、并发，以及调用后的取消。搜索提供者及其语义数据仍归各功能所有者；应用组合负责选择提供者与平台适配器。

当前的实现包括有界同步和异步提供者协调、本地操作和设置投影、确定性排名、嵌套操作输入、重试、故障隔离、可访问性行为和陈旧完成拒绝。当前没有组成代理拥有的或活动的终端实例提供程序。

文件搜索、持久查询或操作历史记录、用户定义的键绑定、操作链接、不透明排名、包含查询或结果数据的遥测以及工作台拥有的代理或终端运行时状态均被排除。

## 领域契约

| 领域           | 合同                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------- |
| 问题           | 当独立拥有的提供者加载、失败、重试和更改顺序时，人们必须通过一个表面发现和调用功能。         |
| 可信输入       | 审查了开放过滤器、安装的操作范围、注册的提供程序、验证的提供程序结果、区域设置和快捷方式平台 |
| 不受信任的输入 | 查询文本和指针或键盘事件；查询文本保留在已安装的内存中并且永远不会执行                       |
| 输出           | 确定性分组的可见结果、加载或失败投影、语义公告，以及至多一个已准备的 Action 调用             |
| 无操作         | 陈旧完成、关闭后完成、不可用结果、重复当前选择以及调用前取消                                 |
| 副作用         | 提供者请求获取和取消、选择后的操作调用、焦点移动、滚动和可访问性公告                         |

## 所有权

| 可变事实                           | 唯一所有者                          |
| ---------------------------------- | ----------------------------------- |
| 打开会话、过滤器、查询修订和选择器 | 工作台搜索交互状态                  |
| 提供者请求身份、阶段和结果集       | 工作台提供者-协调状态               |
| 提供者数据和导航含义               | 贡献的功能                          |
| 行动的可用性和执行                 | 已安装 `ActionRuntime` 和语义所有者 |
| 代理会话、编写器和提交生命周期     | 代理能力拥有者                      |
| 终端实例和进程生命周期             | 应用构成及终端能力                  |
| DOM 焦点、测量滚动和实时公告       | 窄工作台 React 适配器               |

提供者返回值和运行时拥有的调用令牌。他们从不接收工作台状态编写器，也从不提供任意执行回调。

## 规范数据

提供者有一个稳定的 ID，声明它支持的过滤器，公开有界的默认和查询操作，并可选择在其拥有的读取模型发生更改时通知协调器。每个结果都具有稳定的提供者本地身份、准备好的演示、显式分组元数据、可搜索术语、可用性以及准备好的或未绑定的操作调用。

协调器根据 Provider ID 与 Provider 本地结果 ID 分配仓库范围的结果标识。Provider 完成顺序不参与排名。查询匹配度、推荐状态、会话新近度、Provider 优先级、Group 顺序及稳定标识共同构成完整确定性比较；数字优先级较小的 Provider 排在前面。

一位提供商的运行记录：

- 提供商 ID；
- 开放会话 ID；
- 查询修订；
- 重试尝试；
- `loading`、`ready` 或 `failed` 相；
- 准备好后有界结果部分；和
- 发生故障时稳定的内部故障代码。

原始例外永远不会进入产品演示。

## 转换

| 活动             | 守卫                         | 结果                                                             |
| ---------------- | ---------------------------- | ---------------------------------------------------------------- |
| 打开             | 任何州                       | 创建新会话，重置查询和提供商投影，并请求适用的提供商             |
| 查询已更改       | 查询值不同                   | 增加修订、取消先前运行、清除其投影，并请求当前提供者             |
| 过滤器已更改     | 浏览和过滤不同               | 保留查询、增加修订、取消先前运行并请求适用的提供程序             |
| 提供商已启动     | 会话和修订是最新的           | 记录该提供商的一次加载运行                                       |
| 提供者已完成     | 会话、修订、提供者和尝试匹配 | 仅用有界就绪结果替换该提供者投影                                 |
| 提供商失败       | 会话、修订、提供者和尝试匹配 | 仅将该提供者投影替换为稳定的失败状态                             |
| 重试提供商       | 当前运行失败                 | 仅增加提供者尝试并开始替换运行                                   |
| 提供商模型已更改 | 提供商仍然适用               | 仅替换该提供程序运行；其他提供商和当前亮点保持稳定               |
| 启动参数选择器   | 当前结果携带支持的未绑定输入 | 保留浏览快照并进入嵌套选择器                                     |
| 返回             | 选择一个论点                 | 恢复过滤器、查询、修订、突出显示、提供者投影和测量滚动           |
| 关闭或卸载       | 表面是开放的                 | 取消提供程序工作，清除已安装的投影，恢复语义焦点，不调用任何内容 |

`AbortController` 是处置协助，而不是正确性权威。每次完成都会根据会话、修订、提供程序 ID 和尝试进行检查，即使其提供程序忽略取消也是如此。

## 不变量

- 每个可见的异步结果都属于当前打开的会话和查询修订。
- 一个提供者和尝试最多存在一次当前运行。
- 陈旧的、取消的、失败的或关闭后的完成永远不会改变可见的结果。
- 提供者完成顺序不会改变最终分组结果顺序。
- 突出显示的结果不存在或在当前可见结果集中解析。
- 一个提供者的失败不会删除或禁用另一提供者的结果。
- 重试一个提供程序既不会重新启动也不会清除不相关的就绪提供程序。
- 一个接受的结果最多达到一个准备好的 Action 执行。
- 关闭、提供程序取消、选择器取消、突出显示、悬停和预取不会调用任何产品操作。

## 正确性证据

| 声明                           | 所有者切片 | TLA+ 属性                              | 确定性证据                           | 边界与排除项                   |
| ------------------------------ | ---------- | -------------------------------------- | ------------------------------------ | ------------------------------ |
| 陈旧的完成被排除在外           | 过渡       | `VisibleResultsAreCurrent`             | 重新排序完成并重新打开回归           | 有界提供者、会话、修订和尝试   |
| 关闭会清除提供者投影           | 转换       | `ClosedHasNoVisibleProviderResults`    | 关闭、卸载、忽略取消和迟到完成测试   | 不涵盖提供者正确性和网络可用性 |
| 当前亮点仍然有效               | 不变量     | `HighlightIsVisibleOrNone`             | 有状态交互属性测试                   | DOM 焦点单独检查               |
| 当前 Provider run 标识保持新鲜 | 转换       | `ProviderProjectionIsCurrent`          | 直接替换与陈旧完成测试               | 不对结果内容与顺序建模         |
| 完成顺序与观察无关             | 规范数据   | 不适用：不对结果内容/顺序建模          | 排列的提供者完成属性测试             | 排名输入保持相等               |
| 重试是提供商本地的             | 过渡       | `RetryDoesNotInvalidateOtherProviders` | 失败组重试时间线测试                 | 排除超出显式用户重试的重试策略 |
| 选择最多调用一次               | 不变量     | N/A：Action Runtime 拥有执行权         | 准备调用集成测试                     | 排除动作域结果的正确性         |
| 焦点在较晚完成时仍然存在       | 所有权     | 不适用：DOM 集成                       | 具有语义焦点检查点的确定性浏览器跟踪 | 支持的桌面浏览器环境           |

TLA+ 合并配置探索两个 Provider、两个打开会话、从已打开会话直接替换以及关闭后重新打开、有界
revision、attempt `0` 加至多一次 Provider 替换（`MaxAttempt = 1`）、取消、失败、重试与乱序完成。
受维护的 attempt-2 reducer 用例仍是确定性细化证据，不属于该 merge 边界。进展假设当前未取消的
Provider run 最终落定；它不声明网络可用性。

## 维护

- 每当提供者生命周期语义发生变化时，保持提供者状态转换、协调器、React 适配器、TLA+ 模型和确定性回归保持一致。
- 在更改实现之前，将最短模型反例转换为确定性回归。
- 通过公共提供者和 Action Runtime 合约组成提供者；不要为提供者提供工作台状态编写器或任意执行回调。
- 仅在其语义所有者公开接受的读取模型和操作契约后，才承认代理拥有或终端实例结果。
