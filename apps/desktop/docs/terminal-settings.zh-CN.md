# Desktop 终端设置

## 归属与作用域

Desktop 与 TUI 使用同一设备偏好权威。完整清单、默认值、校验、重置语义与生效时机属于
[共享契约](../../../crates/workbench-protocol/docs/user-preferences.zh-CN.md)。
渲染端负责草稿与展示；Main 负责能力准入和 Host 发布；匹配的
`orchbee-settings` 辅助程序调用 Native Site 的 `UserPreferencesStore`。

作用域遵循冻结的原生配置身份，包括显式 `ORCHBEE_CONFIG_FILE`，
独立于 Electron `userData`、Workspace 和远端终端。
旧 `terminal-default-settings-v1.json` 与启动配置文件只作为一次性迁移输入。

## 启动与恢复

Main 在每次受限隐藏进程交换前校验辅助程序的精确文件名及 SHA-256 清单。
请求不包含路径或任意进程命令。
Main 只向未声明的键导入有效旧启动配置与滚动历史；渲染端单独导入十一项通用字段。
无效旧来源保持可见且不被修改。显式编辑和重置保护字段不被延迟导入覆盖。

Main 在终端运行时初始化前读取确认偏好，并向 Host 应用滚动历史默认值。
每秒轮询观察 TUI 及其他 Desktop 写入者。共享存储无效或不可读时拒绝读取，
保留最后确认的运行值并显示问题。不会自动覆盖、回滚或重放写入。

## 更新事务

草稿在首次编辑时冻结来源。比较并设置补丁在共享操作系统锁下提交，提交前再次比较来源。
只有确认持久化的快照才发布通用值。未修改字段保持不变；null 恢复默认值并声明该键。

| 结果                     | 持久值 | 应用行为                       |
| ------------------------ | ------ | ------------------------------ |
| 候选无效或来源过期       | 不变   | 保留草稿并显示拒绝             |
| 提交前拒绝写入           | 不变   | 保留先前确认快照               |
| 回执丢失或持久性不确定   | 未知   | 重新读取；绝不重放             |
| 保存确认但 Host 应用失败 | 新值   | 显示应用问题；重试应用确认快照 |
| 保存及应用均确认         | 新值   | 发布完整确认值                 |

控制器串行处理轮询与修改。Host 应用可以重试，持久写入绝不隐式重试。
重新打开读取当前权威。无草稿控件跟随外部修改；脏草稿保留冻结来源并报告冲突。

Main 向本次观察捕获的回调发布，每个回调至多执行一次，并跳过轮到执行前已移除的回调。
观察者异常不能使原生交换失败。释放时先清空订阅并关闭订阅准入，再等待活动中的 Host 应用；
迟到的完成可以结算已准入的回执，但不能恢复观察者或轮询。
[控制器测试](../src/main/user-preferences/__tests__/DesktopUserPreferencesController.unit.test.ts)
覆盖回调重新注册、移除及应用期间释放。

## 终端生命周期

滚动历史接受 `0` 到 `1_000_000_000` 的整数字节，默认 `10_000_000`。
Main 使用 `SetTerminalDefaults`，新 Host 终端捕获该值。
它不发送 `UpdateTerminalConfiguration`、驱逐已有行或重建运行中终端。
Native Worker 从同一确认快照捕获滚动历史与选定启动配置。
恢复的 Desktop 绑定保留具体启动信息与已有 Host 配置。

## 渲染端能力

十一个端口的引导束以剪贴板读取和共享用户偏好结尾；终端默认值保留狭窄兼容端口。
共享端口传输有界关联请求、确认快照与应用问题，不提供文件系统或 Host 访问。
畸形数据或转移端口会终止能力。文档替换释放 broker 与监听器，Main 控制器继续存活。
Browser Preview 保持独立 origin 存储，省略不可用的原生启动与滚动历史控件。

## 验证

控制器、broker、preload、渲染端和生命周期测试覆盖准入、冲突、释放、迁移、失败保留及新终端捕获。
运行时与真实辅助进程测试覆盖竞争写入和共享存储。
模型及负向对照见[原生契约](../../orchbee/docs/native-settings.zh-CN.md#正确性与证据)。
执行受影响根门禁。原生进程证据仅适用于实际运行的宿主。
