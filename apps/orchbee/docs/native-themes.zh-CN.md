# 原生主题

## 选择与归属

[共享设备偏好](../../../crates/workbench-protocol/docs/user-preferences.zh-CN.md)将应用外观
（浅色、深色、系统）与终端默认色（Host、浅色、深色、自定义）分开。
应用浅色是通用默认值。系统将 TUI chrome 映射到外层终端语义默认色；
TUI 不修改外层宿主字体或外观。

终端 Host 使用捕获帧／窗口的前景与背景。浅色／深色使用共享内置默认值；
自定义使用校验过的 RGB 对。只有带默认标记的单元格被替换。
显式程序 RGB、调色板颜色、OSC 覆盖、反色、属性及宽字符几何在实时和保留行中保持捕获权威。
光标与空白画布使用同一选定终端默认色。本展示不改变保留 Host 的颜色查询响应。

旧 Windows TOML 接受 terminal-native、one-light 和 one-dark。
它们是迁移输入：显式旧值只为未声明共享偏好提供一次初值。
后续 TOML 重载不能覆盖确认的通用外观。
内置主题角色仍映射 chrome、侧栏、菜单、提示及选区覆盖层；
渲染器消费这些角色，不改变焦点、几何或控制。

浅色／深色角色区分画布、chrome 与浮层。系统使用外层宿主默认值；
量化可能合并表面差异，但边框、标签和焦点仍保留。
浮层边框共享主题角及焦点角色；标题独立使用主要粗体文字。

侧栏的持久上下文使用 `surface-current`，与选择器的选区颜色区分。原生主题将 ANSI 灰色背景
与黑色正文配对，随宿主变化的文字不使用 DIM；两个命名主题采用相对 chrome 低对比的
中性填充，并保留主要／次要文字颜色。该填充比键盘选区更克制，同时保留文字的可读对比度。
当前名称加粗；状态字形与显式 token 颜色保留语义。量化使填充与 chrome 重合时，
边栏保留 `*`，即使配置的文字关闭粗体也如此。键盘导航在非当前身份行使用
`surface-selection` 和配套文字，保留独立边栏标记。两种状态重合时，当前上下文仍使用中性填充。
显式 token 颜色和修饰在焦点样式之后应用。这不推断宿主明暗，也不修改终端调色板。

## 色彩能力

Shell 在绘制前采样一次色彩环境输入。纯解析器依次采用：非空 `NO_COLOR`、
`FORCE_COLOR`、`COLORTERM`、`TERM`。`NO_COLOR` 和 `FORCE_COLOR=0` 关闭界面颜色。
Force 值 `1`、`2`、`3` 分别选择 16 色、256 色和真彩色。非法 force 值为未知，
采用 16 色。`COLORTERM=truecolor` 或 `24bit` 选择真彩色；包含 `256color` 的 TERM
选择 256 色，`TERM=dumb` 关闭颜色。
当 `COLORTERM` 和 `TERM` 缺失或为空时，符合普通 GUID 格式的 `WT_SESSION`
标识 Windows Terminal 并选择真彩色。存在 `TMUX`、`ZELLIJ` 或 `STY` 时，
不采用这个外层宿主回退。显式描述符（包括未知值）保留原有决定；格式错误的会话
标识仍视为未知并采用 16 色。不记录变量值。这是色彩能力决定，不推断终端明暗。

Windows Terminal 在拉起连接时设置[普通会话 GUID](https://github.com/microsoft/terminal/blob/main/src/cascadia/TerminalConnection/ConptyConnection.cpp)。
没有该标识的宿主仍采用保守回退；不增加终端查询或逐帧环境读取。

接纳主题时在渲染之外完成主题角色量化，使用现有规范 xterm 调色板和感知距离。
16 色下，文字角色排除亮黑，并通过修饰保留次要／禁用层级。无色模式保留文字、
字形和修饰。Host 调色板可能不同；这不构成物理对比度测量或终端明暗协商。
命名 RGB 主题在真彩色和 256 色下仅以已有的柔和前景色显示禁用文字，不额外叠加 DIM。
弱化强度可能把 RGB 前景色变暗，让浅色表面上的禁用文字看起来接近主要文字。
16 色和无色模式下，柔和前景色与主要前景色重合时，量化仍保留 DIM；
`terminal-native` 继续采用随宿主调色板变化的 DIM。
低色级下，宿主可能把 DIM 黑色画得与普通黑色一样。即使禁用修饰已保留，
仍必须显示不可用原因。

## 发布与重载

有序设置通道在启动时读取共享权威，并每秒轮询。只有完整确认快照更新缓存偏好与主题角色。来源无效或回执丢失时保留最后确认值并显示问题。GUI 编辑和 TUI 保存走同一路径，无需重启终端。渲染器只读缓存值，不读取文件或环境。旧配置重载继续负责无关字段，不能替换确认的通用偏好。
