# 原生 Windows Panel 图形渲染

## 目标与归属

原生 TUI 消费已有 Session 拥有的 Panel/Presentation 图层。图形查询使用现有可取消读取通道的独立实例，不借用 UI 的终端/控制连接、不发送 PTY 输入、不改变焦点。主 UI 拥有可见目标选择、缓存发布、裁剪和成功绘制回执。现有 Client 控制发布者在已认证连接上拥有能力/绘制观察。

只有成功 shell 绘制中包含的表面进入读取范围。准确记录所选主/子项身份及可空终端绑定；删除、重新绑定、隐藏或切换后立即退出范围。Session 身份对重连和冷恢复提供栅栏。稳定标签和保持身份的移动不使像素资源失效。读取前、完整资源读取后和 UI 发布时均核对来源归属。每次有界批次最多查询 64 个表面，在已有 4096-Panel 上下文界限内轮转。

## 完整资源与界限

目录元数据与不可变图层缓存比较。准确资源版本不变时共享已有像素，不复制图像字节。新 RGBA 资源每块最多 256 KiB，核对目标、图层、版本、尺寸、总量、准确偏移、规范 base64 和完成标志。再次读取目录时图层元数据必须完全一致，规范来源栅栏仍须匹配，才能发布。无关的 Session 版本推进可按再次读取的目录版本接纳，不使未改变图层的完整资源失效。失败、过期或中断的读取不会产生部分更新的图像。同一来源等待新帧期间可以保留最后完整图像；绘制回执保留其实际旧版本。

已发布缓存最多 64 MiB 像素和 64 个图像资源。候选批次另有最多 64 MiB 界限，不可变资源在二者之间共享。因此旧/候选像素合计最多 128 MiB，载体/base64 块暂存另有界限。合并缓存发布时执行驻留预算；历史旧资源用满预算时先释放，再安装完整新批次。范围移除释放对应引用；通道关闭中断、join 并释放最后候选。不会增加依赖、服务、目录或临时产物。

## 字符栅格表面

基础传输使用真实 Ratatui 彩色单元格：每格上/下各一个颜色采样，以半格块字符表示。自然适配使用当前实测单元格尺寸，在真实 Panel 矩形内保持图像物理纵横比。尺寸未知时改为保持逻辑采样纵横比，不虚构字体尺寸。缺省网格轴也用相同实测比例补出，两轴都明确时保留声明尺寸。在已有 4096 像素源图界限下，正的无符号 16 位单元格尺寸与无符号 32 位网格输入使用有符号 64 位运算。零或缺失的测量仍使用逻辑回退。极端纵横比限制为至少一列且不超过正文高度，逻辑宽度不足一格时仍显示完整图像。网格列/行支持完整无符号 32 位范围（零表示自然适配）；明确尺寸和有符号位置按声明处理，采用宽于坐标输入的运算并裁剪到正文。Z 顺序来自 Session 目录。负层保留已有文字字形及前景，合成背景；正层在图片 alpha 非零时覆盖文字。完全透明采样保留底层内容。已知 RGB 底色采用直接 alpha 合成；未知默认色/调色板颜色在不透明度低于一半时保留原色，其余选择图像颜色。宽字形首格和占位格保持原子性，字符栅格会拆开它们时保留整组。Chrome、其他 Panel、宽字符归属、来源命中测试及终端鼠标模式仍由已有拥有者负责。

在真实 Panel 正文中绘制，顺序为终端内容之后、shell 覆盖层之前。只在 Terminal.draw 成功后，为未遮挡且来源仍当前的表面发布绘制回执。缓存下载本身不是绘制确认。缩放、zoom、切换、清除和关闭通过同一表面拥有者重新合成；清除后在下一次普通绘制恢复底层终端单元格。

## 有界宿主测量

交互式 Windows shell 只探测已经接纳的终端，在进入自身拥有的模式后、首次普通绘制前发起。现有生命周期写入者发送 xterm `CSI 16 t` 单元格像素查询，以及带非零随机图像 ID 的 Kitty `a=q,t=d,f=32,s=1,v=1` 查询。查询期限为 300 ms，不等待回复才开始绘制，也不创建图像放置。终端名称、环境变量、字体猜测和生产者 `transport` 提示不能建立这些事实。序列遵循 [xterm 控制契约](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html) 和 [Kitty 图形契约](https://sw.kovidgoyal.net/kitty/graphics-protocol/)。

现有输入解码器在按键、前缀、popup 和确认分发前拥有完整单元格报告及图形 APC 回复。原生文本模态中也消费相同元数据；括号粘贴仍为字面粘贴，包括看起来像回复的字节。图形回复最多 256 字节；超限或超时回复持续排空至字符串终止符，不分配更多空间，也不把回复尾部暴露为输入按键。没有后续图形引入符的单独 Alt+下划线保留原有含义。无回复、格式错误或迟到回复不会建立能力、增加人工活动意图或到达保留终端。

只接纳唯一待处理查询在期限内收到的单元格回复。正的无符号 16 位尺寸必须能为查询时的单元格几何形成准确且可表示的窗口像素总量。几何变化立即使测量像素失效。旧式单元格回复没有关联 ID，因此前一回复尚未到达时不能发起另一次单元格查询，即使已经超时；迟到回复先结清该负债并被丢弃，才能接纳后续查询。已知或已结清的测量可在下一次几何变化时重新查询。Kitty 回复必须匹配唯一已发出的 ID 和期限，且不携带放置 ID；无关 ID 不能建立支持。查询支持仍为内部事实，直到物理渲染器实际使用该能力。cell-raster 观察可发布实际测得的单元格像素，但仍发布 cell-raster 传输及 pixelMouse false。

shell 只把测量传给准确匹配的单元格几何和当前原生表面。保留 Pane 几何与 popup 几何采用相同物理像素；新选中的 Machine 在下次绘制前收到当前宿主事实。不增加文件系统资源、后台线程、额外控制台读取者或新依赖。定向验收须覆盖及时、迟到、缺失、错误 ID、格式错误及分块回复、与回复交错的普通按键、字面粘贴、模态捕获、几何失效和实际生命周期写入者。物理图像放置和像素鼠标仍是独立义务。

## Kitty 物理图像界面

Windows shell 的固定后端拥有一个 UI 线程图像界面，并与终端恢复共享自有图像租约。只有及时成功的 Kitty 探测和当前实测单元格像素才允许物理输出。绘制使用实际 Panel 内容区、Session、所选来源/绑定和单元格测量暂存不可变画布。覆盖层、Machine、通知、来源、图层集合或几何变化会在同一同步绘制中退役受影响的物理帧。不支持或未知的宿主继续绘制彩色单元格。生产者提示、终端名称、缓存 Session ID 或仅上传成功都不能确认可见绘制。

物理帧最多包含 64 张图像和 64 MiB 可见 RGBA 输出。每张图像从不可变来源惰性采样到裁剪后的物理矩形；单张超过 32 MiB 则使用单元格回退。自然适配和缺省网格轴与单元格渲染器共用实测比例计算。完整无符号 32 位虚拟网格在采样前裁剪；宽中间运算保留屏外放置而不回绕。保留直接 alpha、图层顺序和有符号 z。无关 Session 版本推进时，只有来源、完整图层元数据、不可变像素身份和物理几何完全不变才复用宿主图像；已确认回执可直接推进到等价画布版本而不重传。不保留完整重采样图像或完整 base64 载荷。活跃帧和一个冻结候选各最多保留 64 MiB 源像素，另有现有 128 MiB 读取/缓存上限。帧刷新成功后、下一次读取发布前释放暂存绘制引用；若需先确认资源删除，有界重规划标志会请求后续绘制。

同时只允许一张图像的分块传输。每个普通帧最多发送 32 块，每块最多 3072 原始字节（4096 base64 字节），随后使用现有单次帧刷新。上传期间冻结完整画布，避免持续推进的生产者使每块重启。每次完整上传需要五秒内与图像 ID 精确匹配的回复。只有整个就绪画布才替换前一个完整物理画布；旧画布只能在来源、图层集合、内容区和实测单元格完全相同时保留，并保持实际较旧版本。其他 Panel 保留各自独立的完整画布。放置回复还需匹配不变图像/放置组合和截止时间。待确认放置不发布已绘制版本。错误、超时或回复队列溢出会退役物理资源，在本宿主会话回退到单元格，不阻塞按键分发或重试不确定输出。

后端在现有同步更新内、单次刷新前发送上传、放置和删除命令。图像 ID 为正数，在自有备用屏会话中不重用且排除探测 ID；分配有上限，耗尽则回退。新的备用屏和唯一已接管输出写者隔离名称空间。仅删除已登记图像 ID。恢复租约在输出前登记分配，直到刷新成功才解除删除义务。正常退出、输出失败、panic 或信号时，恢复先终止未完成图像控制字符串并删除已登记图像，再结束同步输出和恢复其余模式。清理使用已接管生命周期写者，失败后仍尝试后续恢复步骤，不重开 TTY，恢复隔离后不留图像写者。

验收包括跨分块协议重建、当前来源/几何/覆盖层退役、生产者持续推进时的完整帧发布、错误/迟到/失败上传和放置回复、输出失败和清理重试，以及使用模拟响应宿主的实际原生 shell 绘制。模拟宿主不代表真实 Windows 终端模拟器的视觉兼容性；仍需组合验收。

## 事实与验收

新增有界图形观察由已有 Client 控制连接在普通视图同步后提交。Server 核对认证 generation 派生的 Client ID、heartbeat、Workbench 版本、规范目标/绑定及已安装版本界限。其他连接不能替换该 Client 的事实。Info 采用新鲜匹配观察，从实际绘制路径报告 cell-raster 或已准入物理 Kitty 能力及 pixelMouse false，只发布来自当前有界宿主测量的单元格像素。部分表面列表不能把未包含 Pane 判为隐藏。过期、断开或不匹配观察不能声称可见性或成功绘制。

回退路径不声称已协商 Kitty/Sixel 或像素鼠标。托管私有生产者文件租约和完整文件帧 CLI 输入已由 [Session 图形所有者](../../orchbee-server/docs/windows-graphics.zh-CN.md) 实现。物理 Kitty 路径已集成有界探测、上传、放置和恢复；不宣告像素鼠标能力。定向证据覆盖真实原生渲染输出、alpha/z/裁剪、完整块/资源栅栏及 Client 归属。判定对齐或合入 main 前仍需真实 Windows 图形组合流程和最终全量回归。不运行 TLA、WSL、新增 macOS/Linux 运行时或手动抢焦点 Desktop 测试。
