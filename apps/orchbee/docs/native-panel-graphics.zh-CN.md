# 原生 Windows Panel 图形渲染

## 目标与归属

原生 TUI 消费已有 Site 拥有的 Panel/Presentation 图层。图形查询使用现有可取消读取通道的独立实例，不借用 UI 的终端/控制连接、不发送 PTY 输入、不改变焦点。主 UI 拥有可见目标选择、缓存发布、裁剪和成功绘制回执。现有 Client 控制发布者在已认证连接上拥有能力/绘制观察。

只有成功 shell 绘制中包含的表面进入读取范围。准确记录所选主/子项身份及可空终端绑定；删除、重新绑定、隐藏或切换后立即退出范围。Site 身份对重连和冷恢复提供栅栏。稳定标签和保持身份的移动不使像素资源失效。读取前、完整资源读取后和 UI 发布时均核对来源归属。每次有界批次最多查询 64 个表面，在已有 4096-Panel 上下文界限内轮转。

## 完整资源与界限

目录元数据与不可变图层缓存比较。准确资源版本不变时共享已有像素，不复制图像字节。新 RGBA 资源每块最多 256 KiB，核对目标、图层、版本、尺寸、总量、准确偏移、规范 base64 和完成标志。再次读取目录时图层元数据必须完全一致，规范来源栅栏仍须匹配，才能发布。无关的 Site 版本推进可按再次读取的目录版本接纳，不使未改变图层的完整资源失效。失败、过期或中断的读取不会产生部分更新的图像。同一来源等待新帧期间可以保留最后完整图像；绘制回执保留其实际旧版本。

已发布缓存最多 64 MiB 像素和 64 个图像资源。候选批次另有最多 64 MiB 界限，不可变资源在二者之间共享。因此旧/候选像素合计最多 128 MiB，载体/base64 块暂存另有界限。合并缓存发布时执行驻留预算；历史旧资源用满预算时先释放，再安装完整新批次。范围移除释放对应引用；通道关闭中断、join 并释放最后候选。不会增加依赖、服务、目录或临时产物。

## 字符栅格表面

基础传输使用真实 Ratatui 彩色单元格：每格上/下各一个颜色采样，以半格块字符表示。自然适配在真实 Panel 矩形内保持图像的逻辑采样纵横比，不虚构物理单元格像素尺寸。极端纵横比限制为至少一列且不超过正文高度，逻辑宽度不足一格时仍显示完整图像。网格列/行支持完整无符号 32 位范围（零表示自然适配）；明确尺寸和有符号位置按声明处理，采用宽于坐标输入的运算并裁剪到正文。Z 顺序来自 Site 目录。负层保留已有文字字形及前景，合成背景；正层在图片 alpha 非零时覆盖文字。完全透明采样保留底层内容。已知 RGB 底色采用直接 alpha 合成；未知默认色/调色板颜色在不透明度低于一半时保留原色，其余选择图像颜色。宽字形首格和占位格保持原子性，字符栅格会拆开它们时保留整组。Chrome、其他 Panel、宽字符归属、来源命中测试及终端鼠标模式仍由已有拥有者负责。

在真实 Panel 正文中绘制，顺序为终端内容之后、shell 覆盖层之前。只在 Terminal.draw 成功后，为未遮挡且来源仍当前的表面发布绘制回执。缓存下载本身不是绘制确认。缩放、zoom、切换、清除和关闭通过同一表面拥有者重新合成；清除后在下一次普通绘制恢复底层终端单元格。

## 事实与验收

新增有界图形观察由已有 Client 控制连接在普通视图同步后提交。Server 核对认证 generation 派生的 Client ID、heartbeat、Workbench 版本、规范目标/绑定及已安装版本界限。其他连接不能替换该 Client 的事实。Info 采用新鲜匹配观察，报告 cell-raster 能力及 pixelMouse false，物理单元格像素保持 null。部分表面列表不能把未包含 Pane 判为隐藏。过期、断开或不匹配观察不能声称可见性或成功绘制。

回退路径不声称已协商 Kitty/Sixel 或像素鼠标。托管私有生产者文件租约和完整文件帧 CLI 输入已由 [Site 图形所有者](../../orchbee-server/docs/windows-graphics.zh-CN.md) 实现。物理能力路径仍有独立验收义务。定向证据覆盖真实原生渲染输出、alpha/z/裁剪、完整块/资源栅栏及 Client 归属。判定对齐或合入 main 前仍需真实 Windows 图形组合流程和最终全量回归。不运行 TLA、WSL、新增 macOS/Linux 运行时或手动抢焦点 Desktop 测试。
