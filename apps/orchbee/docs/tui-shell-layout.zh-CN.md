# TUI shell 布局

## 范围与归属

原生 Client shell 把宿主区域划分为顶部条、内容区、可选侧面板、带共享边界的窗格区，以及按需出现的一行
状态行。本文档声明 `docs/tui/layout.md` 要求所属应用给出的具体区域、阈值与降级顺序。它只
拥有布局投影：颜色、字形与边框样式归主题层，浮层内容归各自 surface 渲染器，终端单元格绘制
归 `terminal_cells`。

投影是纯函数。`tui_layout::project_shell_areas` 根据当前帧矩形与视图请求的侧面板形态（含首选宽度）计算
所有区域；`tui_shell` 用同一对函数（先 `project_shell_areas` 再 `native_terminal_area`）计算终端
几何，因此绘制内容区与 wire 几何不可能分叉。渲染代码不修改业务状态、时钟或 I/O，布局值也
不跨帧缓存。

模态组合拥有纯几何、帧内按键标签与光标定位、共享动作与关闭按钮绘制，以及精确指针投影和发布。
各特性渲染器拥有自己的本地化内容、类型化 token 与 `HitTarget`、不可用原因、呈现阶段、效果及
绘制回执。共享模块绝不导入特性专属状态或 token。

表单与确认的 `ModalAction` 将有效绑定交给 `ActionSpec` 的可选快捷键槽。它在按钮方括号内
测量并绘制弱化的按键。页脚省去重复动作提示，在按钮行上方保留至多两个次要编辑或导航提示。
Settings 的关闭、返回和子任务取消／确认采用相同规则。
完整的 X 绘制同时登记其精确类型化关闭目标，供蒙层手势复用。

模态的 `title_line`、`description_line` 与 `status_line` 投影
[覆盖层层级](../../../docs/zh-CN/tui/overlays-and-status.md#内容层级)：一个加粗的主要任务标题、
次要上下文与字段帮助、主要标签与值，以及仅作用于字形的状态色。重命名和设置字段在边界上方
保留标签；多字段表单用一空行分隔字段对。确认保留主要目标与后果文字。Settings 将标题放在
边框上，内部分类加粗、位置计数弱化。现有共享行与动作控件继续拥有选择、可用性、悬停、
按下和焦点提示。

文字模态首选 48–72 内部列（含边框与水平内边距为 54–78 列），并限制在可用覆盖层区域内。
完整的必需控件可以增大首选宽度；可选提示不得增大它。正文按最终宽度折行，字段窗口化草稿，
提示仅舍弃末尾的完整记录。项目与检出选择器保留 78/84 列首选宽度、固定头部和页脚，以及
独立窗口化的行；Settings 保留 92 列首选宽度。
[模态见证](../src/tui_render/modal/tests.rs) 覆盖宽度与控件准入，
[完整弹窗见证](../src/terminal_session/ui/tests/modal_pointer_roundtrip.rs) 覆盖项目命名流程、
本地化层级、字段光标、错误／不可用处理和暂停时的目标。

所有模态几何，包括完整提示、动作、字段和固定三列关闭动作，都必须在 `start_modal`、帧修改、
光标定位或命中发布前完成准入。被拒绝的 surface 返回空回执或 `NotPresented`，且对帧与命中图
零修改。获准控件使用同一个精确矩形完成指针投影、绘制与发布。现有特性内准备与测试接缝继续
归其特性所有，包括 Panel close 的 `render_prepared`；因此测试既能验证领域准备，也能验证共享
组合，而不把业务行为移入渲染器。

## 视口分级

宽度与高度独立分级，取两者中更低的级别。

| 级别     | 宽度级（列） | 高度级（行） |
| -------- | ------------ | ------------ |
| Full     | >= 100       | >= 24        |
| Compact  | 60..=99      | 12..=23      |
| Minimal  | 20..=59      | 5..=11       |
| TooSmall | < 20         | < 5          |

`tui_layout` 中的 `ViewportTier::from_size(columns, rows)` 是唯一分类器。各级 chrome 行列
配额：

| chrome       | Full               | Compact                                              | Minimal       | TooSmall      |
| ------------ | ------------------ | ---------------------------------------------------- | ------------- | ------------- |
| 顶部条       | 1 行（tabs）       | 1 行（tabs）                                         | 无            | 无            |
| 状态栏       | 固定预留 1 行      | 固定预留 1 行                                        | 固定预留 1 行 | 固定预留 1 行 |
| 侧面板       | 停靠，有界首选宽度 | 内容保留 60 列时停靠，否则为浮层，有界首选宽度，靠左 | 隐藏          | 隐藏          |
| Panel chrome | 仅分屏边框与叶标题 | 仅分屏边框与叶标题                                   | 不绘制        | 不绘制        |
| 内容         | 剩余区域           | 剩余区域                                             | 剩余区域      | 仅提示        |

TooSmall 时 Client 只绘制一条本地化的小尺寸提示与状态栏，别无他物；宿主变大即恢复正常渲
染。视图请求的侧面板形态只是一种意图：`project_shell_areas` 按级别翻译它（`Docked` 与
`Overlay` 都表示可见：Full 停靠；Compact 下只要内容在有效侧栏旁仍保留 60 列 Compact 最小宽度，
停靠意图就保持停靠，否则改为浮层；更低级别隐藏），因此渲染 chrome 与 wire 几何保持一致，调用方
无需关心级别。宿主宽度不小于默认侧栏加该最小宽度（90 列）时视为宽窗口，默认显示侧栏；更窄的宿主
只以显式请求的浮层打开侧栏。

独立的元数据／Git 轮询间隔不会延迟此本地反馈或已确认结果的交接。

侧栏键盘导航中，Ctrl+Up 和 Ctrl+Down 移动当前 Project，或在当前 Project／未分组列表中移动
Workspace。既有行菜单快捷键保留分组命令，与右键共享稳定目标证明。这些局部绑定从绑定注册表投影到
侧栏帮助；该手势不新增独立快捷键系统。

Windows Full 和 Compact 顶栏包含 Tab、关闭与创建控件、当前可用的 Presentation 选择器，以及
必要时的侧栏恢复控件。Agent 信息位于侧栏与 Agent Board；顶部界面不显示 Agent 摘要，也不会
在这些界面隐藏时要求观测。全局动作可通过 `Ctrl+B F2` 和配置的菜单绑定访问。非 Windows Client
的侧栏不投影规范导航行，因此保留上下文路径；位置与活动 Tab 标签相同时省略路径。
活动 Tab 使用内边距、`surface-current`、加粗身份、下划线和始终可见的当前标记。
分组成员的勾选标记保持独立。
紧凑 Tab 直接显示标签，不加序号前缀；导航列表仍保留键盘位置序号。
分屏的共享外框不再重复通用标题，基础样式使用中性色；焦点窗格周围已有的边界线段
采用聚焦框架角色，同时保留该窗格的强调标题。不在叶子周围增加边框单元格，分隔线矩形
保持原样。分隔线端点更新外框已有边界单元格的交汇字形，
不留半格断口，并保留框架角样式。
单窗格和放大视图保留与分屏一致的外框及一行叶标题，首次分屏不会改变终端内边距。每个窗格在右侧
预留一列 chrome，供[历史滚动条](native-terminal-viewport.zh-CN.md#滚动条交互)使用。
历史为空或待定时仍预留该列，输出本身不会改变 PTY 宽度。该列与内容、标题和分屏分隔线
命中区域不重叠。只有一列宽的窗格省略该列；不足两行的轨道不显示滑块。分屏叶子和放大
视图在原生几何、绘制、输入坐标和布局查询中使用同一内容宽度扣减。
叶标题优先显示自定义元数据，随后使用稳定的创建标签。数字创建标签搭配本地化“终端”前缀，
不采用当前布局序号。活动标题有显式标记，完整边界在分隔线字形绘制后强调，包括共享边缘。
侧栏导航拥有输入时取消终端焦点强调。多个 Presentation 的箭头与数量在单窗格、分屏、放大时
均位于叶标题，各自命中目标互不重叠。
渲染器、PTY 尺寸、弹出终端和只读布局查询共享这份几何；放大视图中隐藏的叶子保留规范的未放大尺寸。
非焦点终端内容保留正常文字对比度；焦点由窗格 chrome 和光标表达，
不对其他程序的内容附加 DIM。
Shell 先绘制终端画布，再为侧栏、标签栏和分屏标题带绘制持久 chrome 背景。
覆盖层绘制自身完整的不透明表面；边框和标题表达边界及焦点，区域区别不再只依赖它们。

顶栏空间用于终端导航。复制和调整大小模式会用各自控件替换顶部条；没有顶部条时，
这些模式会覆盖工作台首行。
这些控件不额外占用终端几何；已绘制控件的指针优先级高于其下方内容。
具体行为由操作菜单、复制和调整大小的所属参考文档维护。

在仍可呈现的层级中，帮助无法容纳完整页面时，既有状态行显示本地化的调整窗口提示，
并保留完整三格 `[x]` 按钮。该按钮在 Minimal 下仍可见，关闭帮助不改变底层模式或 PTY
几何。TooSmall 只绘制根尺寸提示与状态栏，保留帮助 episode，不发布隐藏控件。
恢复到可呈现尺寸后，可继续显示保留的帮助页。

## 快捷创建控件

Windows 顶栏在最后一个可见 Tab 后为 `+` 预留三列，空的规范 Workspace 也保留该入口。
当前 Tab 与创建控件共享顶栏空间，Presentation 选择器位于窗格标题。低于 Compact 时，
控件随顶栏一起隐藏。固定的新建工作区行通过既有快速动作立即创建 Workspace；
符合条件的当前站点 Project 行在绘制宽度允许独立控件时，在行菜单旁保留创建动作。
展开、内容、创建和菜单单元格互不重叠。紧凑字形与语言无关；完整动作标签和不可用原因复用已有中英文目录。

| 入口           | 既有动作与归属                                                                                                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Tab 顶栏 `+`   | `DrawnTabCreate` 冻结 Session、快照 revision 和 context。无修饰左键按下仅启动本地鼠标手势；在同一个仍可见矩形内匹配释放后，请求 `NativeUi` 重新校验证明，再将 `ClientAction::CreateTab` 交给原 dispatcher 和 membership 准入。按下时没有副作用。 |
| 新建工作区行   | 无修饰左键按下启动精确的已绘制动作；在同一个仍暴露的区域内匹配释放后，才将 `ClientAction::RequestQuickWorkspace` 委托给已有创建归属者。不打开表单，直接提交独立 Workspace 与首个 shell；按下时没有副作用。                                       |
| Project 行 `+` | 针对准确的已绘制 Project 打开同一创建子集，把定向快速 Workspace 放在首位。保留原能力检查和禁用原因，不隐式选择子 Workspace。                                                                                                                     |

右键点击 Tab 顶栏 `+` 打开独立的新建 Tab 菜单（普通 Tab、最近分组或新分组）；
全局菜单提供键盘入口。它保留同一个精确的 `DrawnTabCreate` context 证明。
详见 [Tab 菜单](native-tab-groups.zh-CN.md#指针排列与菜单导航)。

身份、几何改变、捕获覆盖、释放鼠标捕获或在控件外释放都会取消 Tab 创建手势。
释放所在输入包的剩余字节（含粘贴）即使在证明被拒绝时也不会进入 pane。菜单入口保留
原捕获与取消生命周期。键盘路径不变：配置的新建 Tab（默认 `Ctrl+B c`）、
Workspace 创建（`Ctrl+B a`）、快速 Workspace（`Ctrl+B Shift+N`）及全局／Project
菜单。这些控件不拥有新的业务状态、终端身份或持久化。

绘制和命中测试覆盖两种语言、默认／RGB 主题、空／有内容的列表、全部视口级别与长标签。
鼠标轨迹覆盖完整点击和失效；NativeUi 测试检查旧 context／快照拒绝，以及向原命令／
草稿 owner 的委托。这些确定性测试及合成缓冲区预览不证明实际宿主的调色板或字体表现。

## 侧栏 Agent 入口

统一侧栏按精确归属关联现有可用 Agent 投影。树中只出现实际 Agent 行；
读取中、不可用、空列表与无匹配占位信息保留在全局 Agent 选择器中。树形列表页脚
统计可见导航条目，包括 Project 与 Context 行，仅溢出时显示范围；不将该数量表示为 Agent 总数。

已折叠的 Project 或 Context 不显示 Agent 汇总；Workspace 状态字形汇总完整的物理 Agent
检查点，因此待处理信息在折叠和 Agent 筛选后仍然可见。当前 Workspace 样式仍保留在 Context
或其折叠后的 Project 上，不改变活动终端。

Agent 与 Workspace 状态字形使用侧栏呈现状态：用户已看过的完成轮次按空闲显示。侧栏可见且观察到
工作中 Agent 时，工作状态每 100 毫秒切换一次主题的等宽帧（盲文 `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`；ASCII 为
`-\|/`）。动画相位保存在 Picker 中并由事件循环推进，绘制仍是状态的纯函数；窗格标题保留静态状态字形。

固定搜索行打开工作区选择器，并聚焦名称查询。即使没有 Agent，也立即显示已有工作区；
输入文字过滤名称，Enter 打开选中的准确目标，Esc 返回终端。仍可用 Tab 或已绘制控件切换
机器与 Agent 模式；Agent 范围与筛选保留既有语义。参见
[工作区搜索所有者](machines.zh-CN.md#跨机器工作区导航)。在显式侧栏键盘归属内，`Shift+N` 调用同一
新建工作区动作，`/` 进入同一搜索编辑器；F1 列出这些绑定。固定动作只在该归属者处于活动
状态时显示这些本地按键标签，并从 `SIDEBAR_BINDINGS` 派生，不嵌入固定文案；完整按键标签放不下时整体省略。
独占输入捕获可以保留 Picker 记住的行焦点以便恢复，但会抑制侧栏焦点边框、行导航提示和
归属者本地按键标签，使捕获表面成为唯一可见的键盘归属者。
已有全局 `Ctrl+B Shift+N` 创建路径仍可使用。查询编辑与取消保留选择器的捕获规则，
打开任一动作都会消费输入包尾部。可见范围页脚打开 Workspace 选择器，空白页脚没有动作。
Workspace 浏览与 Agent 筛选仍可通过已有 Machine 选择器模式访问；本布局不为分组标题分配
新的浏览／筛选控件。底部固定“设置”入口直接打开已有设置编辑器，
与 GUI 侧栏入口保持一致。它位于滚动树之外，不显示菜单或机器标签。空间足够时显示
来自快捷键注册表的完整配置按键路径，而不是写死默认值。键盘使用配置后的动作打开设置
（默认 `Ctrl+b F4`）；已有逗号绑定继续重命名 Tab。
全局操作保留 `Ctrl+B F2`，机器选择保留 `Ctrl+B Shift+M`。
隐藏侧栏不发布侧栏命中区域。所有入口保留原有准入与输入捕获归属。

绘制消费受信任的选择器行、共用窗口、几何和快捷键注册表，不执行观察或后端命令。
绘制与输入测试覆盖两种语言、主题、配置行、树形连接符、选择器／设置入口及
Full/Compact/Minimal/TooSmall 矩阵。宿主交互需要单独的原生证据。

## 侧栏导航模型

点击 Workspace 或在其上按 Enter 会直接激活精确目标，不绘制机器、工作区或 Agent 选择器作为过渡。
同机激活复用当前 Session 及各位置选择记忆；跨机候选保留既有可绘制交接。
当前 Workspace、Tab 及内容遵循已安装的 Session 选择。等待、被替代及取消的请求遵循
[机器导航](machines.zh-CN.md#跨机器工作区导航)。

原生侧栏从完整 Machine checkpoint 和活动 Client 的规范快照绘制 Workspace 及可选 Project 分组。
每台 Machine 依次显示非空历史内容、Project 及其子项，最后是未分组 Workspace。分组后的普通 Workspace 与基于
Git worktree 的 Workspace 同级，每个 Workspace 都拥有自己的 Agent 子行。
`machine_spaces::Checkpoint` 从与 Workspace 相同的受保护 Snapshot 保留 Project ID
和标签，包括具有独立菜单与创建控件的空 Project。活动 Client 在每次 UI tick 提供已验证拓扑，
以及至多一次已准入移动的可撤销显示。独立观察器按准确身份补充元数据和 Git 证据，更新的规范修订号
取代旧的本地拓扑。新拓扑无需等待元数据读取，其他 Machine 保留自身观察生命周期。

`machine_picker::Picker` 拥有 Project 展开、各 Context 独立的 Agent 列表折叠偏好、键盘行焦点
及共用窗口。`SidebarTarget::Project` 携带 Machine／Session／Project 身份；
`SidebarTarget::Context` 携带 Machine 与完整 `NativeContextTarget`；
`SidebarTarget::Agent` 还保留精确成员与物理绑定身份。可选 Project 归属是 Context 元数据，
由 `Picker::sidebar_parent` 从当前投影解析。移动 Workspace 或解散其 Project 不改变
终端身份、Tab 或 Panel 目标。Agent 关联不使用标签或行位置。同名同级行保留 ID 注记。
规范 Project 顺序、各组或根列表中的 Workspace 顺序，以及全局可用 Agent 顺序保持原样。

共用窗口按身份及旧邻居顺序保存手动定位的顶行。插入、排序、展开／折叠、后台来源更新及尺寸变化
在视口边界内保留该行；移除时依次使用旧顺序中下一个仍存在的邻居、前一个邻居、空状态原点。几何变化时丢弃已排队
的滚轮工作。临时创建行参与几何测量，但不成为身份，也不移动保存的真实行锚点。显式导航或前台创建
恢复最小必要的焦点显露。普通视口移动不改变领域选择。

每个成功帧从这些已有身份、父子关系及动作准入构建一个不可变 `SidebarSource`，并由该帧的
所有 `DrawnSidebarTarget` 与 `DrawnSidebarFixedTarget` 共用。标签、状态文案、主题、键盘焦点、鼠标呈现和滚动位置不进入
该来源。普通行和展开控件在按下时记录精确来源、语义部件、目标及已绘制窗口；释放时只重建
一次实时来源，完全匹配后才调用已有 Picker 转换。固定动作记录同一来源及动作特定的效果作用域；
新建工作区和浏览包含当前 Machine 与 Context，搜索和设置无需选择作用域。释放时同样只重建一次，
并要求来源及作用域完全匹配。过期释放会被围栏且不产生效果。悬停和按下不改变当前 Context、
行焦点或选择。菜单、创建、右键及滚轮继续由各自专用手势归属者处理。

| 状态／事件                | 决策与可观察结果                                                                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 初始展开状态／Agent 到达  | 各 Context 的 Agent 列表初始展开，包括新观察到的 Agent；多个列表可同时保持展开。只要 Context 仍存在，显式折叠偏好就跨筛选、Agent 暂缺及到达、Project 折叠保留。                                        |
| Context 展开按钮释放      | 在同一仍有效区域匹配释放后，仅切换精确可见的 Context，不激活终端、不获取键盘焦点；其他列表保留原状态。保留手动滚动的视口，取消待处理滚轮几何，使已绘制命中图及输入包尾部失效。                         |
| 进入导航                  | 可用的 Picker 进入显式键盘归属，包括空树。保留有效旧行焦点，否则显露活动 Context、其可见 Project 父行或第一行。可在首次绘制前进入。                                                                    |
| 方向键／Home／End         | 仅在可见行间移动并显露稳定键盘焦点，不激活 Context 或 Agent。                                                                                                                                          |
| 右／左                    | 右键打开已折叠的 Project 或有可用子行的 Context；已展开时立即进入首个子行。左键从 Agent 回到 Context；已展开的 Context 先折叠，再返回可选 Project；Project 则折叠。Project 上的 Enter 切换其展开状态。 |
| Context／Agent 上的 Enter | 为精确可见目标返回一个经过身份校验的 `Activate(Selection)`，包括 Agent 已有的 Tab 和 Panel。由既有归属者应用；当前 Agent 无需操作，焦点移动绝不写入 `Picker.request`。                                 |
| 菜单／F1                  | Context 与 Project 保留既有菜单意图及准入；Agent 行不产生虚构的 Context 菜单。F1 打开快捷键帮助，保留行焦点和导航归属。                                                                                |
| 来源替换／折叠            | 仅在目标消失时清理其展开偏好。Project 与 Context 折叠保留活动终端、隐藏的展开偏好及计数／当前目标信息。保留精确可见焦点，否则选择最近可见祖先，再退到原有有界位置。删除的 ID 不重定向到同名标签。      |
| 重新分组／解散            | 从当前 Project 元数据解析仍存在的 Workspace 或 Agent 的祖先。目标可见时保留精确焦点；移入已折叠 Project 时将焦点放在该 Project。身份已移除时，先通过最后已知且仍存在的祖先恢复，再退到原位置。         |
| 滚轮／按键显露            | Workspace 和 Agent 命中使用同一合并且每次刷新受视口限制的滚轮窗口。键盘移动恢复焦点显露；滚轮移动不激活目标。                                                                                          |
| Escape／隐藏侧栏          | 退出键盘归属并消费其输入包尾部。最后一个观察消费者隐藏时释放来源行及失效的展开状态；普通终端输入保留已有归属。                                                                                         |

Agent 树形连接符位于 Workspace 状态下方的固定两列轨道。配置续行对齐首行可选状态图标之后的名称。
次要行使用元数据文字，保留显式 token 覆盖。当前 Context 与 Agent 使用相同的中性表面和
粗体身份。调色板折叠或身份 token 显式关闭粗体时，独立标记会保留当前身份；运行状态、
未读状态与键盘导航分别使用独立轨道。

Project／Context 展开字形、身份文字与行菜单使用互不重叠的已绘制范围。续行、内部前置配置
留白，以及位于最前层展开、创建和已显示关闭目标下方的所有单元格，都保留主要父行目标。Project 的
外部分组间隔保持无操作。
`SIDEBAR_BINDINGS` 拥有按键匹配与本地化发现。分发器拥有捕获优先级、过期绘制拒绝及
输入包尾部围栏；菜单归属者保留能力检查和执行。Project 菜单从不代选子 Workspace。
鼠标和键盘展开共用 Picker 转换；导航键仅在侧栏显式拥有输入时生效。
GUI 对应范围为层级与身份语义，不主张像素或后端等价。

| 主张                 | 可执行证据与边界                                                                                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 精确分组且不隐式激活 | 确定性 Picker 用例覆盖 Machine／Session／Context 关联、重复标签、未分组 Workspace、保留的历史内容、多个默认展开列表、折叠偏好保留及精确 Tab／Panel 激活。 |
| 焦点和滚动有效       | 有界生成式导航轨迹覆盖拓扑与分组变化；定向用例覆盖重新分组／解散、已移除的祖先、Agent 与父行移动、当前 Agent 显露及手动滚动后展开。不主张无界证明。       |
| 共享几何与输入权威   | 绘制、鼠标与分发器用例覆盖配置行高／间距、两种语言／主题、宽字形、折叠后的当前目标信息、已显露的 Project 控件、过期命中、滚轮取消及不转移焦点的展开。     |

这些同步呈现转换不增加异步副作用或终端确认。现有侧栏输入、菜单与鼠标所有者及其确定性测试
继续负责独立的完成、捕获与取消顺序。新的树形投影与展开语义除这些定向检查外，还需要上述确定性证据。

## 侧栏宽度与恢复模型

`tui_layout::SidebarWidth` 接受 24 至 60 列，默认 30 列。这是 Picker 拥有的显式 Client
本地偏好，不由内容自动撑开，也不持久化。可见侧栏使用 `min(preferred, host columns / 2)` 列，
即首选宽度与宿主列数一半中的较小值；
既有 Full 和 Compact 下限保证此上限仍高于最小宽度。`SidebarSurface` 将首选值沿既有
唯一 Shell 投影器传给终端几何与本地窗格布局校验。状态覆盖层使用可见侧栏右侧的列。宿主缩小时
仅约束有效矩形，保留首选值供以后恢复。

| 状态／事件             | 决策与不变量                                                                                                                                                                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Full／Compact／Minimal | 保留既有分级与可见意图规则：Full 停靠，Compact 在内容保留 60 列时停靠、否则显示显式请求的浮层，更低级别隐藏侧栏。宽度不会自动打开浮层，也不改变宽窗口下的显示意图。                                                                 |
| 键盘宽度               | 侧栏导航拥有输入时，准确的 Shift+Left 和 Shift+Right 发出缩窄／加宽两列的意图，`0` 发出重置为 30 列的意图。共享快捷键注册表同时提供本地化帮助。即使鼠标捕获已释放，也要求准确且当前有效的已绘制侧栏目标；没有目标就不修改偏好。     |
| 到达宽度边界           | 从有效宽度开始调整。若约束后的结果等于该宽度，则保留原首选值；重置显式写入默认值。                                                                                                                                                  |
| 鼠标按下／移动         | 在既有单列右边框上普通左键按下，捕获其准确视口、含完整首选宽度的表面与有效侧栏矩形。绝对位移产生可撤销的实时宽度，行、边框命中及停靠终端几何同步移动；按住期间宽度偏好、行焦点、展开状态及导航请求不变。                            |
| 匹配的左键释放         | 重新校验已绘制目标，并将原首选宽度与当前偏好准确比较。通过 Picker 单次提交变化后的候选值，使旧命中几何失效并运行既有布局边界。有效矩形相同不能授权过期首选值。                                                                      |
| 取消／来源过期         | Escape、Shift、宿主尺寸变化、侧栏隐藏、上层捕获或已绘制目标丢失都会丢弃预览。零位移和边界约束下的无效调整释放保留原首选值。输入归属者继续负责释放和输入包退役。                                                                     |
| 宽度提交               | 清除排队的侧栏滚轮工作，恢复感知行高的焦点显露。保留键盘归属、展开状态、活动 Context 和请求。已接受偏好接替已投影宽度，后续帧持续保持标签、行高、命中及终端几何一致。                                                               |
| 隐藏后恢复             | 当 Full 或 Compact 能呈现侧栏且没有覆盖层捕获该表面时，本地化顶部条入口调用已有 `FocusBusinessSidebar` 动作，与配置的导航进入路径一致；已有显示切换和全局菜单仍可用。Minimal 和 TooSmall 保留既有简化提示与拒绝行为，直到宿主变大。 |

边框命中使用侧栏控件层，只高于自身表面，低于覆盖式模态层。行、菜单和边框矩形互不重叠。
只读局部 `ResizeProjection` 为绘制、命中映射及终端尺寸观测提供同一有效宽度。
指针分别保存不可变偏好来源及最后成功草稿帧凭据；自身布局变化保留拖动，外部所有者／
viewport／来源变化取消。Compact 覆盖层宽度变化不改变其下方终端几何。图形复用既有
遮盖及草稿拒绝后重绘生命周期。只有实际单列边框使用焦点强调前景色，相邻单元格按新几何
正常绘制。按下、移动、释放和取消
均不向状态区域或浮层添加宽度数值或拖动提示。

纯宽度模型覆盖合法边界、半宿主约束、偏移视口、绝对移动、无效调整时保留偏好，以及
120 → 60 → 50 → 120 的恢复。Picker 用例覆盖比较后设置的拒绝、焦点保留，以及活动
Workspace 已收起时进入导航不展开父项目。侧栏渲染覆盖 24／30／60 列、两种语言、分级降级
和准确边框命中。原生鼠标输入权威下的共享输入证据拥有捕获、过期绘制、取消、匹配释放、
跨已渲染帧的两次按住移动、图形清理及终端几何一致性；纯几何本身不能证明这些副作用。已有有界层级轨迹继续作为层级权威。

## 状态栏

工作台在所有尺寸下固定预留底部一行状态栏。`ShellAreas.panel` 及终端、窗格、滚动条和只读布局
投影均排除该行，侧栏保留完整高度。状态行为空时也保持预留，前缀态、通知和过期均不改变 PTY
尺寸，也不覆盖终端内容或窗格边框。空闲时状态文本为空。

状态文本在前缀捕获、其他输入模式、有意义的通知、连接或恢复、释放指针捕获，以及当前终端
生命周期结束时出现。窗格标题旁仍保留退出反馈：`Locale::native_status` 拥有本地化
退出结果，渲染器即使在会话仍为 Ready 且持有控制权时也继续准入状态覆盖层。
无法容纳输出保留详情时，本地化紧凑文案在二十个单元内保留完整退出码、信号、未知结果或
运行故障事实，预留行保持稳定。
Ready 和放大状态可在前缀提示中查看，普通可控制状态省略，只读输入状态仍明确显示。TooSmall 保留退出提示。
分段遵循 `docs/tui/overlays-and-status.md`；上下文为模式与退出提示让位。
前缀徽章先将取消提示缩短为 `Esc`，再仅保留徽章。菜单与设置在绘制自身提示前完整覆盖背景。
运行时生产者提供不内嵌快捷键文本的本地化事实。页脚使用已启用的实际分派绑定，或当前本地输入
所有者的规范绑定，按解析后的主题字形策略追加一组有序且完整的 `KeyHint` 控件。它不改写内嵌
默认值，也不代入后备按键组合；无法完整容纳的提示会整体省略。可恢复的 Close 状态只有在主事实
完整绘制后才发布绘制凭据。
在 TooSmall 下，被捕获的独立 popup 只提供本地化的尺寸恢复提示。程序输入语义保持不变，
但暂停的表面会消费 Esc、前缀、粘贴和指针输入而不转发。可用表面恢复后，输入继续交给
同一 popup 程序与身份。
被覆盖单元格不透传鼠标输入，也不证明终端图形无遮挡。状态文本区域只有完整绘制时才报告，
保留恢复确认的绘制准入。侧栏固定设置页脚位于此矩形之外。

## 内容区与浮层

未连接的工作台在覆盖式侧栏旁仍可见的区域内绘制本地化连接说明与标题。
这些应用说明使用独立的绘制矩形；规范 shell 区域和终端几何保持不变。显示覆盖式侧栏时，
其下方的窗格视为被遮挡：光标、图形与提醒标记均保持隐藏。

Windows [Workbench 导航器](native-context-selection.zh-CN.md#windows-捕获输入的导航器) 使用现有居中
表面，提供两列标题并围绕本地焦点显示列表窗口。活动标记继续标识已选终端，选择背景表示
Enter 将打开的行。完整可见行随成功帧发布精确凭据。Esc／Enter 提示优先于可选切换键及移动
细节；源用例覆盖两种语言、配置后的前缀标签、长列表滚动列、120x41、120x40 和 80x24。
内部区域小于 40x7 单元格时拒绝呈现，并通过新帧围栏释放捕获。导航器抑制 pane 光标／焦点
强调。前缀输入也隐藏终端光标。快捷键 Help 保持非模态行为。

内容范围内的居中浮层使用 `ShellAreas.panel`，状态行已位于其外。应用设置
改为使用完整宿主视口扣除最后一行，将侧栏和顶部条都纳入居中参考。侧栏可见性和宽度不再移动
该表面。这些定位规则不改变终端几何。`tui_layout` 为内容范围内的表面渲染器提供两个纯函数：

- `overlay_area(&ShellAreas) -> Rect` —— 内容范围内居中浮层使用的区域。
- `place_overlay(area, preferred_width, preferred_height) -> Option<Rect>` —— 解析为
  `min(preferred, area - 4)` × `min(preferred, area - 2)`，居中且多余单元格向左上取整；当
  解析出的内部区域小于 4x3 时返回 `None`。

被拒绝的浮层不绘制，由调用方通过状态栏报告。因为状态行在所有浮层与模态之后绘制，即
使旧 surface 渲染器仍在自行计算几何，"状态栏不被覆盖"这一不变量也成立。

## 分屏窗格

`divide_panes(area, orientation)` 返回 `PaneDivision { first, divider, second }`，其中
`divider` 是两个子窗格之间恰好共享的一个单元格列或行；当任一子窗格小于文档化的 4x3 最小
值时返回 `None`。保留原有 50/50 意图：divider 单元格从第二个子窗格的份额中扣除，`first`
保持过去 50% 分屏得到的宽度。

叶窗格不绘制边缘边框：位于区域边界上的边由区域外框承担，面向 divider 的边由 divider 单
元格承担。每个叶窗格在其矩形内占一行标题；窗格拥有输入时，活动叶窗格的标题使用焦点
强调样式，标题下方区域接
收终端单元格。非活动叶窗格绘制本地化的空状态，说明终端已保留并给出聚焦按键——绝不绘制
伪造的 live 内容。divider 单元格在遍历过程中收集，最后按相邻 divider 单元格解析出交接字
形（`├ ┤ ┬ ┴ ┼`）统一绘制一次。

在 Client 本地 zoom（`Ctrl+B z`；session 契约见 `native-tab-session.md`）下，绘制
集合收缩为焦点叶窗格：它在整个内容区渲染并记录唯一的 pane 命中区，而未绘制的叶子仍按
其规范叶矩形上报，使其 viewer 保持存活。焦点叶子向线上上报整个内容区，使其终端收敛到
放大尺寸；zoom 中不绘制 divider 单元格。绘制/命中集合与观测集合的这一分离是 zoom 唯一
的几何效果——规范投影本身不变。

捕获输入的界面将窗格的焦点强调替换为未聚焦边框与次要标题样式。参考浮层保留窗格焦点，
并使用未聚焦边框。侧栏分组标题使用主要文字加粗，不使用焦点颜色。
Windows 的 Machine 选择器与 Worktree 草稿拥有输入时，也会取消窗格焦点强调并隐藏终端光标。
Session 状态只为图标着色，正文使用主要文字样式。
已就绪状态使用已有成功样式，其他阶段保留警告样式。
实时及保留的终端单元格共用主题默认配色投影：带默认标记的前景与背景跟随主题，
程序显式设置的颜色保持不变。

## 降级顺序

遵循 `docs/tui/layout.md`：先丢弃可选上下文文本，缩短提示标签，丢弃提示标签但保留模式指
示，侧面板解除停靠，隐藏侧面板，截断标签。上表把这些步骤绑定到具体行列配额，任何
surface 不得跳步。

## 调整大小

每一帧都按实时宿主矩形重算投影。宿主至少 4 列 3 行时，退化的终端区域仍得到非零内部投
影，会话循环得以存活，小尺寸界面保持可退出；低于该下限时的 last-valid 几何保留属于环境
切片的职责。

包内私有的[完整帧观察器](../tests/support/tui_observer.rs)由 Linux PTY 进程测试与
[跨平台观察器测试](../tests/tui_observer.rs)共同使用。修改帧语法时运行

## Tab 元数据标注

固定 Tab 使用本地化 `Pinned`／`固定` 标注。Windows 紧凑标签栏绘制独立的彩色组标题、展开标识及成员数量；
展开成员保留普通 Tab token，折叠标题标识组内活动成员。导航器仍提供每个规范 Tab 及其分组标注。
文本沿用既有清理器和字符单元宽度预算，已绘制宽度定义准确的 Tab／分组鼠标区域。
显示标注不会成为原始名称或自动序号。[Tab 分组契约](native-tab-groups.zh-CN.md)拥有展开、配置及跨宿主能力覆盖。

待创建行与正式 Workspace 行预留相同的非空配置 token 行，包括尚无内容的元数据行。迟到的 Git 信息填入这些位置，不移动相邻条目。标题留白仅由可用高度决定，不随元数据就绪状态变化。样式规则可以隐藏文本，但不删除其所在行。

## 侧栏符号说明

F1 包含当前上下文、未读变化、展开折叠及所有 Agent 状态的符号说明。悬停侧栏行时，在预留的侧栏页脚解释其标记。与工作区名称相同、或同一规范目录及分支重复的分支文字省略；分支差异和过期观察仍保留显示。配置的元数据行在此投影中保持高度。

## 快捷键发现范围

帮助默认展示常用操作及当前模式控件。Tab 或已绘制的范围按钮展开全部操作与侧栏符号说明；重新打开时回到常用操作。非空筛选始终搜索全部操作。分组保留声明顺序。每组内按单词前缀匹配且不区分大小写，标题匹配优先于按键和别名匹配；中文还支持连续子串匹配。帮助名称明确操作对象并统一使用面板术语，区分面板内的终端。PageUp/PageDown 与页头箭头按已发布的可见行数翻整页；滚轮和方向键移动一行。切换范围或筛选会撤销旧绘制权限并重置滚动。页脚说明页头按钮含义。

侧栏图例将展开控件的符号标为“已展开”和“已折叠”。帮助首次成功绘制前使用八行的有界导航估计；绘制后按发布的容量翻页。
