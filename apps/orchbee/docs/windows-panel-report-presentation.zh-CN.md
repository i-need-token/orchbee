# Windows Panel 上报展示

## 范围与归属

原生 Windows TUI 读取当前 Tab 主 Panel 的终端 Agent 上报和 Panel 元数据。这些观察补充面板展示，不创建规范 Agent 会话、不改变 Agent 面板、不确认关注状态，也不授权终端输入。Server 的上报和元数据负责人仍是权威。子 presentation 不继承主 presentation 的上报。

UI 拥有一条独立 Client 连接的读取通路，复用既有 Agent 读取通路的取消和汇合设施。绘制和键盘处理不执行网络 I/O，上报读取失败不能使终端输入连接退役。每轮绝对期限五秒，冷却一秒；最多一轮在途。范围受 Workbench 上下文节点上限约束，编码行总量上限 8 MiB。

## 一致观察模型

范围包含精确 Site、Workbench 修订号、有序 Panel ID 及其主绑定。先读取全部元数据批次，再读取全部 Agent 上报批次，最后用空读取校验两个独立修订号。每份应答必须匹配范围修订号、请求的 Panel 及绑定。元数据守卫使用同一轮真实上报的 Agent 和权威来源。修订变化、绑定畸形、行缺失、超限或部分读取均整体拒绝。

| 事件                                   | 结果                                         |
| -------------------------------------- | -------------------------------------------- |
| 新 Tab、绑定、Site 或 Workbench 修订号 | 立即移除旧范围观察，开始新的有界读取         |
| 完整关联轮次                           | 共同发布上报及有效元数据                     |
| 常规刷新在途                           | 保留该精确范围上一份完整观察                 |
| 读取失败或过期                         | 隐藏旧上报派生文本，标明状态不可用           |
| 旧 epoch 或旧范围回执                  | 丢弃，不改变当前视图                         |
| 退役、替换或 Drop                      | 中断、断开并汇合自有读取通路，不遗弃工作线程 |

渲染器再次核对当前绑定。只读观察不改变选择、焦点、布局、控制权、历史位置、终端几何或规范关注状态。仅主 presentation 的边界与既有公开 Panel 读取 API 一致；子状态需要另有精确 presentation 范围的观察。

## 标题栏行为

显式自定义 Panel 标题优先，其次是受守卫约束的元数据标题，再其次是既有创建／展示标签。状态标记采用元数据 displayAgent 或真实上报 Agent，并使用对应的受守卫约束状态标签，缺省使用本地化的 idle／working／blocked／unknown。全局元数据 token 以字面键值文字追加在标题之后；宽度限制可能隐藏末尾 token。缺少上报 Agent 时不虚构 idle 或规范会话。

状态标记最多保留标题栏一半宽度，避免长标题隐藏阻塞状态。状态词放在 Agent 名称之前，只有状态词使用语义状态颜色。剩余标题和 token 遵循既有显示单元截断和主题分隔符；用户字符串均经过终端文本净化。加载和不可用状态提供英文、中文文案。单面板与放大面板使用现有外框标题，分屏面板使用现有叶节点标题栏。Minimal 层级保留现有的无边框单面板显示。既有鼠标命中区域及标题栏高度不变。

## 验证与交付

证据必须覆盖两个修订号校验、身份变化、旧 epoch、取消、事实缺失、元数据守卫、全角／控制字符、窄标题栏及真实 Windows 原生 TUI 对实时上报变化的观察。渲染与进程证据不认证 provider，也不证明最终产品对齐。交付匹配 cohort；源码／cohort 回退即回滚。不改变线协议版本或持久迁移。全量回归继续推迟到 Windows 对齐全部实现完成。

原生导航选中已绑定子 Presentation 时显示其自身标签与序号。此仅主项通道对子项明确返回既有本地化不可用状态，绝不把主项报告／标题／tokens 当作子项观察。精确子项报告查询仍待集成。
