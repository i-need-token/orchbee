# 原生动作菜单

## 交互

Windows 的 `Ctrl+B F2`、`[keys].menu` 和状态栏菜单按钮打开全局动作菜单。
无修饰右键为已绘制的 pane、tab 或 Workspace 行打开菜单。打开或取消不改变焦点。
pane 内容保留配置的 `right_click = "panel"` 策略；pane 标题仍属于 Client。
Shift 手势保留外层终端旁路。Machines 保留 `Ctrl+B Shift+M`。
菜单按钮和 Machines 指示器使用独立的状态栏单元格与点击区域。
Workspace 侧栏仅对当前机器、已绘制 Site 上仍存在的准确行准入右键。
它复用现有 Workspace 菜单，打开或取消不请求机器或 context 切换。

Up/Down 或 j/k 选行；Home/End 选首行/末行；Enter 执行选中动作。左键点击已绘制
行执行动作。Esc 或点击外部取消。菜单行在内容区域内滚动，状态栏始终可见。
固定页脚显示选中行与总数（`current/total`）；Enter 提示放不下时仍保留 Esc。
菜单替换整行状态；完整、紧凑和最小提示均保留 Esc，不混入底层通知或 Machines 文字。
菜单宽度包含行标记、内边距和边框；标签超出可用宽度时按字形簇边界截断，并使用主题的省略号。
每帧按当前可用行数计算可见窗口，缩放后的首次绘制就保持选中动作可见。
成功绘制为鼠标准入提交同一可见窗口；窗口增大时填满可用行数，不改变选择。
取消或不可用通知在状态栏只显示一次，不用同一会话通知的第二份文字替换当前快捷键提示。
无法显示标题、至少一行和退出说明时关闭并给出本地化提示。菜单捕获输入期间，
终端任务继续输出。
捕获期间隐藏底层 pane 光标；取消后恢复普通 pane 投影，不改变焦点。
已知不可用动作仍以禁用文字角色显示，在每种颜色层级保留完整主题样式及其
修饰符。可以选中以阅读本地化原因；Enter 或
点击保持菜单打开，不能确认或导航。固定原因行在最小可呈现尺寸下仍保留
退出说明及选择计数。禁用选中项的状态提示不显示执行指令。

浏览没有时限：阅读、选行、重绘和激活禁用项都不启动执行计时。
确认可用动作时创建唯一的 30 秒绝对截止时间，目标导航和转交共用该截止时间；
重绘和导航回调不续期。到期撤销尚未转交的动作，不回滚已接受的导航。
目标、来源、几何、配置和捕获失效仍会取消浏览。

可用性投影既有动作 owner 的前提，不统一增加 Ready 守卫。已有目录的
Workspace 禁用目录配置；当前 Workspace 同时应用原有空状态及 setup
准入守卫。鼠标捕获已释放时禁用释放鼠标捕获。未知异步前提继续交给原 owner；
菜单不根据只读机器观察推断 Git 支持、Worker 可达性或操作结果。

Project 菜单提供已有的 Workspace 创建选择器、快速创建 Workspace、Project 重命名及
Worktree 创建/打开动作。创建选择器标为“新建工作区（选择项目）…”，因为原 owner
仍允许选择 Project。快速创建 Workspace 经由
[setup owner](native-workspace-setup.zh-CN.md#windows-快速启动-workspace) 接受准确的已绘制
Project，包括空和非当前 Project。其他条目要求明确的当前 Workspace 属于准确的目标
Project，否则保持禁用，并显示“请先选择此项目中的工作区。”。
Project 动作从不导航或代选子 Workspace。快速创建通过 ClientView 和 InputDispatcher
携带有类型的目标证明；setup owner 单独保留当前来源 context 及 desired／焦点 pane。
它在准入前核对原菜单截止时间，随后使用既有准备和表单确认预算，不对人工编辑计时。

pane 菜单提供已有分屏、缩放、键盘调整、复制、接管和关闭动作。tab 菜单提供
新建、重命名和关闭。Workspace 菜单提供快速新建、新建 tab、目录、重命名、
Worktree 创建/打开及关闭。全局菜单提供新建 Workspace、Worktree、重载、设置、帮助、
侧栏、导航器、Agent 看板、释放鼠标和分离。关闭仍打开原有确认；菜单从不代替
删除确认。设置交给现有编辑器；checkout 删除、策略编辑和自定义或插件菜单不在此界面范围内。

carrier 不可用时，全局菜单仅保留 Client 本地帮助、侧栏、释放鼠标及分离。
成员菜单要求 carrier 存活；首个会话状态到达之前也必须有已观察的几何。

## 模型与归属

用户希望无需记住快捷键即可发现并执行现有动作。

| 记录字段 | 合约                                                                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 输入     | 已绘制的稳定目标、准确 context/member/incarnation、当前动作前提、完整解码输入包、配置、单调截止时间及成功菜单绘制回执                                      |
| 数据     | 一个本地 episode、有界行与选择以及 owner 派生的不可用原因、呈现 token、冻结的已确认动作、自有导航 generation 和可选准确目标成员                            |
| 输出     | 本地捕获与绘制；通过现有 membership owner 进行有界导航；至多一个动作交给完整 ClientView/dispatcher 路径；本地化取消或拒绝                                  |
| 决策     | 现有真实捕获优先。帮助、侧栏和导航器作为不变底层保留。选择动作才准入导航，打开不导航。每个动作保留原有可用策略，不统一要求 Ready                           |
| 不变量   | 未绘制或过期时不能激活；打开/取消不改焦点；不对替代目标执行；不隐式重试；输入及决策包尾部不进入 pane；关闭仍需原有确认                                     |
| 模型     | 捕获、绘制、目标失效、自有/外部导航、取消、前提和一次动作转交的有限安全状态机                                                                              |
| 依赖     | 现有原生 membership、终端状态、输入解码器、hit map、布局、本地化和动作 owner；无新依赖、wire 或持久数据                                                    |
| 归属     | NativeUi 管准入与目标导航；确定性菜单管选择和绘制权限；ClientView 管本地视图决策；仅 InputDispatcher 应用 shell、模式和布局副作用；仅原操作 owner 执行变更 |
| 参考范围 | 当前 OrchBee 动作的可发现性，不声称完整 Herdr 菜单对齐                                                                                                     |

`MenuTarget::Project` 携带 `WorkbenchProjectId`，不使用标签或行索引。
准入冻结完整的规范 Project；仅当其 ID 与当前 Workspace 的 Project 匹配时，
同时冻结该 Workspace/Directory 来源。空 Project 和当前 Workspace 之外的 Project
仍是有效菜单目标；setup owner 准入时快速创建 Workspace 可用，其他动作保留当前 Workspace
前提。确认和转交时必须保持同一 Project 与可选 context
证明；来源改变或记录被替换时取消 episode，不重新定位。

所有对象入口适配器都传入成功绘制的 `DrawnMenuSource` Site 和 revision。
侧栏 owner 同时核对当前机器与稳定的焦点行。右键、行内可见动作入口及对象菜单键
使用同一目标。对象键仅属于明确进入的侧栏导航；终端拥有的键保持透传。
菜单捕获输入期间，调用方保留侧栏焦点，并在关闭时调和已删除的行。
菜单不另存一套侧栏焦点状态。全局菜单仍可独立使用。

| 打开时的 Project context                    | 可用性及副作用                                             |
| ------------------------------------------- | ---------------------------------------------------------- |
| 当前 Workspace 属于准确 Project             | 既有动作保留自己的前提；确认仅提供一个动作，不导航         |
| Standalone、其他 Project 或没有 Workspace   | 快速创建 Workspace 不导航地提供准确 Project；其他条目解释缺失的 context |
| Project 或捕获的 Workspace/Directory 被替换 | 确认或转交前取消；从不替换成其他子项                       |
| 取消                                        | 保留原生来源和调用方拥有的侧栏焦点                         |

## 转移与取消

| 状态 / 事件                       | 守卫及结果                                                                                             |
| --------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 隐藏 → 打开                       | 稳定已绘制来源，无真实捕获或待定手势；冻结目标与当前来源，捕获打开包                                   |
| 打开 → 绘制                       | 绘制同一 episode 和有界行；仅成功绘制确认其 token                                                      |
| 打开 → 选择                       | 移动有界选择，在重新绘制前撤销旧 token                                                                 |
| 打开 → 可用性改变                 | 刷新 owner 派生的原因，在重绘前撤销旧 token；已知不可用行不能授权确认                                  |
| 打开 → 禁用项激活                 | 保持选择和捕获，显示原因，不转交动作或导航                                                             |
| 打开 → 时间流逝                   | 保持浏览和捕获，不创建执行截止时间                                                                     |
| 打开 → 确认                       | 完整输入、当前已绘制 token 且行可用；冻结恰好一个动作和前提状态，创建唯一的 30 秒绝对执行截止时间      |
| 已确认 → 导航                     | 区分 AlreadyExact、自有 Context generation、自有 Tab generation 和准入的本地 focus；不从无操作推断准入 |
| 导航 → 转交                       | 仅自有 prepare/apply 结果授权推进；准确目标仍存在，来源和前提一致；原动作决定可用性                    |
| 转交                              | 在应用完整 ClientView 转移和 dispatcher 副作用前移除一次性意图；不重试                                 |
| 取消 / 执行超时 / 不可用          | 撤销尚未转交意图；不回滚已接受导航，不执行动作                                                         |
| 来源 / 几何 / 配置 / 覆盖捕获改变 | 撤销尚未转交 episode；外部导航保留自身语义，不能完成菜单意图                                           |

呈现 token 绑定 episode、行、几何与准确语义目标，不绑定普通 pane 输出序列。
输出可重绘底层而不取消菜单。新 incarnation、目标删除、结构来源改变、菜单无法
呈现、变尺寸或冲突捕获均撤销激活权限。

对象入口准入在冻结当前记录之前核对成功绘制 hit map 的 Site 和 Workbench revision。
Workspace 与当前 context 证明保留准确 Workspace 和主 Directory，包括 Worker 和路径；
Tab 证明保留完整投影记录。自有导航候选及最终选中目标必须匹配这些证明。
ID 未改变不能授权被替换的来源。
Context Refresh 与 Tab attachment generation 使用不同类型的导航键，数值相同也不能
结算对方的菜单意图。

打开右键 press 在普通 pointer focus/selection 之前处理。取消或转交后仍捕获其
匹配 release。菜单关闭后仍捕获整个解码决策包，包括分段序列和粘贴。释放鼠标
与缩放在转交前检查冻结前提。
每条菜单关闭或转交路径也捕获已轮询输入，直到发布新帧。已有 pane press、选择、
链接、分隔线拖动、待定 focus 或排队 wheel 流会拒绝菜单准入，继续由原 owner 处理。
仅按下前缀会保留分隔线拖动，直到选定动作；选定的非菜单动作保留原有取消行为。
失去焦点或真实新同按钮 press 会使未上报的打开 release 过期，避免吞掉以后属于
程序的 release。

目录配置暴露与 setup owner 共用的纯拒绝查询。准确冻结的 Workspace/Directory
记录允许在不导航检查非当前目标的前提下，确定其已有目录。键盘或鼠标确认之前
以及转交之前再次查询准入。可用性改变使绘制 token 失效；目标/来源失效仍按
既有规则关闭 episode。

## 正确性与验证

`formal/tla/NativeActionMenus.tla` 在两个 episode 和目标、几何失效、自有/外部
导航、既有捕获及包边界内检查有限安全性。不声称公平性或无界进展。核心测试检查
绘制权限、选择边界、重复激活、取消及支持重放和失败缩减的生成事件序列。原生集成测试把自有
generation 映射到已接受 membership 回调，输入/渲染轨迹把捕获和几何映射到 TUI。
`BrowseTimePasses` 在打开阶段停顿；`ExecutionExpires` 仅取消已确认、导航中或待转交的 episode。
注入时钟案例区分浏览时间与唯一的执行截止时间。该抽象描述到期准入，
不描述真实墙钟时长或 carrier 调度。
`project` 行类别精化捕获的当前 Workspace 前提：`OpenProjectCurrent` 准入该 context，
`OpenProjectOther` 表示空 Project 或非当前 Project。`projectQuick` 允许两种目标并保留发起
来源。两种 Project 行均不能使用任何 `Admit`
转移；`NoProjectNavigation` 检查这一限制。它们复用 `AlreadyExact`、禁用激活、
来源失效和一次性转交。抽象不建模 Project 标签、目录或成员记录；确定性测试检查这些证明。
`projectQuick` 扩展及其 setup 交接用例已经源码审阅，但没有已执行的 TLC 或原生测试结果；
先前菜单证据不能证明新增目标行为。

| 所属声明                                              | 抽象映射                                                                              | 可执行证据                                                               | 边界                                                       |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------- |
| 禁用动作不能导航或转交                                | `available` 守卫 Confirm/Handoff；DisabledActivation 保持状态；可用性改变撤销绘制权限 | 菜单核心生成轨迹及禁用键盘/鼠标激活测试；NativeUi 目录及鼠标前提测试     | 两个 episode 和目标；仅已知 owner 拒绝                     |
| 侧栏右键保持焦点及端点身份                            | 既有 Open 来源/目标冻结及来源失效                                                     | 当前/外部机器、Site 不匹配、行缺失及取消的已绘制侧栏鼠标轨迹             | Windows 原生侧栏；打开时不切换                             |
| 短菜单仍能解释拒绝原因                                | 选中不可用原因投影同一准入值                                                          | en-US/zh-CN 完整、紧凑及最小尺寸渲染轨迹；真实 Windows Terminal 截图     | 截图用于视觉发现及验收，不代替模型精化                     |

渲染检查覆盖 en-US/zh-CN、终端原生/RGB 主题、宽字符标签及标准、紧凑、最小和
无法呈现尺寸。原生 Windows ConPTY 验证主流程，不打开或聚焦用户 Desktop 窗口。
真实 Windows Terminal、特定 provider 会话和完整历史模型集属于单独证据。

集成仍需现有完整仓库检查。菜单测试不替代原动作、确认、Worktree 或剪贴板证据。
