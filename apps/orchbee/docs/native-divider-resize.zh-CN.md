# 原生分隔线调整

## 合同与所有者

原生 Client 可用无修饰左键按住已绘制的 pane 分隔线。按住期间，每次已绘制的移动都会改变实际 pane 布局及物理控制者的终端尺寸。松手只把最终比例接受到共享布局一次。比例仍为 10%–90%，跨 Client 共享，并由现有 checkpoint 所有者保存。[原生键盘调整](native-keyboard-resize.zh-CN.md) 继续提供键盘入口。本能力遵循[鼠标输入](../../../docs/zh-CN/tui/mouse-input.md)，不增加协议、存储格式、输入接管或存活进程恢复。

`PointerState` 拥有一个可撤销的 `DividerDrag`。`tui_layout` 拥有确定性几何及不可变的 `DrawnDivider`：Session、终端上下文、Tab、焦点 panel、Workbench revision、split、有序 slot、原比例、方向、split 区域、已绘制分隔线和 viewport。渲染器只在最后成功帧记录可见分隔线。缩放、折叠和没有框架的 split 不暴露调整目标。按下、移动、空闲和松手时的原生检查须与完整规范来源一致。拖动另存最后成功绘制的草稿目标；自身完成帧只推进该凭据，不改变按下原点，帧前多次移动仍使用上次成功凭据。规范焦点、revision、几何、捕获变化或命中图缺失／不匹配会取消草稿，绝不重新指向另一条分隔线。

解码 `MouseEvent` 的 cell 坐标是不可信输入。只有无修饰左键按下能准入；左键移动和左键或通用松手继续手势，即使已经离开原区域。Ctrl 或 Alt 不能替换已准入的所有者。其他按键和滚轮不能替换手势。Shift 取消预览，仍由 Host 拥有。纯 `DividerDrag::update` 把 split 轴向位移除以可分配 cell 数，加到原比例并限幅。垂直于轴的移动无效。零位移保留原浮点值的精确身份。松手独立投影其最终坐标，不依赖最后一次移动事件。预览复用最小 pane 尺寸投影；小视口中预览线可能在名义比例到达极限前停止移动。

输入端口返回准入或可见的忙碌/失败提示，并只接受一次有变化的松手比例。`NativeUi` 重新核验选中规范缓存和几何。只读 `ResizeProjection` 为绘制、指针区域及终端尺寸观测使用同一个树投影器。只有物理控制者发送终端调整，局部草稿不授予新权限。规范布局查询及 CAS 准备从不消费草稿。首帧及刚切换的界面在发布前初始化控制所有者；每次绘制观察规范 viewport，不额外执行控制 tick。shell 在绘制变化草稿前观测有效 pane 尺寸；自身投影不算外部宿主几何变化。

`ClientControl` 拥有键盘和鼠标共用的唯一局部异步确认：原选择、请求身份和截止时间。其通道原子区分暂态积压与已停止或失败的所有者；空闲时准入被拒也保留可见提示。它只提交一次现有精确 split 比例 CAS，等待规范发布和兼容的成功绘制，不生成远端回执。松手把显示租约交给该待处理操作，在发布延迟期间保留最终可见几何。规范发布直接接替，不再添加位移。拒绝、结果未知、到期、中断、所有者／捕获丢失或外部几何变化永久退役该租约；旧条件恢复也不能复活。已提交修改仍遵循现有完成策略，不重试，也不声称回滚。[共享 split 比例](../../orchbee-server/docs/shared-split-ratios.zh-CN.md) 拥有 Server 修改及持久化。

渲染保持纯函数。反馈只为实际移动后的分隔线设置样式，保留交接字形及相邻终端单元格。悬停和按下的分隔线使用已评审的共享交互 surface。显示局部草稿几何时抑制图形及位置回执。若候选帧不再暴露精确投影目标，shell 会在同一次 flush 前恢复规范帧和图形。按住时，本地化状态说明松手与 Esc。已绘制草稿拥有状态栏尾部：关闭的机器入口暂时隐藏，草稿结束后恢复；已打开的机器选择器仍保留正常捕获优先级。隐藏入口时同一帧退役其指针区域，拖动或松手跨过原区域仍由分隔线所有者处理。

## 转移与决策

| 状态/事件                                                  | 条件及结果                                                     |
| ---------------------------------------------------------- | -------------------------------------------------------------- |
| Idle，无修饰左键按下                                       | 可见来源精确且修改通道空闲：保留来源和按下 cell，显示预览      |
| Idle，修饰键/其他按下                                      | 不拖动，不发送 pane 字节或修改                                 |
| Preview，移动                                              | 规范来源及自身绘制凭据一致：实时投影 pane 布局及控制者终端尺寸 |
| Preview，自身帧成功                                        | 保留不可变按下来源，只推进已绘制草稿凭据                       |
| Preview，无变化松手                                        | 局部结束，不修改、不增加 revision、不分配请求                  |
| Preview，有变化松手                                        | 先丢弃手势，再一次交接精确 CAS，等待现有局部确认               |
| Preview，Esc/Shift/命中图丢失/捕获/导航/外部 viewport 变化 | 恢复当前规范显示，不修改、不延迟重放                           |
| 提交中，再次按分隔线                                       | 消费并提示忙碌，不保留新拖动                                   |
| 明确拒绝/模糊结果                                          | 可见失败/结果未知，不自动重试                                  |
| 提交中，发布延迟                                           | 在原来源／截止时间租约下保留最终松手几何                       |
| 已知提交、发布及兼容绘制                                   | 规范显示接替；局部完成                                         |

普通 pane 鼠标跟踪、选区、滚轮归一化及 Host 捕获租约仍由现有所有者管理。没有已准入拖动的松手无效。绑定和 overlay 可取消预览，但不能提交它。ReadOnly Client 可以改变共享比例，手势不会授予输入或终端尺寸权限。

## 正确性与维护

所属实现测试覆盖命中几何、跨成功草稿帧的两次按住移动、规范来源隔离、合并最新意图、中断、一次提交、CAS 冲突、延迟发布显示及发布/绘制顺序。侧栏实时宽度由[鼠标输入](native-mouse-input.zh-CN.md#侧栏宽度输入)管理，共用该投影生命周期。

在 `src/tui_layout/divider/tests.rs`、`src/tui_pointer/tests/divider.rs`、`src/workbench_client/client_control/tests/divider.rs` 及相邻的状态、carrier、输入和渲染套件中维护实际证据。流程具有多种结果时，使用受控完成/时钟顺序及生成轨迹重放。

运行 `cargo test --locked -p orchbee --all-targets --all-features`。此流程不另设 TLA 模型。命名／生成实现轨迹证明有界所有权及投影主张，不证明全部交错或物理终端外观。真实宿主验收须在独立松手前捕获至少两次按住移动及其中的已渲染帧，同时检查可见 pane 边界和实际内部终端尺寸。覆盖两个轴、嵌套 split、侧栏宽度、限幅及取消／退役。宿主观测不证明未测试平台。共享身份、所有权和提交协议仍由单独注册的核心模型负责。
