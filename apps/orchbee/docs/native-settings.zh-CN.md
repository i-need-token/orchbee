# 原生设置

## 交互与作用域

受支持的原生 TUI 宿主通过 `Ctrl+B F4` 打开设置。Windows 还提供侧栏设置行
和全局动作菜单。捕获输入的界面编辑本地草稿，同时窗格输出继续。
它覆盖[共享清单](../../../crates/workbench-protocol/docs/user-preferences.zh-CN.md#清单与生效时机)
中的全部通用偏好，包括启动配置和新终端回滚默认值。宿主拥有的字体、
像素指标和管理流程遵循清单中的明确边界。
原生设置 feature 将十三个共享键统一映射到各自的行、分类、控件类型、可用性、
整数单位、边界、步长和生效范围。编辑器、本地化与渲染器目前消费行、分类、控件、
可用性和有界整数事实。生效元数据用于记录并测试 feature 契约；实际应用这些效果
仍由既有领域所有者负责。来源比较、原子提交和重置行为仍由既有状态与协议所有者
负责。值、默认值与校验仍由 Workbench Protocol 拥有。

根界面将设置分为外观、终端、通知和启动配置四类。每节使用安静的标题和分隔线，
每项设置有稳定的标签列和值列。当前设置使用中性的当前上下文背景和粗体标签，
弹窗边框标明键盘所有权。布尔勾选、`~` 草稿更改标记、禁用值和选择器导航保持独立。
全部重置、重新读取、关闭和保存位于列表下方的固定操作区，不会出现在滚动的设置项中。
根界面保留一条上下文说明和一条状态行，不再持续展示通用预览段落或行索引计数。
窄界面先移除上下文说明，保留全部必要操作并使用两行固定操作；标签按显示宽度截断，
整数值保留精确内容。

`/` 或绘制出的搜索行启动全局搜索。查询最多 256 字节，按稳定的分类顺序，
要求每个词都匹配英文或简体中文分类名、标签和简短说明；值和用户填写的配置文本不进入索引。
仅保留包含结果的分类。搜索显示结果数量和明确的无结果状态。Enter 或 Tab 退出查询输入，
聚焦匹配行而不编辑它；无结果时 Enter 保持搜索。Esc 先清除正在输入的搜索或保留的筛选，
再关闭根界面。筛选保留草稿和保存来源。非空筛选下的返回按钮与 Esc 执行同一局部步骤；
标题栏关闭始终关闭整个界面。

Tab/上/下在设置和固定操作间移动；PageUp/PageDown 按页移动，Home/End 到达首个／末个焦点目标。
左/右直接在草稿中改变有限选项或有界值。Enter/空格或点击行在同一弹窗中打开有限选项选择器；
激活布尔项切换其草稿值。面包屑标明子编辑器或选择器，其简短说明和取消／确认页脚替代根界面的
内容及操作。选择器导航只改变候选项；外观候选项在本地预览，其他选项没有运行时效果。
接受后改变父草稿，取消则恢复此前的预览。
子界面页脚按完整的本地化取消／确认标签及 Esc／Enter 绑定测量宽度。两个动作无法并排时，
先为其保留两行固定区域，再分配子视口。最小选择器至少保留一个选项行，文本编辑器保留输入
和光标。确认框仅在完整本地化决策内容及两个控件都能容纳时准入；不支持的几何不发布任何控件。
预检与绘制消费同一份已解析区域。
高度紧凑时，选择器滚轮移动自己的视口，只将候选光标移到最近的可见选项；它不会接受值或移动父视口。
`Ctrl+s` 仅在根浏览状态调用固定保存操作，与按钮使用同一已绘制权限。
文本字段使用[共享的有界行编辑器](native-line-editor.md)，
包括 Ctrl+W 删词，并支持字面粘贴。绘制对完整原始值投影一次，将光标映射到可见字素边界，
移除控制字符不会使光标落入绘制的簇内部。启动配置具有独立页面，每次编辑一个字面参数，显式选择默认项，
删除配置前要求确认。进入该子页面时记录父页面的行、视口和焦点；返回时恢复这些状态，
同时保留已经接受的草稿编辑。只有自定义模式可编辑自定义颜色；Windows 不提供登录
Shell。键盘导航会显示当前行；指针滚动或界面缩放时，该行仍作为稳定的导航锚点。
设置名称保留 GUI 的英文/简体中文词汇。原生分类和键盘导航将共享清单适配到单元格界面；
GUI 行为保持不变。

自定义可执行文件为空时标记为必填。启动字段详情以两种语言说明配置、字段和取值要求。
保存失败会显示第一个无效配置字段，包括非默认配置和精确的字面参数，不改变其他草稿值、
保存基线或默认配置。返回会恢复保存位置；修正或确认移除／重置后可以再次明确保存。
编辑、移除、重置和匹配的重新读取会清除旧校验反馈。配置集合的结构错误仍使用通用拒绝提示。

完成时长阈值的微调步长为 1 秒，大步长为 10 秒；回滚上限的微调步长为
1,000,000 字节，大步长为 10,000,000 字节。步进从当前精确值计算，在所属
领域边界处饱和，不会把值舍入为步长倍数。左/右和绘制出的减/加控件使用微调；
文本子编辑器外的 Shift+左/右使用大步长。Enter 仍打开精确值有界编辑器。

设置在临时状态行上方的完整宿主视口内水平与垂直居中，参考范围包含侧栏和顶部条。首选尺寸为
92 列、30 行，并限制在该视口内；侧栏可见性与宽度不再移动弹窗。现有最小内容准入、拒绝和挂起
机制保留草稿，状态行始终不被覆盖，定位也不调整 PTY 尺寸。根组合器用例覆盖两种语言、120x40、
120x30、100x24 和 80x24、侧栏隐藏／显示以及 24／30／60 列偏好；这些是绘制与输入映射检查，
不代表物理宿主上的真实手势证据。

设置的预检与绘制消费主题的 `paired_pointer_surfaces` 投影。反色的悬停／按下回退会解析为
一组中性前景／背景配对，覆盖完整行的标签、值、标记与空白格；选择器选项和固定页脚动作
使用同一投影。单色保留一条随宿主变化的反色带。命名 RGB 表面与显式内容颜色保持原有角色。
这份局部主题副本只改变呈现，不改变命中几何、指针准入、选择、草稿或保存权限。

渲染器投影类型化的共享动作、行和值控件。标题关闭、页脚动作、各行与减／加控件
发布同一种通用的“释放时激活”交互；其中也包括可见、类型明确的禁用目标，但这些
目标不能进入按下、激活或点击穿透。普通左键释放必须匹配按下时准确且仍有效的令牌
与矩形；键盘编辑、失焦或布局变化撤销该次按下。当前指针捕获只准入按钮事件，
因此在宿主准入任意移动事件前，这些控件不声明普通 hover 反馈。滚轮仅在活动列表内
准入：每格三行，每次处理受可见高度限制，不循环，也不改变选中行、语义焦点、
草稿值或生效值。它只改变请求的视口并停止自动跟随选择。精确的 `SettingsDraw`
回执包含界面令牌、分类列表视口和实际绘制的设置／操作身份：锚点仍在区间内时保留行激活权，离开绘制
区间后则不能激活。键盘导航会再次显示该锚点；点击已绘制目标可以建立新锚点。
子编辑器和确认框保持输入归属，并提供自己的确认／取消。确认框把实际生效的
Esc／Enter 绑定放在取消／确认按钮内，使用次要颜色和常规字重，不再重复提示行。
只有未修饰的 Enter 能确认；空格只用于列表选择或文本输入，不能确认。
带显式修饰键的 Enter 和按键释放不能确认，仍支持传统回车字节。Esc 先退出
子编辑器或确认，再关闭根界面。标题关闭会关闭整个界面。只有空闲的通用草稿界面才允许在
周围空白背景上普通左键按下并匹配释放，通过同一个精确已绘制的关闭目标退出。
存在未保存更改、搜索／筛选、文本输入、选项选择器、启动配置子页面、确认、协调状态或进行中的读取／保存时，
点击外部会保留界面和当前任务。此守卫复用外部更新时冻结草稿基线的同一个活动任务判定。
移入界面、令牌过期、失焦或布局变化会取消背景手势。显式关闭与 Esc 保持既有本地退出行为；
主动关闭会隐藏已接受的保存，但不会取消它。

保存是唯一写入动作。打开、编辑、取消和缩放都不会发布运行策略。
语言、应用主题与终端默认颜色会在整个画面本地预览，包括背景界面、实时与
保留终端行以及快捷键提示。显式程序颜色和终端字节仍由程序拥有。
无效颜色文本保留最后接受的草稿颜色。关闭恢复最新已确认外观；接受颜色字段
或从启动配置子页面返回时保留父页面预览。

预览只携带外观字段。本地修改的字段覆盖到最新已确认生效外观上，不重建保存基线；
因此无关外部更新不会清除预览。同一键冲突时保留本地预览和既有冲突／重新读取门禁。
全部重置仅在确认后预览所有默认值。可见的保存处理中状态保留预览；隐藏界面会
释放预览，但已接受的提交继续。结果未知时撤回预览，直到匹配的显式读取完成。
客户端的遮盖界面使用已确认外观；设置重新成为当前捕获所有者时恢复保留的预览。
对成功绘制的
保存按钮按 Enter、`Ctrl+s` 或点击，只能消费一次授权。全部重置需要确认，在保存前仍
属于草稿；即便值已经为默认值，重置也会声明全部通用键。
启动配置页也提供需确认的单独目录重置，保留草稿中的其他设置。未编辑的
打开视图跟随已确认的外部变更；正在编辑、输入文本、处于启动配置子页面或确认中的草稿
保留原始保存基线，同时单独暴露最新已确认生效快照并提示冲突。已知冲突不能用过期来源提交。
重新读取会确认丢弃编辑并发起新读取。明确的保存失败只能从新的已绘制上下文重试。
来源过期拒绝或结果不明会禁用保存，直到匹配的显式重新读取成功；被动观察、重绘、缓存快照和
旧读取完成结果都不能清除这一要求。请求绝不自动重放。

完成子界面和搜索返回步骤后，Esc 丢弃未提交的根草稿；提交后则隐藏界面，已接受保存仍可继续。捕获的输入包/
粘贴尾部在取消及下一次重绘期间仍归该界面所有。设置界面下方隐藏窗格光标。
界面至少需要 36 列、10 行，并完整容纳本地化页脚按钮。确认框还必须完整显示
包含草稿作用域的决策文案，因此可能需要更宽。
如果首次经过判定的绘制无法满足该尺寸，本次打开的界面会被拒绝并隐藏，
同时显示已本地化的“放大窗口后重新打开”提示；已经接受的读取或保存仍以原令牌结算，且不能重新打开界面。
至少成功绘制过一帧后，尺寸不足只会暂停已绘制交互授权，同时让设置继续作为选中的恢复捕获：
非 Esc 输入会被消费，Esc 在设置所有者内关闭，因此输入不会落入窗格或下层保留工作流。
草稿、冻结基线、生效快照、子页面状态、视口和焦点锚点会保留，供下一次成功绘制恢复。
因其他所有者遮盖而缺少回执时，只撤销精确绘制授权，不能判定为几何拒绝；遮盖所有者独占
顶层捕获，设置工作流保留但不参与竞争。等待 200 ms
后显示处理中反馈。有序设置通道使用两秒交换期限，将前台请求与一秒观察
轮询串行化，关闭时中断并回收自有连接。替换后的 Session/编辑器轮次不能继承
旧完成结果。

## 领域与归属

| 记录字段 | 契约                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 问题     | GUI 与 TUI 用户编辑同一份设备偏好，不丢失更新，不产生分叉默认值。                                                               |
| 输入     | 冻结的配置身份、完整已确认快照、精确源令牌、类型化脏补丁、已绘制行回执、明确保存/重置意图。                                     |
| 权威     | Workbench Protocol 拥有值与边界；Local Session Runtime 拥有私有记录/锁/提交；原生 Session 与匹配的 Desktop 辅助程序共用该存储。 |
| 状态     | 最新生效运行值、独立冻结的草稿基线、本地更改、视口/焦点锚点与已绘制激活权、一个已获准交换，以及明确拒绝/结果不明协调状态。      |
| 效果     | 已确认快照控制运行偏好；独立的可撤销投影仅预览产品文案、界面和终端默认颜色。启动／默认值更改作用于新终端创建。                  |
| 拒绝     | 无效或不安全来源、作用域不匹配、源过期、不支持的启动选项、通道繁忙或存储不可用，均保留现有数据和已确认行为。                    |

Session 在启动时冻结原生配置身份。客户端不发送路径、原始 TOML、另一设备
选择器或任意文件写入。共享值保存在旁边有界的私有偏好记录中；旧 TOML
保留为显式一次性导入来源。Desktop Main 与 renderer 仅导入获准且尚未声明
的字段。重置声明阻止后续导入恢复旧值。参见
[作用域与持久化](../../../crates/workbench-protocol/docs/user-preferences.zh-CN.md#作用域持久化与迁移)。

| 转移             | 必需行为                                                                         |
| ---------------- | -------------------------------------------------------------------------------- |
| 隐藏 → 打开      | 读取完整快照并冻结其源。                                                         |
| 草稿 → 编辑/绘制 | 编辑保持本地，将可撤销外观投影到整帧，撤销旧绘制授权。                           |
| 草稿 → 保存      | 要求当前成功绘制，冻结非空补丁，在派发前消费提交。                               |
| 提交 → 落盘      | 锁定共享记录、比较源、校验完整候选并原子发布；保留省略字段。                     |
| 落盘 → 生效      | 仅发布已确认值；不得把磁盘回执解释成 Host 应用确认。                             |
| 外部更新         | 发布最新生效值并刷新未编辑视图；保留活跃编辑或子任务及其冻结基线，并显示冲突。   |
| 拒绝/结果不明    | 保留可见草稿与生效值；来源过期或结果不明后，必须匹配的显式读取成功才能再次保存。 |
| 几何不可用       | 拒绝尚未绘制的界面轮次；暂停并保留已经获准的界面，直至成功绘制后恢复。           |
| 取消/关闭        | 丢弃未提交编辑并显示最新已确认外观；提交后隐藏界面不能回滚提交。                 |

应用主题独立改变界面，终端颜色另行决定。应用为系统时，主机终端颜色使用外层终端捕获的
默认值，并以已解析的应用调色板回退；浅色/深色/自定义只改变默认标记，保留显式程序颜色和颜色查询语义。
禁用的前景／背景行显示实际显示颜色，而非未使用的自定义值；低色深宿主缺少 RGB 时显示
选定的终端外观。
选中即复制控制后续手势完成；显式复制仍可用。Agent 模式/全局声音控制自动
提醒启用状态，不抹去宿主投递或逐 Agent 静音策略。完成提醒对物理终端的
序列事实只消费一次，要求新鲜时间戳和最短时长，开启设置时绝不重放。
它以本地化瞬时状态和可选响铃呈现。

Agent 尾部折叠共用保留历史的读取/确认/恢复权威。它仅用精确匹配且已确认
的窗口替换经过证明的主屏幕空白后缀。过期、缩放、含图形或不可用窗口会
回退到实时网格；光标随其所属实时行移动。普通键入保持实时输入。选择、
滚动条和手动历史导航会取得已显示窗口的所有权；自动跟随不能移动进行中
的选择/导出工作。底层租约由[视口契约](native-terminal-viewport.zh-CN.md) 约束。

## 生效时机与能力边界

每个共享键都通过同一原子保存和私有记录持久化。
[共享清单](../../../crates/workbench-protocol/docs/user-preferences.zh-CN.md#清单与生效时机)
拥有值、校验与默认值。原生编辑器以本地化的行帮助说明下列生效范围：

| 键                                 | 草稿行为                                       | 保存确认或外部观察后的效果                                                       |
| ---------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------- |
| `locale`                           | 整帧产品文案预览；跟随系统使用启动时的语言环境 | 当前应用文案与后续本地化反馈；程序字节不变                                       |
| `applicationTheme`                 | 整帧界面预览                                   | 当前界面；独立于终端显示主题                                                     |
| `terminalDisplayTheme`             | 宿主／浅色／深色／自定义的默认颜色预览         | 现有实时与保留终端呈现；显式程序颜色保持精确                                     |
| `customForeground`                 | 已接受的有效颜色仅在自定义模式预览             | 自定义模式中现有默认标记前景色；选择其他显示主题时仍保留此值                     |
| `customBackground`                 | 已接受的有效颜色仅在自定义模式预览             | 自定义模式中现有默认标记背景色；选择其他显示主题时仍保留此值                     |
| `copyOnSelect`                     | 仅草稿                                         | 后续手势完成，包括已经开始的手势；显式复制仍可用                                 |
| `trimTrailingBlankRowsForAgents`   | 仅草稿                                         | 通过精确保留窗口／确认所有者作用于现有已检测 Agent；用户选择和历史操作保留控制权 |
| `agentNotificationMode`            | 仅草稿                                         | 后续符合条件的隐藏 Agent 转移，不补发；仍遵循宿主交付与各 Agent 静音策略         |
| `completionReminderMode`           | 仅草稿                                         | 后续新鲜的命令完成；需要 Shell 集成并遵循焦点策略                                |
| `completionReminderMinimumSeconds` | 仅草稿                                         | 后续完成事件以新时长阈值判定                                                     |
| `soundEnabled`                     | 仅草稿                                         | 后续符合条件的提醒；仍遵循宿主声音能力与各 Agent 静音策略                        |
| `scrollbackBytes`                  | 仅草稿                                         | 新建终端捕获上限；现有／恢复终端保留各自上限                                     |
| `launchProfiles`                   | 子页面编辑仍属于父页面草稿                     | 后续默认启动捕获目录／默认项；现有程序保留启动事实                               |

原生宿主配置属于单独获准的界面，不是共享编辑器的额外设置行。Windows TOML
更改需要显式执行 `server reload-config`（默认前缀 F5），再由客户端每 500 ms
的配置观察器接收。共享偏好独立每秒观察一次，设置关闭期间也继续观察。
两种发布都不代表所有已连接客户端已经确认应用。

| 已准入的原生配置或客户端状态                                                                                                  | 实际应用策略                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `keys.prefix`、已实现动作的覆盖、`keys.commands`                                                                              | 完整准入的重载同时更新派发和对应帮助／提示，清除待处理前缀；仅加载配置不执行其中命令         |

| `ui.window_title`                                                                                                             | 重载后实时标题订阅使用已准入模板；外层宿主标题交付仍是一项能力                               |
| `ui.toast.delivery`、旧 `enabled`、`agent_delivery`、`delay_seconds`、`herdr.position`；`ui.sound.enabled`、`ui.sound.agents` | 重载更新手动交付和后续自动反馈；已确认的共享 Agent 模式／全局声音仍具权威，保留各 Agent 静音 |
| 旧 `theme.name`                                                                                                               | 仅一次填充尚未声明的共享外观；后续 TOML 重载不能覆盖已确认的通用偏好                         |
| `terminal.default_shell`、`terminal.shell_mode`                                                                               | 重载仅改变后续启动准备；已确认的共享启动配置优先，Windows 通用配置拒绝登录 Shell             |

| `terminal.new_cwd`、`worktrees.directory`                                                                                     | Windows CLI 在下一次相关创建调用中读取；不移动现有进程                                       |
| `session.resume_agents_on_restore`                                                                                            | 仅启动时生效；重载报告 `restartRequired`，不重做恢复                                         |
| `update.manifest_check`                                                                                                       | 重载更新既有规则检查调度器；自动检查仍遵循受管发布／能力限制                                 |

`ui.mouse_capture`、`ui.mouse_scroll_lines`、Herdr 侧栏宽度字段和其他已识别但
不支持的键仍报告为不支持；加载它们不会改变客户端行为。字体、像素尺寸、
透明度和实体 Option 键处理由外层宿主拥有。剪贴板、终端／操作系统通知与声音
需要宿主支持，TUI 不能因值已保存就承诺交付。外观预览不会引起新的宿主模式、
重启、进程启动或伪造的命令完成事件。

## 正确性与证据

[浏览／选项轨迹](../src/native_settings/tests/browse.rs) 覆盖双语全词匹配搜索、值排除、
查询字节上限的原子拒绝、无结果、选择器精确单字段接受、取消外观预览、外部更改、
过期指针选项和带筛选的配置子页面返回。
[组合用例](../src/tui_render/settings/tests/browse.rs) 固定分类／标签／值的主体布局，
覆盖滚动与尺寸层级下的固定操作、移除隐藏命中区域、搜索光标和两种语言下的同弹窗选项接受。
[输入包用例](../src/terminal_input/dispatcher/tests/settings.rs) 保证查询输入与局部返回不会进入窗格输入或持久化。
这些本地导航变化不改变共享提交／发布协议。

[指针组合用例](../src/tui_render/settings/tests/pointer.rs) 通过实际绘制的设置命中映射，驱动
已准入的移动与按下报告。在原生、命名、ANSI-16 和单色主题及两种语言下，检查完整标签／值、
复选框、有界数字、选择器和页脚色带，包含禁用减号与次要快捷键文字。指针反馈保留同一绘制回执、
命中几何、选中设置与草稿值；实际宿主呈现仍需要单独审阅截图。

[编辑器预览用例](../src/native_settings/tests/appearance.rs) 覆盖每个已准入键的
精确单键保存补丁、冻结基线、子页面返回、重置、无效颜色输入、冲突投影、
结果未知和轮次回收。[整帧用例](../src/terminal_session/ui/settings/tests/appearance.rs)
使用现有原生终端，经过真实 Shell 绘制边界，覆盖两种语言、80x24／120x40
和真彩／256 色／16 色／单色能力。它们比较背景界面、默认与显式程序单元格、
取消、外部更新和客户端遮盖捕获。这些确定性证据不证明剪贴板、通知、声音或
物理模拟器交付。配置观察器用例还会在同时更新实时绑定、对应提示和两类侧栏
配置时，保留已确认的共享外观和指针释放状态。

`SettingsCommitPublication.tla/.cfg` 有界建模两个独立准备的操作系统进程
写入者、独立 Main/renderer 导入、明确编辑/重置值，以及一次不协作外部编辑。
`Acquire` 取得共享锁；`Write` 再次检查源并保留其他键。导入仅填充未声明键。
发布携带不可变的已提交快照；应用失败和响应丢失不会回滚，也不授权再次
写入。无更改回执、文件系统原语、能力发现和界面几何仍由实现测试负责。

导入捕获的源、值与声明仅在持锁期间使用。两条释放路径都将这些临时数据
重置为规范默认值；下一次导入会捕获新的读取集。这会合并仅过期输入不同
的状态，同时保留全部参与者、输入值、已尝试/完成导入、持久声明、提交、
发布和回执，以及所有允许的外部编辑顺序。

检查性质包括单写入者归属、无关键保留、迁移期间保留重置/声明、提交后发布、
完整值、不可变发布身份，以及不重放结果不明操作。负向对照移除最终源比较
和导入声明守卫，必须得到覆盖/重置值复活反例。协议一致性、存储/辅助程序
测试、GUI/TUI 草稿测试、聚焦字段的修正与受保护的外部点击生命周期、启动捕获、
终端呈现和输入测试覆盖具体边界。
真实双向 GUI/TUI 编辑、重开、重置、错误和可见效果仍是验收要求。

运行 `node scripts/tla/run-models.mjs --models native-settings-save` 及所属
Cargo/TypeScript 检查。受影响的根门禁仍为必需。
