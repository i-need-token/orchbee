# 原生首次运行引导

## 所有权与范围

Windows 原生 Client 拥有位于侧栏、不捕获输入的欢迎引导，用于在终端保持输入焦点时呈现下一步可用动作。卡片介绍新建 Workspace、通过现有 Agent 面板选择并启动 Agent、动作搜索以及快捷键帮助。卡片本身不会启动 Agent、安装软件或创建 Workspace。既有操作所有者会再次校验每个显式动作。GUI Client 保持自己的发现入口；原生前缀词汇属于 Client，因此不共享学习状态。

## 显示与交互

首次连接的原生 Client 在侧栏可用空间内显示引导，直到用户明确关闭。普通终端按键仍发送给终端。按钮与键盘绑定复用相同的 Workspace 创建、Agent 面板、动作菜单与帮助所有者。帮助提示从生效的绑定注册表生成；各动作不再重复公共前缀。默认关闭序列为配置的前缀加 F1。侧栏底部显示有效的浏览绑定，引导自身保留帮助入口。

引导在侧栏页脚上方、滚动树之外预留行，永不覆盖终端单元、不改变终端几何，也不遮盖原生图形。模态界面、前缀提示、侧栏导航和调整大小操作期间暂时隐藏引导，至少保留四行导航树。侧栏可用区域至少 24 列、15 行时，以七行显示全部动作；较小区域至少 18 列、八行时，以四行显示帮助与关闭。否则不绘制引导，既有键盘帮助与关闭绑定仍然可用。隐藏的侧栏可通过既有控件重新打开。紧凑、隐藏或暂时抑制均不视为关闭；从模态界面返回不会在终端上引入覆盖层。回到空 Workspace 不会重新显示已关闭的引导。

## 持久状态

状态位于解析后的原生配置文件旁，路径为 `<config-filename>.native-state/onboarding.json`。封闭的版本 1 文档包含 `version` 与 `dismissed`，上限为 1024 字节。状态属于该配置档案，可跨 Session 保持；Session 检查点、用户偏好与 Server 发布均不包含此状态位。

读取不创建文件。状态缺失时显示卡片；不可读、过大、未知版本或畸形状态会显示引导和本地化警告，并保留现有字节。明确关闭时获取现有私有缓存锁，读取并校验最新文档，再原子写入关闭状态。并发关闭是幂等操作。无效现有数据不会被修复或替换。保存失败时卡片在本 Client 内关闭，并通过本地化提示说明重启后可能再次出现。私有缓存所有者负责权限、有界读取、发布残留与句柄释放。

## 证据与生命周期

单元覆盖包括缺失与版本化状态、畸形与过大文档、两个并发关闭意图、新状态实例间持久化、保存失败、损坏字节保留、两种语言、已绘制鼠标控件、紧凑几何，以及相邻终端全部单元与鼠标所有权保持不变。渲染夹具断言显示引导不会激活 Client overlay 或前缀。受影响的原生宿主门禁负责运行这些用例以及既有输入与鼠标套件。真实终端审阅应覆盖普通输入、显式点击、关闭后重启、自定义绑定与小视口。夹具所有者在最后一个缓存句柄释放后清理私有临时目录。
