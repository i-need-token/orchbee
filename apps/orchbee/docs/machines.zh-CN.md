# 已保存的 Windows 机器

原生 Windows Client 拥有已保存的 SSH 机器配置。六个 `machine` 命令管理标签、
SSH 目标、明确的远端 Site 名称和启用状态。凭据、密钥、主机信任及 SSH 配置
由 OpenSSH 管理。参考行为固定为 Herdr
`e0507237ad8d41f60aece10d00ef29ce2339ca34`。

## 目录与状态转换

选定 Windows 配置文件旁的 `machines/catalog.json` 是私有、原子写入的
schema-version-1 文档。修订号为非负安全整数；每个配置使用随机生成且互异的
32 字符小写十六进制 ID。最多允许 64 个配置及 128 KiB。标签不能为空白、
不能含控制字符，且不超过 128 UTF-8 字节。目标不超过 1024 ASCII 字节：
SSH 主机别名、`[user@]host` 或 `ssh://[user@]host[:port]`；支持带方括号的
IPv6。拒绝密码和 shell 元字符。会话名称使用原生 Windows Site 语法，默认
为 `default`。与参考实现相同，同一目标和会话可以对应不同 ID。

| 事件           | 守卫与转换                                               | 副作用                         |
| -------------- | -------------------------------------------------------- | ------------------------------ |
| List           | 缺失目录视为空；无效数据报错                             | 只读，不创建目录               |
| Add            | 校验并检查容量；准备远端；持锁重读最新目录；追加启用配置 | 远端 Site 可能在本地提交前启动 |
| Rename         | 精确 ID 存在；标签有效                                   | 替换标签；相同值不变           |
| Enable/disable | 精确 ID 存在                                             | 设置标志；相同值不变           |
| Remove         | 精确 ID 存在                                             | 删除配置；不停止远端 Site      |

写入使用现有 Windows 私有缓存锁和原子替换。每次实际变更只增加一次修订号。
读取拒绝未知字段、无效身份、重复 ID、溢出、超大文件及不安全的文件系统对象。
损坏不会被视为空目录。本地提交失败不会回滚已启动的远端 Site。提交后的
取消保留已提交回执。

## 远端准备

Add 使用系统 OpenSSH 可执行文件及 60 秒总期限，启用批处理模式、严格主机密钥
检查、禁止转发、有界输出及进程 Job 所有权。密码提示和新主机信任应先通过
OpenSSH 处理。SSH 诊断不复制到机器 JSON 或产品错误中。Windows 远端命令
使用编码后的 PowerShell 程序，参数作为字面数据传入。

准备阶段先检查已安装 `orchbee.exe` Client 的版本、平台、协议和已接纳 cohort，
然后启动指定 Site。首个 SSH 调用结束后，第二个 SSH 调用确认同一 cohort
仍然运行且兼容，之后才能提交配置。回执独立于本地目录提交，区分远端的
`not-contacted`、`unchanged`、`possibly-started` 和 `ready` 状态。
进程结算未知会明确报告，不会通过重试伪装成添加成功。

远端安装缺失或不兼容时，不保存配置并报错。远端自动安装和交互认证仍未实现；启用配置不能证明实时连接。
重命名、启用、禁用或删除都不会停止远端会话。

## 证据与生命周期

确定性校验和变更轨迹覆盖无效输入、重复操作、容量和修订号边界。私有存储
测试使用真实 Windows 锁及原子写入。远端程序测试以真实 PowerShell 运行自有
夹具，覆盖准备失败和无效响应。这些测试不能证明真实双机 SSH/TUI 链路。
夹具及其进程 Job 由测试负责，在最后一个使用者结束后回收。

## 命令路由契约

`orchbee --machine <id-or-exact-label> <command>` 选择已启用配置，ID 优先于标签；
重名标签拒绝。前缀支持 `--machine=value`，不可与 `--site` 混用，不修改目录。
帮助始终本地显示。允许 workspace、tab、panel、Client 查询及控制、终端查询及发送、Agent 操作、
worktree、通知、运行配置、manifest 和受支持的插件操作；拒绝本地管理、安装、
TUI 和交互式终端流。

路由由原生 CLI 中继负责，不改造本地 IPC 认证。先探测远端 Windows Client，
再向其精确可执行文件发送有界版本化请求。私有中继入口再次校验 cohort、Site、
参数语法及允许命令，再用字面参数启动自身程序并持有 Windows Job。
业务操作仍由现有远端 CLI 负责，不绕过本地对端凭据认证。
终端文件及 stdin 在调用方读取一次，以原始字节传输；目录及程序路径由远端解释。
清除调用者终端及 Worker 上下文，使用显式目标或远端 Client 选择。
回复保留原始输出、诊断及退出码，不把 SSH 诊断重建成业务结果。

探测及本地输入分别限时 60 秒。执行遵守命令自己的期限，含显式 forever 等待。
取消时结算本地 SSH Job，但发出请求后丢失传输无法证明远端进程已结算或业务回滚；
失败标记远端结果未知，绝不自动重试。发出前的失败标记未提交。
远端中继负责业务子进程 Job；断连仍可能留下已被接受的业务操作，不承诺分布式取消。
请求、回复及输出有明确上限，截断不能被当成成功。夹具中继测试不代表真实跨机器验收。

私有请求最多 2 MiB，回复最多 24 MiB，原始 stdout/stderr 各最多 8 MiB；
参数总计最多 64 KiB、1024 项。PowerShell 补全支持选机前缀及路由命令范围。

## 持续 TUI 连接

Windows TUI 在运行中读取已保存目录并提供机器选择器，按 Ctrl+B 后 Shift+M 打开。
不保留常驻页脚指示器。按配置身份选择，不按行号
或标签绑定；本地始终可选。禁用、删除、重名及损坏配置不能静默变成另一台机器。
已启用配置自动建立只读发现连接，只有显式选中才打开终端界面；保存的启用状态不能证明在线。
候选会话可绘制前保留当前界面；取消或失败继续当前会话。切换成功保留各机器视图，
并在接纳新输入前清除过期的鼠标及输入状态。本地始终保留，最多缓存四个非活动远端
界面；逐出只释放 Client 连接，远端 Site 继续运行。缓存的非活动界面撤销 Client 控制、
通知及外层标题订阅，返回时重新建立并传递宿主焦点观察。隐藏界面不能宣称 Ready
控制目标，也不能确认已经可见绘制。

持续传输所有者创建私有同用户本地管道，为原生 Client 所需各条通道提供有界 SSH
字节中继。SSH 认证远端账户；已接纳的精确远端程序验证安装 cohort，只连接所选
已有 Site 的同用户管道。原生 Client 接纳及应用帧不变地经过此通道，不伪造已接纳
代数，不绕过 Server cohort 检查。远端终端输入、布局、元数据和控制仍由原有模块负责。

Client origin 持有传输守卫，拥有监听器、中继任务及 SSH Job，包含二级查询/控制通道。
每条通道缓冲有界；背压暂停读取，不丢弃字节。EOF 退役该通道，不重放已提交帧。
最后一个守卫释放时取消并加入中继任务、结算子进程。远端 stdio 适配器同样拥有并结算
二进制读写子进程 Job。断开 Client 不停止远端 Site 或终端进程；不新增端口转发、
主机密钥接受、凭据存储、远端安装或 POSIX 实现。

选择器打开时拥有键盘和鼠标输入。Escape 取消，Enter 或点击选择已绘制的精确身份。
尺寸变化或目录替换会使已绘制行失效；粘贴及关闭输入包的剩余部分不能泄漏到底层终端。
每次异步连接有独立身份及取消所有者，过期完成不能切换当前机器。

选择器标题显示当前的机器、工作区或 Agent 模式。打开时由它绘制底部状态行，
显示当前模式及直接使用的导航、Enter、Tab 与 Escape 提示，替代终端前缀快捷键提示。
编辑搜索时，状态行显示“搜索”，并明确 Escape 结束编辑，而非关闭选择器。
宽度缩小时先用简短退出提示替代完整提示，再仅保留 Escape 按键；
所有选择按显示宽度计算，提示分段保持完整。模式名称与按键不能同时放下时，只保留按键。
关闭后恢复被覆盖的终端单元格。选择器关闭时不绘制页脚或发布相应鼠标区域。
高度缩小时，可选模式按钮与 Agent 筛选摘要先让位，保留当前列表行，编辑时则优先保留原有搜索框。
两行页脚继续可见；隐藏的控件不生成鼠标区域。Tab 仍切换模式，完成搜索保留原有输入语义。

证据须覆盖二进制双向传输/背压/EOF/取消、真实辅助进程的同用户管道接纳、选择身份
及过期结果轨迹，以及渲染后的键盘/鼠标路径。本地夹具不证明真实 SSH 网络存活、
远端安装或完整双机验收。

## 自动机器发现

运行中的 Windows TUI 按 ID、目标及 Site 协调已启用配置。每个端点代际拥有一个观察器、
取消标记和最新事件槽。最多同时建立四个新连接，已在线观察器不占启动名额。轮转游标保证后续配置不会被前方持续失败的端点饿死。禁用、删除
或替换配置取消旧观察器，退役线程加入后才复用其名额。目录损坏会暂停所有发现，但不
改变当前终端界面。重命名保留连接身份。观察器不创建终端、不取得控制、不切换焦点，
也不启动 Site 或安装软件。

观察器使用已接纳的持续通道，每两秒读取原生 Workbench 快照，单次读取期限五秒。
有界摘要保留 Site/修订号、项目/工作区/Tab 数量，以及最多八个预览标签，每个标签
最多 80 个标量；另保留下述工作区导航使用的有界上下文身份与标签。新近成功读取的
原生快照才表示在线，保存配置或 SSH 进程本身
不能证明在线。超过十秒的观察标为过期，不提供连接复用。

状态迁移为等待 -> 连接中 -> 在线，或连接中/在线 -> 重连/需要处理。临时失败从
500 毫秒开始重试，翻倍至最多 120 秒；连续在线 60 秒后重置失败历史。认证、主机信任、
不支持/无效协议、安装缺失及快照拒绝进入需要处理状态，不自动重试。显式选机可请求
再次尝试。目录代际过滤所有结果，包含删除后重新添加同一 ID；单事件槽合并观察，
不积累无限历史。已接纳观察器在失败交付前保留传输；UI 清除缓存来源后确认退役，
观察器在自己的线程上清空邮箱并释放最后的传输所有权。配置数量限制观察器数量；退出时先取消所有工作者，再逐一加入。

机器选择器显示本地化连接状态及聚合概览；远端标签仅是数据，不能注入终端控制字节。
显式选择最多等待 60 秒取得新鲜观察器，复用其已接纳来源建立独立原生通道，候选可绘制
后才提交切换。失败、到期或 Escape 保留当前界面。Escape 只取消选择，已启用配置的发现
继续。重试只针对观察，不重放终端输入或 Client 变更。下述工作区模式提供合并导航，
Agent 模式补上物理 Agent 导航。来源限定的合并 Agent 视图见下文；远端引导/认证和真实网络
长期会话验收仍是独立义务。

证据须覆盖重试时间/稳定期、永久拒绝、并发、配置替换与目录损坏、合并及取消、真实
只读快照帧、过期来源拒绝和本地化概览渲染。参考范围为 Herdr e0507237 的端点管理及
已保存 SSH 传输；本地 IPC 夹具不能证明远端 SSH 认证或网络恢复。

## 跨机器工作区导航

机器选择器有机器、工作区与 Agent 三种模式，可用 Tab 或已绘制的模式按钮切换。工作区模式
合并本地最近接纳的规范导航与已启用远端的新鲜观察；每行携带机器身份、Site ID，
以及独立上下文 ID 或稳定的 Workspace/context ID 对。可空的 Project 归属是元数据，不参与选择身份。
标签与行号不参与路由。原生协议
限制每台最多 1024 个上下文；项目/工作区标签各保留最多 80 个安全标量。共享不可变
上下文数组避免每次 UI tick 复制列表。本地保留导航只是候选列表，不证明远端在线。
概览在线数量描述远端观察器；离线或过期远端上下文不可选择。改名、调整 Project 归属或重排保留选择身份；
删除会使已绘制命中失效，不能把待执行选择指向其他对象。

显式选上下文会打开独立接纳的原生通道，包括已激活或已缓存的目标机器。候选先读取
新鲜快照，并在任何附着前验证精确 Site 与上下文。该路径不会因导航而打开或创建
独立终端。消失或被替换的目标失败，不选择回退项。空上下文以 Empty 成员状态启动，
没有 viewer 或终端；切换后仍能使用正常创建动作。邮箱为空与非空启动都分配新代际。
既有独立启动仍正常打开独立上下文。每个机器候选都显式携带启动期限；远端观察期限
不会隐式成为终端启动权限。

排队选择冻结端点与目的身份。目标上下文可绘制后，候选才替换当前界面；失败、超时与
Escape 保留当前界面，不重放变更。离开本地时保留它；替换同一机器时仅在提交后释放
其旧界面。只选机器时恢复缓存所选上下文，包括空工作区与未绑定占位。

同一精确端点的定向新通道可以在释放旧界面前，从该端点的活动或缓存界面继承有界且
仅用于渲染的文本画面库。候选的新鲜规范快照按精确 Site、context、Tab、Panel、
Presentation 及 worker/terminal binding 裁剪画面库；身份冲突时采用候选自己的更新画面。
几何及任何已知 HostEpoch 仍是渲染门。交接不携带 attachment、selection、输入、
controller、feedback 或 retained-context 权限，也绝不跨越端点替换。

成功切换沿用
既有机器交接，使主机输入与已绘制
区域失效。下述 Agent 模式共用此交接；主侧栏共用下文的 Agent 投影；Agent 前后切换见下文。

证据包括先快照再精确启动、Site/上下文缺失或不匹配时在产生效果前拒绝、空上下文
成员状态、真实机器候选启动与取消、重名与本地/远端身份隔离、同端点活动／缓存画面
交接与端点替换拒绝、重排/过期命中、模式
键鼠及窄屏渲染。本地协议端不能证明真实 SSH 或真实主机视觉验收。

## 跨机器 Agent 导航

Agent 模式按需汇总本地和新鲜、已启用远端的物理 Agent 观察。每次完整读取将原生
Workbench 快照与有界物理状态分批结果关联，全部对应同一 Workbench/上报修订。
未读取、不可用、过期与成功空列表明确区分。仅有 Agent 标签的观察形成行；主及子
Presentation 保留各自身份。标签只作为过滤控制字符后的显示数据。行携带机器、Site、
上下文、Tab、Panel、Presentation 和完整物理绑定，名称与行号不赋予导航权限。

最多四个观察任务并发。每个任务拥有独立接纳通道、五秒总期限与单结果槽；读取限制
为 4096 个已绑定 Presentation 和 8 MiB 序列化物理状态、上报和元数据行，冷却两秒。最后一个 Agent 读取消费者隐藏时取消未完成任务。
来源删除、禁用或被替换时丢弃结果；新鲜度从工作者完成时起十秒后到期，
包含等待 UI 消费结果的时间。只有显式激活才打开终端。
候选重新验证所选快照和物理检查点，直接启动精确成员，在取得控制前核对返回的 Host
身份，不先创建独立终端或附着第一个面板。失败、取消及目标被替换保留旧界面；提交
仍要求内容可绘制。不重放终端输入或变更。

证据须覆盖有界完整读取、修订/成员/物理身份不匹配、主子成员位置、过期任务取消和
公平调度、键鼠身份、精确启动及控制前 Host 身份拒绝。实时终端标题 token 及真实 SSH/系统视觉验收仍是独立义务。
Herdr 的列表与聚合侧栏枚举物理 pane，不枚举未附着规范会话。原生 Agent 会话列表与
单 Site 看板已有这些会话；跨机器聚合它们属于架构扩展，不计为替换缺口。
现有单 Site Agent 看板仍可使用。

## Agent 元数据、视图控制与导航

Agent 列表仅在重叠的稳定读取区间内关联物理状态、Agent 上报以及独立所有者的元数据：
各批次对应同一 Workbench 修订、精确成员/父面板/终端绑定，各读取所有者有一致修订。物理状态与 Agent 上报读取共用上报修订；元数据拥有独立修订。
全部初始批次读取后，依次用元数据、上报、物理状态栅栏确认版本。失败、成员缺失或
修订变化拒绝整个观察。全部读取共用既有期限、行数及序列化状态字节上限。
真实 Agent 与权威来源事实约束有效元数据；显示标题/提供方/状态标签及 token
不替换物理导航目标。

Client 拥有临时状态/范围/排序/搜索控制。`f` 循环状态（包括 Done），`c` 循环全部/当前机器/当前上下文，
`s` 循环位置/优先级/提供方/标题/状态序号，斜杠编辑最多 128 个安全标量的查询。
Enter 或 Escape 先退出查询编辑；Ctrl+U 清空。已绘制控制支持鼠标激活。
过滤包含安全的机器/位置/标题/提供方/token 文本。同排序值保留规范位置顺序；优先级
依次为受阻、已完成、工作中、空闲、未知。状态序号是上报版本，不是跨机器时钟。
缺失观察与无匹配结果区分。数据、上下文或控制变化使已绘制激活身份失效。

Ctrl+B 后 `{` 或 `}` 请求跨机器上一个/下一个 Agent；可配置的
`previous_agent`/`next_agent` 动作共用同一投影器。八秒意图等待有界观察，按精确
当前成员环绕；当前成员不在列表时选最后/第一个，排除不可用行。空列表或唯一目标
已经聚焦时不产生附着。后续按键或指针输入取消待执行意图。实际激活仍使用独立接纳、
重新验证且可绘制的候选，失败保留旧界面。

证据覆盖元数据条件、重叠修订栅栏和绑定错误、稳定并列与机器限定上下文/身份、查询
边界及控制取消、已绘制键鼠/窄屏/本地化和全局动作输入隔离。实时终端标题 token 及真实网络/系统视觉验收仍是独立义务。

## 来源所属的 Agent 视图

`agent view set --spec <json>`、`agent view clear [--source <name>]` 和
`agent view get` 操作所选 Windows Site。Server 拥有一份临时且带修订号的
规格：最近一次有效设置替换旧规格；不带来源的清除直接移除，指定来源则仅
移除精确匹配的规格。重启移除覆盖。读取需要读取权限；修改需要导航管理权限。
无效、拒绝或不可用的操作保持旧规格。请求交接后不自动重试修改；丢失修改回复
报告结果未知。读取或提交前交换失败使用独立的 `exchange-failed` 回执，不冒充
服务端拒绝或未知修改。插件来源使用 `plugin:<id>`，要求插件已安装且启用；下次读取
会清除已禁用或移除插件的视图。其他来源名表示归属，不是认证凭据。

规格包含 `source`、可选 `label`、可选 `filter` 和可选 `sort`。来源去除首尾
空白后须为 1–120 个 ASCII 字母数字或 `:._-` 字符；标签去除首尾空白和控制
字符后须为 1–32 个标量。规格编码上限 64 KiB，同时限制字符串操作数。
过滤器 `op` 支持 `all`、`any`、`not`、`eq`、`in` 和 `exists`；分组非空，
最多八层、64 个节点及 32 个 `in` 值。字段为 `status`、`workspace_id`、
`tab_id`、`pane_id`、`agent`、`seen`、`state_change_seq` 或
`{ "token": "name" }`。值使用字符串，`seen` 使用布尔值，序列使用完整 64 位无符号
整数；对应 ID 字段还可使用 `{ "context": "current_workspace_id" }` 或
`current_tab_id`。状态允许 idle、working、blocked、done 和 unknown。

最多八个排序项包含 `field` 和可选 `order`（默认 `asc`，或 `desc`）。
字段为 workspace_order、tab_order、pane_order、attention、status、agent、
seen、state_change_seq 或 token 对象。Token 名为 1–32 个 ASCII 字母数字、
下划线或连字符。值比较不做显示清理；无论方向，缺失值排最后；全部相等时
保持规范位置顺序。关注优先级为 Blocked、Done、Working、Idle、Unknown。
序列是观察版本，不是共享时间戳。

当前机器稳定的来源规格过滤聚合列表和全局 Agent 循环；其他机器的覆盖
不会叠加。ID 操作数和当前上下文值由当前机器限定。Workspace ID 为原生
工作区身份（独立终端缺失），Tab ID 为原生 Tab 身份，pane ID 为精确
Presentation 身份，包括子 Presentation。位置顺序来自快照的工作区、Tab
和窗格有序位置。缺失上下文操作数按缺失比较，包含参考实现的缺失等于缺失
语义。界面预设和搜索进一步收窄来源过滤；显式来源排序优先，排序控件说明归属，否则采用界面
排序。物理检查点前读来源规格，之后读取栅栏；来源变化或不可用不等于空覆盖。

Seen 属于本 Client。首个完整端点检查点建立已查看基线；新增或改变的绑定
版本为未查看。Idle 加未查看投影为 Done。现有原生关注状态提供来自可见
终端绘制或显式聚焦的精确绑定／版本确认。列表、过滤和普通读取不能确认
终端。端点替换／重启或物理重新绑定不能继承其他身份的确认。

投影复用未改变的来源检查点，每批关注状态仅协调一次。私有绘制版本戳由当前
机器限定，Client 交接使其失效；新 Client 不能继承相同计数器。最后一个 Agent 读取消费者隐藏时释放缓存行／规格；有界的绑定版本确认仍归 Client 所有，移除／禁用的
来源会被清理。

证据覆盖规格边界／类型拒绝、按来源替换和清除、插件资格、修订和传输未知、
端点限定上下文、缺失／相等多字段排序、完整视图栅栏和精确关注版本。
实时终端标题 token 和真实 SSH／系统视觉验收仍是独立义务。

## 按序号聚焦 Agent

Windows `[keys] focus_agent` 接受配置的 `1..9` 数字或范围，支持前缀／直达
修饰键及显式禁用，默认未绑定。匹配的绑定数字选择前后切换所用同一当前来源
过滤、稳定排序的聚合列表中对应的零基条目。前九个有效 Agent 行显示相应数字；
加载中／不可用／空列表提示不占序号。配置后的快捷键帮助在两种语言中显示实际
触发键，包括禁用绑定。旧终端的 Shift 数字符号解析为绑定数字；精确配置的
符号绑定优先于这条兼容路径。

既有八秒意图等待加载中的观察。未知当前来源仍明确拒绝；不存在的序号既不
环绕也不截断，已聚焦目标不附着。后续输入取消待处理意图。解析后选择冻结
精确端点／成员身份，并使用与鼠标和前后切换相同的重新验证、可绘制候选流程。
选择或读取序号不能确认终端已查看。

证据覆盖按键／配置序列化／冲突接纳、完整修饰键分派与输入包尾捕获、覆盖层
优先级、来源过滤后的编号、加载、不存在／当前目标、取消和精确跨机器身份。

## 主 Agent 侧栏

Windows 主侧栏按精确 Machine／Site／Context 关联 Agent 选择器中的可用投影，
将 Agent 显示在所属 Workspace 或 Standalone 行下面；标签不决定归属。
当前机器的来源视图和 Client 本地状态、范围、排序及搜索继续决定可用性。
即使其他父行已折叠，前九个可用条目仍保留全局筛选列表序号。当前聚焦的物理成员有标记。
[侧栏导航](tui-shell-layout.zh-CN.md#侧栏导航模型) 拥有展开状态和共用树形窗口。
标题中的筛选动作进入现有 Agent 选择器，提供键盘导航、筛选、搜索、来源状态和完整详情；
配置的选机快捷键加两次 Tab 也可进入同一模式。读取中、不可用、空列表及无匹配占位信息
保留在选择器中，不成为嵌套 Agent 行、序号或导航目标。
侧栏行属于导航条目：鼠标左键按下后冻结绘制时的
机器、成员和物理身份，重新核对可用性，再启动已有的复核及可绘制候选切换。
当前目标无需重新附着；已变化、删除、禁用或不可用的身份不会跳到替代行。
其他按键、修饰键、释放及拖动不能激活条目。

侧栏使用 Shell 的 Full/Compact 有界宽度，在 Minimal 或过小窗口隐藏。默认 Agent
条目占两行，配置条目使用解析后的高度与间隔；优先容纳完整条目，单条超过正文高度时
裁剪到实际视口，横向按字素安全截断。共用页脚显示树形列表的可见范围，并打开 Workspace
选择器。窗口跟随键盘焦点或精确可见的当前 Agent，后备目标为其 Context；手动滚轮固定
窗口，直到聚焦或筛选变化。滚轮每格排队三个条目，在输入节拍合并，每次最多应用
一个已绘制视口的条目数；方向反转取消旧队列余量。覆盖层、模态输入及释放鼠标捕获仍优先于
侧栏手势。成功绘制后发布与绘制一致的区域，调整窗口大小使旧区域失效。

可见侧栏或已打开的 Workspace／Agent 选择器模式都是读取消费者。共用收集器沿用已有机器、时效、
期限、行数、字节及取消边界；仅关闭选择面板不会停止可见侧栏刷新，最后一个
消费者隐藏时释放来源行和视图，并取消读取。侧栏绘制、滚动及打开列表不确认
终端版本。即使 Wide Client 因高度不足自动将侧栏浮动，几何上的侧栏覆盖层也会
阻止终端绘制确认。实时终端标题 token 和真实 SSH／模拟器视觉
验收仍属于独立工作。

## Agent 侧栏配置模型

Windows 用户通过 `ui.sidebar.agents.rows`、`rows_by_agent`、`row_gap` 选择侧栏内容。
共享 Windows 配置所有者接纳整个有界文件及最多 32 KiB 的封闭规范 JSON profile。
已有 Site 配置所有者与键位、通知策略一起发布；只有 Client UI 所有者安装完整验证
的新版本。致命来源错误保留全部已安装设置。无效的已配置侧栏 profile 使用安全默认值、
产生警告并继续作为完整候选原子发布；畸形私有线协议 profile 在 Client 安装前拒绝。
渲染器不读取配置文件、不启动后台工作。

行内容接受 `state_icon`、`state_text`、`machine`、`workspace`、`tab`、`pane`、`agent`
、`terminal_title`、`terminal_title_stripped` 和 `$name`。缺失或被规则隐藏的 token 消失，无剩余 token 的行消失；条目仍保留
焦点标记、序号、精确目标及导航资格。自定义值与状态文字来自已受版本和身份保护的
展示元数据。规则匹配原始值，仅绘制阶段清除控制字符、按字素截断。
`terminal_title`、`terminal_title_stripped` 使用下述实时物理标题观察；
pane 标题和 `$terminal_title` 不冒充这两个内置值。

默认行在序号和状态字形旁显示有效呈现标题，下一行显示 Provider 和本地化状态。
清理后标题为空白时回退到 Provider；Provider 与标题相同则不再重复。父 Machine／Workspace
信息保留在树形层级中，不在各 Agent 重复。Provider 文字先于状态文字收缩；
截断后不足两列前缀加省略号的 Provider 省略；能完整显示的短 Provider 名称仍保留。
状态颜色只用于字形，状态文字使用主要文字角色，不继承 DIM。

| 输入或事件                         | 决策与可观察结果                                                     |
| ---------------------------------- | -------------------------------------------------------------------- |
| 未设置行且没有匹配覆盖             | 使用标题优先的双行默认                                               |
| Provider 覆盖                      | 先匹配物理 Agent 标签，再匹配其规范报告标签；displayAgent 不选择布局 |
| 空行、缺失自定义值、隐藏规则       | 移除配置文字，至少保留身份行及精确点击目标                           |
| 带样式文字                         | 应用基础前景色/粗体/淡化，再应用首条匹配规则；`hide=true` 移除 token |
| 文字规则                           | equals/contains/starts_with 恰选一项；可选 ASCII 大小写折叠          |
| 数字规则                           | 有限 gt/lt 阈值恰选一项；严格解析有限数字，不 trim、不折叠大小写     |
| 布局或发布改变                     | 重置跟随焦点窗口及待处理滚动，不改变筛选、已读或物理身份             |
| 不同高度条目的视口                 | 容纳完整条目与间隔；单条超过视口时仅裁剪到实际正文                   |
| 滚动                               | 按条目移动，每次不超过已绘制条目数；按实际高度计算末页边界           |
| 无效的已配置侧栏 profile           | 使用安全侧栏默认值、产生警告，并随完整候选发布                       |
| 致命文件/TOML 或畸形线协议 profile | 发布或 UI 安装前拒绝，保留原键位、通知及侧栏                         |

最多接纳 16 行、每行 16 个 token、每 token 16 条规则、64 个 Provider 覆盖。
自定义键使用元数据 ASCII 语法，Provider 键使用有界原生 ID。前景色接受 `#rgb`
或 `#rrggbb`；主题所有者映射用户显式前景色及修饰，默认展示仍用语义主题角色。
非负 `row_gap` 适配 u16，仅放在条目之间。末尾空白与间隔不激活条目；绘制与输入
共用同一解析窗口和几何，包含被裁剪的超高条目。

核心证据覆盖严格接纳、规范 profile 往返、首条匹配/隐藏/大小写/数字规则、原始值
匹配、Provider 身份、缺失/空内容、末页与焦点窗口、有界/反转滚动、精确点击目标。
适配证据覆盖整个发布失败保留、真实配置 IPC、双语言/主题及短/完整高度。
可配置绘制不赋予新 Agent 权威、终端已读确认、持久迁移、网络或模拟器视觉证明。

## 实时终端标题观察模型

Agent 侧栏用户可选择 `terminal_title` 或
`terminal_title_stripped`，跟随精确物理终端的 OSC 标题。
现有 Host 元数据事件是唯一的标题写入者。Windows Worker
维护连接拥有的有界投影，以完整 Host 身份和元数据版本为键，
独立于 Agent 报告序号、视图过滤和 Client 已读状态。
关闭 Host 连接会释放投影；确认物理资源处置后删除对应条目。
缺少观察仍表示不可用，观察到空标题才表示确认清除。
两者均不以窗格标签或自定义 `$terminal_title` token 替代。

只读工作流在现有拥有的观察通道上，每批请求至多四个精确物理绑定。
Site 在 Worker 读取前后核对成员关系以及保留的 Worker、创建和 Host 代数。
Worker 每次消费至多 32 个排队 Host 事件，向持续活跃的事件流让出执行，
不附着 viewer，不申请输入或尺寸控制，
不读取终端屏幕、不启动 Host，也不确认绘制。
多个展示别名的相同精确物理身份只读取一次，再回填到各自受保护的绑定。
每个回复回显操作和物理身份；绑定变化、无效版本、格式错误和超界
均拒绝候选。标题是顺序观察，不声称所有 Host 终端的原子快照。
侧栏沿用现有约两秒的观察刷新节奏，采样原始符号，不承诺显示每个动画帧。
收集器保留现有总截止时间、取消、行数、字节以及最终成员关系、
报告和源视图栅栏。

每个 Host 连接的投影接纳至多 1024 个物理标题以及 64 MiB 标题文本；
单个标题遵循 Host 的 64 KiB 元数据上限。
独立有界 Worker 回复帧承载四个完整值，避免截断原始值。
较新元数据替换旧值；完全相同的重放无操作；版本倒退、同版本变化
或终端身份复用均无效。Client 从同一观察绘制原始和去动画形式。
去动画处理移除一个 Windows 提权前缀以及至多一个后接空白的已知
活动符号，保留 Unicode 文本。规则在显示净化与字素截断前检查所选
原始形式。仅标题变化可改变行高并取消旧几何下的待处理滚动，
但不会改变 Agent 注意力或导航身份。

核心证据覆盖缺失与清除、版本单调性和重放、身份替换、有界帧与精确
回复关联、去动画、原始值规则及自定义 token 区分。
适配器证据覆盖实际 Windows 元数据事件和管道、Site 读取前后物理栅栏、
收集器取消与渲染。这些展示 token 不引入新的公开 CLI 命令、
持久标题注册表、Host 协议、输入权限或独立终端确认。

## 工作区侧栏模型

Windows 主侧栏按精确 Site/context 身份解析工作区行，不按显示标签或 Agent 来源视图过滤。
配置所有者接纳 `ui.sidebar.spaces` 行与 `row_gap`，最多 16 行、每行 16 个 token。
内置值为 `state_icon`、`state_text`、`workspace`、`branch` 和 `git_status`；
`$custom` 值来自 Workspace 报告所有者。样式与首条文本规则在终端净化前检查原始值。
图标和 Git 计数 token 不接纳文本规则。缺失或隐藏值折叠行；仍保留至少一行身份供导航。

工作区状态聚合 Client 已读投影后的完整物理 Agent 观测，优先级为 blocked、done、working、idle、unknown。
Agent 观测不可用或完整轮次未包含该 context 时保持 unknown；该精确 context 的完成空观测为 idle。来源过滤与自定义显示标签不改变权威。
Git 观测来自选定 Worker 上的规范 Workspace 目录。`git_status` 是相对本地 upstream 的 ahead/behind；
不是脏文件计数，也不为不可用仓库编造零。游离或未出生分支、缺少 upstream、非仓库均明确区分。
读取不 fetch、不修改配置、不启动终端或执行插件。

Git 读取复用 Windows 自有发现槽：受检启动、轮询、取消、五秒截止时间、保留回执及子进程／管道结算。
Server 发现交换采用非阻塞队列接纳和绝对截止时间等待。晚到的受检发现回复可丢弃，
不因此退役健康 carrier；有副作用的操作仍要求送达完成结果。超时启动绝不重发。
已知 operation/job 身份只通过同一 FIFO 高优先级队列发出一次取消，不等待回复；
接纳或传输失败时，物理作业及五秒 TTL 仍由 Worker 所有。Server 不报告清理已确认。
Git 字面参数采用命令局部仓库选择，不扩大信任。Site 成员、目录及 Worker 代际在 I/O 前后检查。
分支为不含控制字符、最多 1024 字节的 UTF-8；ahead/behind 计数为 uint32。
元数据读取保留独立修订及空批次最终保护；接纳完整候选前重新核对拓扑。

Agent 与工作区观测复用有界作业生命周期，使用独立四作业池（合计最多八个），
五秒操作预算、十秒新鲜期、取消及 join 后释放。绘制无 I/O。
工作区及其已展开的 Agent 子行共用一个 Client 滚动窗口。实际行高与间隔决定焦点显示、末页、滚动刷新和精确点击区域；
每次滚动刷新最多推进一屏。身份、数据或配置改变会取消旧待处理几何。
激活重新检查精确机器／Site/context，标签不能重定向。工作区选择器提供额外的键盘导航路径。
小视口缩减可见树形列表时仍保留此路径。文字 token 分配宽度时为固定图标／Git 计数留空间；
长分支名／自定义值先缩短，避免挤掉可读的 ahead／behind 计数。

Site 将键位、通知及两种有界规范侧栏 profile 作为一个候选发布。致命来源错误或畸形私有发布
保留全部先前 Client 配置；无效的已配置侧栏使用安全默认值及警告并进入原子候选。
两个各限 32 KiB 的侧栏 profile 使用 256 KiB 配置帧，包含 JSON 转义；字段预算保持独立。
匹配 cohort 一起更新；公开版本化 CLI 文档保持旧变体封闭。
核心与适配器证据覆盖严格接纳、修订／代际替换、取消、真实 Windows Git 与管道、
null/unknown 区分、样式／Unicode 绘制及导航几何。整套 cohort 与真实模拟器／SSH 验收仍是独立证据。
