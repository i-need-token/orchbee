# TUI 设置

## 权威与范围

本规范负责 Orchbee 原生 TUI 设置的可复用组合和交互：元数据投影、类别与搜索、设置行与控件、草稿与预览状态、提交反馈、重置、冲突呈现和返回行为。设置所属的领域继续负责其标识、值语义、有效域、默认值、作用域、优先级、持久化、同步、副作用、安全和兼容性。

跨客户端含义和应用时机遵循 [`INTERFACE-DESIGN.md`](../INTERFACE-DESIGN.md) 及功能的共同契约。前端适配器遵循
[`frontend/settings.md`](../frontend/settings.md)。原生操作遵循 [`actions.md`](actions.md)，输入遵循
[`keyboard-input.md`](keyboard-input.md) 和 [`mouse-input.md`](mouse-input.md)，控件遵循
[`components.md`](components.md)，外壳几何、捕获、状态和返回遵循
[`layout.md`](layout.md) 与 [`overlays-and-status.md`](overlays-and-status.md)。

这是新增和实质性变更的 TUI 设置行为必须满足的契约，并不声称当前每项设置或每个界面都已符合。对于分阶段缺口，应记录负责人和完成条件；不得宣传尚不支持的行为。应用所有的参考文档，包括
[`native-settings.md`](../../../apps/orchbee/docs/native-settings.zh-CN.md)，仍是当前目录、协议和持久化行为的权威。

## 准入与所有权

设置是会改变后续产品行为、可持久且可再次访问的选择或策略。命令、单次任务回答、状态、诊断、迁移、凭据交换、资源集合或破坏性数据操作仍是操作或专用工作流，即便设置界面链接到它们。不得为尚不可用的未来能力显示路线图行或禁用占位符。

| 职责                                                   | 所有者                     |
| ------------------------------------------------------ | -------------------------- |
| 稳定标识、值域、默认值、缺省语义、作用域、优先级和来源 | 设置的领域所有者           |
| 持久化、同步、验证、提交、副作用和恢复                 | 现有功能、协议或存储所有者 |
| 共同术语、应用时机、效果范围和 GUI/TUI 对应关系        | 功能的共同体验契约         |
| TUI 类别、搜索投影、控件、草稿状态、预览、焦点和反馈   | 原生设置组合层             |
| 几何、视觉角色、按键解码、指针手势和覆盖层生命周期     | 对应的 TUI 适配器规范      |

元数据目录可以提高一致性，但本规范不要求一个注册表、schema、通用渲染器或新包。应复用现有所有者类型和参考文档。通用投影不得抹去领域专用的验证、说明、控件或管理任务。

## 设置投影

TUI 中显示的每项设置都要提供或引用足够的元数据，使界面无需反向推断存储记录即可渲染和操作。

| 字段         | 必须决策                                                       |
| ------------ | -------------------------------------------------------------- |
| 标识与所有者 | 稳定的非本地化键、领域所有者和允许的写入者                     |
| 位置         | 稳定类别、可选分区、本地化标签与简明说明，以及经审查的搜索别名 |
| 值           | 类型、有效域、规范默认值、单位和缺省语义                       |
| 作用域与来源 | 可编辑作用域、优先级、继承、强制策略和有效来源投影             |
| 可用性       | 平台、能力、权限、策略和依赖守卫及其原因                       |
| 提交         | 即时或原子草稿策略、验证边界、提交点、取消和恢复               |
| 效果         | 当前或未来生效、重载或重启要求，以及异常成本或外部效果         |
| 重置         | 重置是显露继承值、恢复产品默认值，还是不可用                   |
| 安全         | 本地性、敏感性、保留策略，以及该值是否适合进入普通设置草稿     |

元数据携带本地化描述符、稳定规范值和类型化边界。标签、翻译值、行位置、颜色和存储键不能代替语义标识或有效来源投影。

## 状态模型

即使一个控件同时显示多个事实，也要区分以下状态：

| 状态           | 含义                                                         |
| -------------- | ------------------------------------------------------------ |
| 已保存基准     | 原子草稿开始时的已确认值，以及来源或修订标识                 |
| 有效值         | 解析优先级和能力后，当前实际支配行为的已确认值               |
| 草稿值         | 当前设置任务所有的未提交编辑                                 |
| 预览值         | 用于判断草稿的可逆局部呈现；绝不是已持久化或领域已提交的证明 |
| 键盘游标或焦点 | 当前导航或编辑位置；绝不是已保存值、有效值或已选值           |
| 临时选择       | 选择器中在显式接受前获得焦点的选项                           |
| 等待中的提交   | 为提交冻结的已验证补丁、来源标识和唯一执行标识               |
| 外部更新       | 更新的已确认快照；它会刷新干净视图，或与活动草稿冲突         |

打开原子编辑器时，冻结完整的已确认基准和来源标识。渲染要明确投影已保存值、有效值、草稿、预览、焦点和等待状态；绝不从另一个状态的外观推断。已确认的领域更新可以改变有效值，而不移动键盘游标或临时选择。

## 界面组合与发现

多设置草稿应使用捕获型覆盖层，除非所属应用已准入持久页面或窗口。使用
[`overlays-and-status.md`](overlays-and-status.md#覆盖层组合) 中的共享槽位进行组合：稳定的任务标题、可选导航和查询、可滚动内容、状态、必要时的操作，以及固定页脚。

- 按用户目标和产品词汇组织类别，不按源码模块或存储文件组织。类别标题是定位标志，不是改变值的控件。
- 保持层级浅。集合、凭据生命周期、反复增删改任务或复杂冲突流程应打开有明确用途名称的子任务，并提供可见的返回路径。
- 子任务记录父级类别、获得焦点的设置、查询、滚动锚点、草稿和预览。返回时恢复该导航状态，并按照提交策略把已经接受的编辑保留在父草稿或领域中。它只撤销子任务中仍未接受的活动编辑或预览，绝不能用默认值重建父级。
- 包含多个类别的界面提供全局搜索，范围是当前可用设置的本地化类别名、标签、简明说明和经审查的别名。不得索引值、秘密、用户文本、隐藏能力或诊断。
- 搜索只用于导航。它保留草稿，使用确定性的全词匹配与排序，跳过没有匹配子项的类别标题，并提供明确的空结果。激活结果只展示其所在行并移动焦点，不改变值。
- 在滚动和尺寸等级降级期间，任务标识、当前返回路径、验证或冲突状态以及提交操作始终可见。当几何尺寸不受支持时，拒绝显示该界面，不能隐藏返回或提交控件。

## 行与类型化控件

一个设置行包含持续可见的本地化标签、可选的决策相关说明、有效或草稿状态、异常时的来源或锁定解释，以及能表达该值的最小类型化控件。说明用于解释后果、作用域、依赖、安全、效果范围或恢复；不得重复标签或讲解常规按键用法。

| 值或意图                           | TUI 控件                                                 |
| ---------------------------------- | -------------------------------------------------------- |
| 独立布尔值                         | 编辑已声明草稿或调用已声明即时操作的开关                 |
| 两个或更多有限选项                 | 使用稳定规范值、已提交标记和独立导航游标的选择器         |
| 有界整数                           | 带单位、边界和确定性大小步长的步进器与精确值             |
| 有界字符串                         | 带已声明验证和长度限制的单行编辑器                       |
| 颜色、主题、模型、路径或运行时目录 | 使用规范值、不可用状态处理的领域选择器；只有可逆时才预览 |
| 相关子设置                         | 打开一个子任务并在返回时恢复父级的分组行                 |
| 资源集合或凭据                     | 摘要和进入专属工作流的具名操作                           |
| 重置或破坏性操作                   | 遵循适用确认和效果契约的具名操作                         |

- 悬停、焦点和激活使用获准控件的完整几何；不得增加无标签的单元格目标。键盘和指针路径产生相同的类型化编辑或操作。
- 焦点、悬停、当前有效值、临时选择、已修改草稿、锁定状态、验证和等待状态按照
  [`visual-foundations.md`](visual-foundations.md) 保持视觉区别。
- 只有当不可用值可以解释当前行为或存在当前恢复路径时才保留显示。必须说明原因；仅用禁用样式并不充分。
- 键盘导航和已经激活的搜索结果会展示其当前行。手动指针滚轮输入只移动视口，绝不改变草稿、有效值、焦点或激活。如果滚动或尺寸变化使获得焦点的交互目标不再绘制，组件声明的策略会把焦点移到已绘制的回退目标，或在不提交的情况下放弃键盘所有权。
- 当前目录中不存在的动态解析值仍应披露为不可用或过期。把焦点放到回退选项上绝不能暗中清除已保存值。

## 草稿、预览与提交

应用时机由功能的共同 GUI/TUI 契约负责。呈现者不得从开关推断即时提交，也不得从覆盖层的存在推断原子草稿。

- 拥有原子共享草稿的编辑器只有一个显式 `Save` 边界。子编辑、开关、重置和预览只修改该草稿；导航、筛选、滚动、尺寸变化和焦点变化都不会持久化草稿。
- 只有当所有者声明激活就是提交点，并且控件不处于承诺稍后 Save 的原子草稿中时，即时设置才有效。不得在没有独立可见边界和所属协议的情况下把即时写入混入原子草稿。
- 只有局部、可逆并可安全重复应用时才准入预览。所有者记录进入时的投影，移动游标可以更新它。接受前的局部返回恢复该进入投影。接受操作结束预览，并按照声明的策略更新父草稿或提交；之后返回会保留已经接受的结果，只撤销更新且仍未接受的预览。
- 变更会发送请求、改变授权、排空工作、影响隐私或可能在外部失败的设置，不通过导航进行预览。应先接受选择，再调用其操作。
- 验证由值所有者执行。无效输入保留最后确认的有效值；在安全时保留草稿供修正；错误显示在控件旁；Save 尝试后把焦点移到第一个无效编辑器。
- Save 需要当前成功呈现的界面、有效且非空的补丁、冻结的来源标识和尚未使用的提交权。接受操作冻结这些事实，只消耗一次权利，并创建一个等待执行。重复按键、点击或重绘不能再次提交。
- 提交前关闭会丢弃原子草稿并撤销预览。Save 已被接受后隐藏界面只释放呈现，不取消、不重放也不回滚提交。

TUI 向现有持久化边界发送类型化补丁。除非公共所有者明确要求，否则绝不发送路径、序列化配置文档或替代存储选择器。只有已确认快照可以成为新的已保存基准，并驱动已确认的产品效果。仅有磁盘写入回执不能证明每个宿主效果都已应用。

## 外部更新与结果

已确认的外部更新会成为最新的权威有效状态。它刷新干净视图，并按语义标识保留仍有效的焦点。有未提交草稿、活动编辑器、子任务、预览或确认时，保留原始已保存基准供比较，并把更新的有效值显示为冲突；绝不能暗中变基或覆盖。重载是显式操作，它确认丢弃本地工作并读取新的完整基准。

| 结果         | TUI 必须执行的行为                                                             |
| ------------ | ------------------------------------------------------------------------------ |
| 已确认变更   | 采用返回的完整快照与来源，清除已提交草稿状态，并显示有效值和效果范围           |
| 已确认无变更 | 采用已确认快照，清除已提交补丁，并在不弹出成功提示的情况下说明值未改变         |
| 已拒绝       | 保留草稿和最后确认的有效值；显示本地化原因以及所有者定义的修正、重载或重试路径 |
| 未知         | 保留草稿和最后确认的有效值；说明提交状态未知，并要求重新观察后才能再次提交     |

提交完成结果携带界面实例、执行标识、来源标识和请求代次。被替换界面、旧草稿、先前编辑器阶段或过期请求的完成结果不能改变当前值、预览、焦点、反馈或等待状态。被拒绝或未知的请求都不会自动重放。

## 重置、依赖与敏感工作流

- 单项设置重置要说明它是移除显式覆盖、显露继承值，还是暂存规范产品默认值。重置使用领域操作；它不是另一个默认值写入器。
- 重置一个内聚分区或原子草稿时，应说明作用域和受影响值；当范围难以撤销时要求确认；在所属 Save 之前仍是草稿状态。
- 当附近的前置条件可以启用依赖设置时，保持该设置可见但不可用。显示依赖关系并保留已确认的有效值。
- 切换作用域前应解决任何活动草稿。绝不能根据上次访问的类别或行推断写入作用域。
- 秘密和外部凭据直接进入获准的有界工作流，之后从 UI 内存清除。它们绝不能进入普通草稿、搜索索引、通知、诊断或持久 UI 状态。
- 账户删除、凭据撤销、保留历史删除、迁移和诊断都是有独立效果与恢复边界的具名工作流，不是设置开关。

## 验证

| 变更声明        | 所需证据                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------ |
| 元数据或准入    | 测试覆盖标识、类型与边界、默认值与缺省、作用域/来源、可用性、应用时机、重置含义和两种区域设置                      |
| 组合或搜索      | 单元格网格测试覆盖类别、说明、确定性筛选、没有孤立标题、空结果、子任务返回、滚动和尺寸等级                         |
| 类型化控件      | 键盘和指针测试到达相同编辑或操作，并区分有效值、草稿、游标、悬停、锁定、验证和等待状态                             |
| 预览            | 测试证明只导航预览、接受行为、返回时准确恢复、不会持久化，以及拒绝过期预览                                         |
| 原子草稿与 Save | 测试证明编辑保持局部、只有 Save 写入、验证阻止分发、一次权利只产生一个请求、取消恢复基准，以及隐藏不取消已接受工作 |
| 外部更新        | 测试覆盖干净刷新、脏草稿冲突、显式重载、语义焦点保留、来源比较和不会暗中覆盖                                       |
| 结果处理        | 受控完成覆盖已确认变更、已确认无变更、拒绝、未知、过期代次、不重放和效果范围文案                                   |
| 重置或依赖      | 测试覆盖继承与默认值重置的区别、重置仍为草稿、确认、不可用原因、作用域安全和敏感值排除                             |

依据 [`verification.md`](verification.md) 使用渲染、输入、尺寸调整、区域设置、降级色彩和受支持宿主证据。当竞争写入者、比较交换发布或未知提交结果的风险满足
[`MODELING-AND-CORRECTNESS.md`](../MODELING-AND-CORRECTNESS.md) 时对其建模；普通行渲染不需要独立形式化模型。
