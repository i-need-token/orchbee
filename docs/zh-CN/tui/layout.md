# TUI 布局

## 权威性和范围

本标准拥有 Orchbee 自有终端界面的区域组合、信息优先级、对齐、尺寸层级、降级顺序、覆盖层几何、
视口锚定、截断和尺寸变化行为。颜色、框架和字形遵循
[`visual-foundations.md`](visual-foundations.md)；覆盖层内容和状态行为遵循
[`overlays-and-status.md`](overlays-and-status.md)；可复用表面与控件组合遵循
[`components.md`](components.md)。所属应用记录其具体区域及阈值；本标准定义这些决定必须满足的规则。

这些规则是新增和实质性变更 TUI 行为的必需契约；写入本标准不代表每个现有 Client 已经符合。
运行时采用须由源码和 [`verification.md`](verification.md#契约评审) 要求的证据建立。分阶段缺口记录
负责人和完成条件。

## 区域

全屏 Client 把宿主区域划分为持久 chrome 和内容，并按需叠加临时状态层：

| 区域      | 契约                                                              |
| --------- | ----------------------------------------------------------------- |
| 顶部条    | 最多一行；承载 Tab 和当前位置等导航                               |
| 状态行    | 按需覆盖内容一行，不预留终端高度，位于其他覆盖层之上              |
| 侧面板    | 可选；Full 宽度下停靠，Compact 宽度下为覆盖层，Minimal 宽度下隐藏 |
| 内容      | 剩余区域；接收 chrome 未占用的每一行和每一列                      |
| pane 边界 | 分屏 pane 之间的一个单元格，由两侧邻居共享                        |

- chrome 的行数和列数按层级固定，并由所有者记录。chrome 绝不为了容纳内容而增长；内容通过
  层级适配。
- 在同一层级内，项目数量、标签长度、状态和异步活动绝不改变停靠 chrome 或主内容的几何。只有
  宿主几何、显式布局动作或层级切换可以改变它们。
- 侧面板可在自身列范围内保留固定页脚。列表独立滚动；页脚不占用相邻终端内容的行。
- 只要 chrome 能放下，内容绝不小于一行乘一列。放不下时，chrome 按已记录的降级顺序先让步，
  内容才会消失。
- 每个尺寸都是整数个单元格。百分比只解析为单元格一次，并在任何其他计算之前夹到该区域已记录的
  最小值和最大值之间。
- 分屏 pane 至少保持所有者记录的最小内部尺寸；无法同时满足两个子节点最小值的分屏会被拒绝，
  而不是裁切绘制。

## 信息优先级与对齐

按以下顺序分配空间：任务目标和必需决定；主提交、返回、退出或恢复控件；当前上下文和位置；
当前任务状态；辅助元数据；最后是装饰。低优先级项目绝不挤占、裁切或在视觉上盖过高优先级项目。

- 每个组合屏幕把主要面积与视觉强调留给工作内容。非分屏界面只有一个主工作区域；分屏中的同级
  pane 保持自身几何，由焦点指明当前输入区域。持久 chrome 用于说明位置和导航，不在多处重复
  同一上下文和操作。帮助用于可发现性，不是重复的主控件。
- 每个表面只定义自身需要的对齐轨道，例如展开、状态、序号、标签、元数据和尾部动作。该表面各行
  的轨道保持稳定；条件性子项、状态、选择或动作不得让身份标签在行间或帧间横向跳动。不同组件
  无需共享其不使用的轨道。
- 尾部值或动作的轨道先于标签测量预留。某行没有该值或动作时，也保持与同组行相同的标签边界。
- 相关行使用一套声明的间距和缩进层级。缩进由深度计算，不取决于该行当前是否显示展开字形或
  状态标记。

## 行几何

- 在视口放置和指针命中测试之前，根据语义内容、换行策略和当前宽度解析每个可见行的高度。行可
  换行、展开或显示详情时，代码绝不假设 `index == y`。
- 选择、当前上下文填充和命中矩形覆盖行的完整解析高度，包括有意的内部留白，但不包括组间间距。
- 当一个意图必须显示某个语义行时，视口只滚动到足以完整绘制该行。比视口更高的行对齐到自身
  开头，并提供其已记录的内部滚动或展开行为。
- 重排把行几何作为一个整体布局结果更新。渲染和指针分发消费同一结果，二者都不独立重建偏移。

## 尺寸层级

层级为提示、chrome 和覆盖层提供共享的降级词汇。宽度和高度独立分类；表面取二者中较低的层级。

| 层级    | 宽度     | 高度     | 行为                                                                     |
| ------- | -------- | -------- | ------------------------------------------------------------------------ |
| Full    | ≥ 100 列 | ≥ 24 行  | 完整提示、停靠侧面板、完整标签                                           |
| Compact | 60–99 列 | 12–23 行 | 缩短提示、侧面板改为覆盖层、截断标签                                     |
| Minimal | < 60 列  | < 12 行  | 任务仍可用时保留当前返回或退出路径及完整主动作；否则暂停并进入“过小”状态 |

低于 20 列或 5 行时，Client 只绘制一条本地化的“过小”通知和状态行，其余一概不画，并在宿主
变大时恢复正常渲染。任何暂停的表面仍保留在模型中；状态行保留当前有效的返回、退出或恢复提示，
不可见的提交或确认动作不可用。

每个表面遵循一个已记录的降级顺序。默认顺序为：移除装饰和重复的辅助文本、丢弃可选元数据、
使用已记录的短标签与提示、把次要动作移入可发现的溢出入口、取消侧面板停靠、隐藏侧面板，最后
截断标签。表面绝不跳步以更快达到更小的结果。

仍然可交互的任务先为完整的返回或退出控件与主动作预留空间，再分配可选内容。快捷提示是一个
不可拆分的按键加标签记录：使用已记录的短形式、完整换行，或按优先级移除。绝不绘制被截断的
按键或标签。如果必需目标和控件无法同时放下，则拒绝该表面或使用“过小”状态，不得呈现残缺任务。

## 覆盖层

- 覆盖层相对内容区域定位，水平和垂直居中。居中时向左上角单元格取整。
- 鼠标打开的上下文菜单改为锚定触发单元格，使用状态行上方的完整视口，包括导航构件。
  将整个菜单框限制在该视口内；不得仅因普通覆盖层使用 pane 区域，就把侧栏触发位置移到 pane 区域。
  键盘打开保留所属界面的确定性定位。
- 覆盖层宽度为 `min(preferred, area.width − 4)`，高度为 `min(preferred, area.height − 2)`。
  首选尺寸以单元格或百分比给出，并按上述规则解析。
- 新请求覆盖层的解析内部区域小于 4 列乘 3 行时，不打开该覆盖层。触发动作通过状态行报告拒绝，
  且不执行领域效果。已经打开的覆盖层遵循
  [`overlays-and-status.md`](overlays-and-status.md#生命周期与返回) 中的暂停契约。
- 覆盖层在绘制前清除其下方的单元格，pane 内容绝不透出。
- 捕获覆盖层保留可见且最新的模式指示器和退出提示。状态层覆盖内容单元格，不调整子终端尺寸；
  关闭时重绘被覆盖内容。
- 先分配 [`overlays-and-status.md`](overlays-and-status.md#覆盖层组合) 中的固定外壳槽位，再分配
  内容视口。头部、导航、查询、状态、动作和页脚绝不随内容滚动。如果这些槽位导致内容小于已声明
  的最小区域，则拒绝覆盖层，不得裁切固定槽位。
- 超出剩余内部高度的覆盖层内容可滚动并显示位置。可变行高参与该视口计算。

## 截断与换行

- 按 [`visual-foundations.md`](visual-foundations.md#显示宽度与文本安全) 中的规则以显示宽度
  截断。标签从末尾截断；路径从中间截断；数字等标识符绝不截断。
- 同时承载标签和按键提示的行保持提示完整，截断标签。
- 按键提示作为完整的按键加标签记录保留。多个提示只能在记录之间换行；无法换行时，先移除低优先级
  记录，不得裁切任何一条记录。
- 比区域更宽的列表逐行独立截断；绝不引入水平滚动。
- 散文在词边界换行。换行后的块绝不超过其声明的最大高度；多出的内容滚动或通过已记录的更短
  形式概括。
- 当前 Tab 始终完整可见：Tab 条先围绕当前项开窗，再绘制邻居。选择器在选择器导航期间，或依据其
  声明的“临时游标保持可见”策略显示临时游标；普通视口移动可以让该游标留在屏幕外。

## 滚动区域

- 比区域更高的列表或文本区域用一列宽的滚动条或 `current/total` 指示器显示位置；所有者记录采用
  哪一种。
- 每个可滚动表面都区分视口移动和选择器导航。滚轮输入默认表示视口移动；任何含义取决于当前控件
  的按键都由所有者明确记录。
- 视口移动保留领域选择、已提交值和逻辑内容锚点；仅因临时游标离开屏幕，手动定位的视口不会自动
  跳回。选择器可以声明“临时游标保持可见”策略，在视口移动后只把临时游标移到最近的完整可见
  可用行。这种移动绝不激活行或改变领域状态。
- 选择器导航按语义行移动临时游标，并只滚动到足以完整绘制该行。当前输入所有者执行激活时，显示
  由此产生的当前 Tab 或当前项；后台状态变化绝不移动视口。
- 视口翻页滚动一个视口高度减一行以保留上下文；半页移动是可选的。
- 跟随实时输出的区域钉在底部，直到用户向上滚动；此后保持位置，直到显式返回底部。
- 视口保存语义锚点：稳定项目身份；对于换行内容，还包括逻辑内容位置和行内显示偏移。内容插入、
  删除、重排、展开和尺寸变化保留该锚点；绝对显示行号不构成锚点。如果项目消失，依次使用下一个
  存续项目、上一个存续项目，最后使用该区域空状态的起点。
- 底部跟随是一种显式视口状态。只有在其生效期间，新输出和重排才保持底部钉住；保留普通锚点
  绝不会暗中重新启用跟随。

## 尺寸变化

- 每一帧都从当前宿主几何计算布局。缓存的矩形只服务于针对上一绘制帧的指针命中测试，几何变化
  时即被丢弃。
- 尺寸变化触发完整重绘。零或缺失的几何被忽略，上一个有效几何持续生效，直到新的有效几何到达。
- 重排之前捕获每个滚动区域的语义锚点。行高和区域重算后先恢复该锚点。当前独占编辑器或必需决定
  随后只进行让焦点控件保持可见所需的最小调整；选择器仅在其声明“临时游标保持可见”策略时如此
  处理。其他情况下以阅读锚点为准，即使临时游标仍在屏幕外。任何情况都不得改变领域选择，也不得把普通
  视口重置到顶部或底部。
- 子终端 pane 只在其内部几何变化时才接收尺寸变化。即使中间的尺寸变化被合并，一轮尺寸变化的
  最终几何也总会应用。
- 覆盖层在尺寸变化时重新计算几何。无法再放下时进入
  [`overlays-and-status.md`](overlays-and-status.md#生命周期与返回) 中暂停的“过小”状态，不得丢弃
  草稿、必需决定、已接受工作或恢复路径；重新放得下后恢复正常渲染。

## 验证

| 变更               | 必需检查                                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 区域或层级变更     | 按 [`verification.md`](verification.md#渲染证据) 中每个必需几何渲染，包括“过小”通知                                                |
| 对齐或行变更       | 混合深度、混合状态、无动作、换行和展开行保持已声明轨道；渲染和指针命中使用相同的解析高度                                           |
| 降级顺序变更       | 每一步一个测试，证明上一步内容存在而下一步内容不存在；必需控件和提示保持完整                                                       |
| 新增覆盖层         | 测试覆盖最大和被夹紧的几何、新建尺寸拒绝、已打开尺寸暂停与恢复；内容滚动时固定槽位保持固定                                         |
| 截断或开窗变更     | 测试包含宽字符、完整提示记录、可变高度行、屏幕外的临时游标和可见条带之外的当前 Tab                                                 |
| 内容变化或尺寸变化 | 测试分别保留普通语义锚点与底部跟随，在不改变领域选择的情况下应用焦点或临时游标可见优先级，使用删除后的回退规则，并拒绝过期指针矩形 |
