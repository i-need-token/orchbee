# TUI 组件

## 权威性和范围

本标准拥有 Orchbee 在终端单元格网格中绘制的控件及组合控件的可复用视觉与交互契约。它约束
组件状态、可操作感、共享 chrome、命中几何和组合方式。领域身份、动作资格、效果和产品文案仍由
所属功能负责。

颜色、修饰符、字形和显示宽度遵循 [`visual-foundations.md`](visual-foundations.md)；区域分配和降级
遵循 [`layout.md`](layout.md)；输入归属与解码遵循 [`keyboard-input.md`](keyboard-input.md) 和
[`mouse-input.md`](mouse-input.md)；覆盖层准入与捕获遵循
[`overlays-and-status.md`](overlays-and-status.md)。共享产品含义遵循
[`INTERFACE-DESIGN.md`](../INTERFACE-DESIGN.md)。语义动作身份与执行遵循
[`actions.md`](actions.md)；设置值、范围、提交和重置遵循 [`settings.md`](settings.md)。

这些契约约束新组件和对现有组件的修改，并不声称每个现有表面已经实现它们。只有实现和下文要求的
证据建立了该结果，现有表面才算符合本标准。

## 所有权与准入

| 所有者     | 职责                                                                                   |
| ---------- | -------------------------------------------------------------------------------------- |
| 功能       | 稳定的动作与实体身份、标签、可用性及原因、当前与勾选值模型及声明的提交边界、效果和结果 |
| 组件       | 最小可用几何、槽位、状态组合、渲染、已记录命中区域、导航意图，以及其矩形内的降级       |
| 表面组合器 | 存在哪些组件、阅读与焦点顺序、布局层级，以及分配给各组件的空间                         |
| 主题       | 每个语义角色的具体样式和低色深回退                                                     |
| 输入适配器 | 原始事件解码、归属优先级、指针捕获策略，以及规范化事件的传递                           |

- 组件接受有类型的语义状态并发出有类型的意图。它绝不从本地化标签、颜色、行位置或字形推断
  身份、可用性或操作。
- 共享组件代码属于其真实消费者共同使用的最窄所有者。只有多个真实消费者需要同一份完整契约时，
  才把局部控件提升为共享组件。本标准命名组件族是在定义其行为，并不要求共享实现。不要创建万能
  widget 桶，也不要仅因使用相同库类型就把功能专属行移入共享模块。
- 共享组件拥有完整的重复性契约：静止与交互状态、最小和紧凑几何、键盘与指针对等、命中区域、
  截断、本地化和验证。只绘制边框或颜色的 helper 不是组件。
- 变体共享同一个状态模型和交互语法。不要通过布尔标志把无关控件做成一个组件。产品屏幕通过
  已记录槽位组合组件，而不是给共享渲染器加入屏幕专属分支。
- 组件状态是纯数据。布局与渲染仅由状态、几何、主题和 locale 决定。只有所有者收到组件意图后
  才执行效果。
- 拥有可复用基础控件或重复组合的应用或包在该所有者内维护一份参考，链接唯一源码入口、语义状态与
  意图类型、行为测试和消费者采用测试。移动、提升、替换或移除时，在同一变更中更新这些链接。
  这是维护发现路径，不是业务表面清单；不要引入平行注册表、manifest schema 或目录命令。

使用三个所有权层级：

| 层级     | 内容                                                              | 复用边界                                 |
| -------- | ----------------------------------------------------------------- | ---------------------------------------- |
| 基础控件 | 按钮、行内动作、行交互层、Tab、编辑器、值控件、快捷键条目和滚动条 | 状态和手势含义相同时复用                 |
| 重复组合 | 列表或树、选择器、模态窗口和快捷键栏                              | 拥有基础控件的排列与协调，不拥有功能效果 |
| 业务表面 | 功能导航器、设置表面、活动看板或工作流                            | 留在功能所有者中，组合基础控件与重复组合 |

编写控件前：

1. 从所属应用或包的维护参考开始。对于可复用基础控件或组合，沿链接找到唯一源码入口、语义类型、
   行为测试和消费者采用证据。对于局部控件，找到对应的功能自有源码与测试。不另建平行的 TUI
   组件目录。
2. 通过所有者阅读最接近的基础控件或重复组合，比较状态轴、槽位、手势、降级和证据，而不是只
   比较截图。
3. 契约匹配时复用。缺少兼容的重复需求时扩展其语义所有者。共享契约已经覆盖局部重复时替换它。
   行为属于功能专属时新建局部控件，并且只有满足上文准入规则后才提升为共享组件。
4. 更新所属参考链接、类型、行为测试和受影响的消费者采用测试。业务表面记录采用了哪些共享契约，
   但不分叉其视觉或输入规则。

## 状态模型

以下各轴相互独立。组件声明它支持的每条轴并渲染有效组合，而不是把它们压缩进一个 `selected`
标志。

| 轴       | 状态               | 契约                                                           |
| -------- | ------------------ | -------------------------------------------------------------- |
| 信息层级 | 标题、主要、次要   | 只描述阅读优先级；交互绝不把元数据提升为主要内容               |
| 键盘归属 | 未聚焦、已聚焦     | 焦点标识事件所有者，且不依赖背景填充也保持可见                 |
| 指针     | 静止、悬停、按下   | 悬停和按下绝不提交模型值；动作菜单可通过所有者移动临时候选     |
| 导航     | 无、临时选择       | 临时选择是在接受前通过导航到达的可逆行或值                     |
| 身份和值 | 当前、已勾选       | 当前标识活跃上下文；已勾选标识控件声明值模型中的已选选项       |
| 可用性   | 可用、禁用并带原因 | 禁用阻止激活，但保留身份和可发现性                             |
| 操作     | 空闲、等待、结果   | 等待描述激活后的工作；成功、失败、取消和未知是结果，不是可用性 |

背景严格只用一个角色，优先级依次为 `surface-pressed`、`surface-selection`、
`surface-hover`、`surface-current`，最后是组件基础表面。其他通道保持独立：

- 键盘焦点通过 `frame-focused` 或稳定的 `accent-focus` 标记保持可见；
- 当前身份通过 `BOLD` 或稳定的当前标记保持可见；
- 已勾选值保留使用 `accent-selection` 的勾选字形；
- 禁用内容使用 `text-disabled`，但当前或已勾选标记仍可辨认；
- 等待状态保留焦点、当前和已勾选提示，并加入固定宽度的 `status-pending` 字形和本地化操作动词。

集合应声明其唯一键盘所有者焦点提示绘制在哪里。有框架的集合使用外层 `frame-focused` 边框；
无框架的行所有者预留专用焦点轨道。该投影必须显式声明：省略轨道绝不是隐式回退，框架内的行也
不重复框架的焦点提示。无论哪种情况，临时导航都保留自己共享的行标记。

已勾选属于控件声明的值模型和提交边界。它可以投影父草稿、暂存的多选值或已确认领域值，并与临时游标
保持独立；其本身不能证明已经持久化。投影值与已确认或有效基准不同时，所有者提供可见的草稿变更提示，
且该提示与焦点、临时导航、校验和等待状态保持区别。

指针悬停绝不移动键盘焦点、当前上下文或已勾选值。打开的动作菜单通过所有者处理真实的无修饰、
无按键移动，让已绘制可用行成为临时候选，并使用与键盘导航相同的整行选中背景和导航标记。
这不会执行动作或打开子菜单。离开后保留候选，方向键从该候选继续。禁用行和分隔线不成为
指针候选。其他集合在悬停时保留临时游标。按下会武装一个可用目标；离开该
目标就移除按下样式。指针策略决定在释放时是否激活。禁用目标绝不获得悬停或按下样式。

等待不等同于禁用。功能提供操作能否再次调用、取消或并发运行；组件呈现该策略，绝不自行发明。
状态颜色只出现在状态字形或状态词上。任何交互或层级状态都不用成功、警告或错误色做强调。

状态变化绝不移动相邻标签或列。组件要为它可能进入的任意状态预留所需的标记、字形、状态和
辅助动作槽位。

## 动作控件

| 类型       | 静止时的可操作感                            | 用途                                                               |
| ---------- | ------------------------------------------- | ------------------------------------------------------------------ |
| 按钮       | `[ Label ]`，方括号内两侧各有一个空白单元格 | 独立的提交、取消、确认或表单动作                                   |
| 行内动作   | 稳定动作字形或格式化按键，后接本地化动词    | 位于页眉、工具栏、动作行或页脚中，且所在分组已经表达动作语境的命令 |
| 行动作     | 完整的带标签行是主要目标                    | 打开、选择或激活列表或树行代表的实体                               |
| 纯图标动作 | 带方括号且宽度稳定的字形，例如关闭控件      | 在获准几何下无法保留标签的通用动作                                 |

- 普通文本里的裸名词不是动作可操作感。安静的行内动作在静止时也通过动作字形或显示的按键及
  动词保持可辨认；悬停绝不是它唯一的动作提示。行的溢出菜单触发器遵循下文的集合规则。
- 按钮的方括号、内部留白、标签和预留状态槽位组成一个绘制与点击范围。一个决策上下文中的主要
  按钮在静止时使用 `accent-action`；次要按钮使用 `text-primary`。两者都不会看起来像键盘焦点。
  状态角色绝不区分主要、默认或破坏性动作。
- 明确的破坏性动作可声明共享的破坏性意图色调。标签使用 `accent-destructive`，独立于主要／次要
  层级；禁用内容仍使用 `text-disabled`。行和按钮所有者保留普通的悬停、按下、焦点及临时导航轨道。
  它们绝不为此意图自行构造警告颜色或借用状态角色。
- 决策按钮将所有者格式化的快捷键放在方括号内，在标签后留两个空白单元格。快捷键使用
  `text-secondary` 和普通字重；终端单元格保持宿主字号。它属于按钮完整且固定的绘制与命中范围，
  绝不另建第二个动作。
- 列表辅助动作槽中的按钮在静止时使用 `text-secondary`，并继承该行的表面。其自身的悬停与
  按下反馈仍限于已绘制的动作范围。
- 按钮组为每个按钮预留焦点标记单元格。聚焦按钮在该标记和方括号上使用 `accent-focus`。指针
  悬停用 `surface-hover` 绘制完整按钮范围；按下使用 `surface-pressed`，且不抹除焦点标记。可用
  按钮的标签在悬停或按下时加 `BOLD`。
- 等待按钮预留状态字形槽，并按空闲标签与等待本地化标签中较宽者设置标签区域。操作开始时，
  它的外部范围不变。
- 行内动作与相邻内容有明确的分组边界和间隔。悬停和按下时，其有效命中矩形作为一个整体绘制。
  它绝不伪装成标题、元数据值或链接。
- 纯图标动作有本地化的可发现名称，以及当前帮助所有者展示的键盘路径。布局能保留标签时，改用
  行内动作。没有名称和键盘对等路径的字形属于装饰，不能获得命中区域。
- 可用的纯图标动作静止时使用 `text-secondary`。悬停时，其字形和方括号增强为 `text-primary` 加
  `BOLD`，不添加填充；按下时保持这一强调并添加 `surface-pressed`。位于框架上的纯图标动作在每个
  方括号与框架线之间保留一个空白表面单元格；这些单元格不属于其命中范围。声明了破坏性悬停的
  所有者（如行关闭）可以替换悬停内容角色。
- 动作所有者提供可用、禁用原因、等待和并发状态。在权威结果到达之前，组件绝不乐观报告成功或
  清除等待状态。

## 值控件

| 类型           | 静止时的可操作感                                                           | 值契约                                                                   |
| -------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 布尔           | `[ ] Label` 表示关，`[x] Label` 表示开                                     | 只有领域允许第三种或聚合值时才提供混合标记                               |
| 单选           | `○ Label` 与 `● Label`，声明的 ASCII 回退分别为 `( )` 与 `(*)`             | 勾选标记跟随声明的值模型；临时游标保持独立                               |
| 有界步进器     | 稳定的减小、格式化值和增大轨道，例如 `[-] value [+]`                       | 所有者提供边界与步进语义；不可用的端点保持可见并呈禁用状态               |
| 编辑器或选择器 | 编辑器有带标签的字段边界；选择器显示标签、当前值或草稿值，以及显式打开动作 | 编辑保留草稿与光标；打开选择器遵循下文预览与接受契约；普通值文字不是控件 |

- 所有者提供类型化值、格式、边界、混合态准入、已确认或有效基准、草稿变更事实、可用性、校验和等待
  状态。组件发出类型化意图，绝不通过解析字形或本地化文案还原值。
- 布尔或单选目标包含其标记、间隔和完整标签。步进器的减小和增大分别拥有完整绘制目标。除非所有者
  准入编辑器或跳转动作，否则格式化值是没有命中区域的静态文字；准入后，该值目标拥有完整绘制字段。
  选择器触发器同样拥有完整字段。不存在无标签空隙或只在悬停时出现的目标。
- 悬停和按下覆盖有效目标，焦点、临时导航、已勾选值和草稿变更提示仍彼此独立。草稿可以改变勾选
  标记，但独立的变更提示继续表明它与已确认或有效基准不同。
- 每项值操作都有对等键盘路径。状态变化保留全部轨道和控件外部占位；不可用端点、校验和等待中的
  工作都不移动标签。

## 列表与树

共享列表拥有导航、滚动、行交互层和命中几何。每个条目拥有其语义内容和身份。条目渲染器绘制
文字和内容专属状态；列表随后应用当前、悬停、临时选择、焦点和搜索覆盖层，避免各行发明不同的
交互样式。

行按以下顺序使用一致轨道。集合可以将运行状态放在固定的尾部元数据槽，而非前置状态槽；
声明的位置在全部同级条目与交互状态下保持一致。身份与勾选标记仍保留各自独立轨道。
可选辅助元数据先于主要内容丢弃；移位后的状态槽始终保留。
树可以将展开控件紧随首行已显示的身份之后，而非放在前置轨道。文字适配前先预留一个间隔
单元格和字形，保持同级标签起始列稳定。只有实际绘制的字形单元格拥有展开控件的悬停、按下与
激活；前置留白和续行仍属于各自声明的所有者。

| 轨道     | 契约                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 焦点     | 仅供无框架的行焦点所有者使用；有框架的集合只在外层框架呈现一次焦点            |
| 导航     | 共享的单单元格临时游标（`›`，ASCII 为 `>`）；绝不复用作当前、勾选、变更或序号 |
| 缩进     | 组件内每层树深度使用一个恒定步长                                              |
| 展开     | 前置布局为同级叶节点保留空槽；行内布局在身份旁预留字形预算                    |
| 状态     | 固定宽度的身份、勾选或操作字形槽                                              |
| 主要     | 可伸缩的对象标签；只有给其他必需轨道预留预算后才截断                          |
| 元数据   | 右对齐或第二行的辅助信息；先于主要内容丢弃                                    |
| 辅助动作 | 预留的尾部范围；静止时使用次要层级，在行聚焦或悬停时加强，且绝不移动主要标签  |

- 无论行是否有子节点、状态、元数据或可见辅助动作，同级标签都从同一列开始。只有序数位置有
  产品含义时才显示数字。
- 导航标记及其 `accent-selection` 处理由集合拥有，而非条目渲染器拥有。功能代码提供临时身份和
  固定几何，不提供替代字形。
- 主要行目标覆盖该行拥有的每个单元格和每条线，包括内部留白，避免出现无法命中的条带。外部
  分组间隔不属于行的背景和交互范围。单独绘制的辅助动作有自己的命中区域，并在该区域内优先命中；其键盘对等路径保持可发现。
- 安静的辅助动作在绘制时通过动作字形或格式化按键保持可辨认。行的溢出菜单触发器可以在静止时
  隐藏，在悬停行或其子控件、或该行实际拥有键盘焦点时显示。预留其范围，不发布隐藏动作目标，
  保留已有右键菜单和键盘路径；悬停或按下已显示的触发器时，继续显示。显示它不会移动身份，
  也不会取消已按下待释放的行。
- 行的关闭图标动作可以按同一规则，在悬停行或其子控件时显示。它贴齐首行尾部边缘，仅在显示
  期间覆盖该行右对齐的元数据和尾部标记；身份始终保留固定一列间隔，因此在静止和悬停时以相同
  方式截断。它在行表面上使用
  `text-secondary`，仅在自身悬停和按下时使用 `accent-destructive`。它不发布隐藏目标，保留已有
  菜单和键盘关闭路径，并进入所有者的常规关闭确认。
- `surface-current` 在焦点移走后仍标识活跃实体。`surface-selection` 标识临时游标。
  普通集合的指针悬停使用 `surface-hover`，且不移动这两个事实；动作菜单遵循上述候选契约。
  勾选字形独立于三者，标识其声明值边界上的
  已选多选值。
- 当前、已勾选或临时标记在截断和低色深渲染下仍然存在。可选元数据绝不成为身份或状态的唯一提示。
- 展开行切换它自己的分组。展开或折叠按稳定身份保留选择；只有选中后代被隐藏时，才按确定规则
  移动选择。
- 分组标题要么是没有命中区域的静态文字，要么是具有焦点、悬停和键盘激活的完整展开行。不能
  只有字形的一小部分可点击。
- 筛选按稳定身份保留临时值和勾选值。如果临时条目被移除，列表按已记录顺序选择最近的剩余
  条目；悬停不影响该选择。
- 当一行有多条视觉线时，延续内容与主要轨道对齐。交互背景和焦点标记覆盖该行的完整视觉高度。

## Tab

- Tab 列表是一个焦点所有者。当前 Tab 属于持久当前上下文，使用中性的 `surface-current` 加
  `BOLD` 或稳定当前标记。键盘焦点使用独立的 `accent-focus` 标记或聚焦框架；手动激活型 Tab
  列表还可以用 `surface-selection` 显示其临时游标。
- 每个 Tab 标签的完整绘制范围都是动作目标。悬停和按下遵循动作状态规则，并且在获准手势提交前
  绝不激活 Tab。
- 激活 Tab 会改变内容，并把焦点留在该 Tab，除非所属流程明确把焦点转入新面板。仅移动焦点
  绝不改变当前 Tab。
- 溢出通过换行、滚动或已记录的溢出控件遵循所属布局层级。当前 Tab 和退出路径保持可见；标签
  不会被静默丢弃。

## 搜索与编辑器

- 搜索控件在静止时有可见的本地化范围标签或搜索前缀。占位文字只是补充，绝不承载持久说明或
  成为唯一输入可操作感。
- 覆盖层查询槽遵循 [`overlays-and-status.md`](overlays-and-status.md#框架外观)：静止时显示激活
  按键和提示，编辑时显示 `Label: draft` 并带终端光标。它没有方括号边界；表单编辑器保留自己的
  边界。
- 控件区分查询、焦点、匹配数量、加载、空结果和错误。空查询与无匹配是不同状态。搜索错误不
  清除查询。
- 聚焦编辑器使用 `frame-focused`、其无框架的 `accent-focus` 标记或其查询槽标签，并显示终端
  光标。未聚焦
  编辑器保留边界和草稿，但绝不绘制假光标。
- 随草稿变化，前缀、模式、校验、等待和辅助动作槽位保持稳定。上下文提示可以变化，但可编辑
  起点和提交边界不能移动。
- 编辑行为、原子粘贴、输入法组合和最大长度遵循
  [`keyboard-input.md`](keyboard-input.md#编辑与草稿)。校验和拒绝显示在所属页脚或状态表面中，
  不用原始错误文字替换草稿。
- 打开选择器、帮助表面或临时子任务时记录并保留父级草稿和光标。在接受前返回会恢复进入快照。
  接受会结束所有预览，并按所有者的提交策略更新父草稿或领域；此后返回会保留已接受结果。只有所属
  功能接受父级提交后，才清除或替换父级草稿。
- 建议与补全使用选择器状态模型。预览建议可以改变可逆的草稿投影；仅悬停绝不预览或提交。

## 选择器

选择器组合一个搜索控件、一条分隔线、一个可滚动列表主体和上下文页脚。放在覆盖层中时，共享
模态框拥有外框和标题。搜索与页脚固定，只有结果主体滚动。

- 选择器拥有查询、临时游标、滚动位置和可逆预览。功能提供稳定条目身份、当前值与勾选值、
  可用性和提交效果。
- 移动键盘游标只改变临时选择。单选接受按已声明边界更新父草稿或权威值。在多选选择器中，切换只
  改变目标勾选投影；选择器接受动作才跨过其声明的父草稿或领域边界。悬停不改变任何一项。
- 预览派生自临时条目，并在选择器接受前返回时恢复。接受会结束该预览，并按已声明边界更新父草稿
  或领域；此后返回会保留已接受结果，只撤销更新且仍未接受的预览。条目仅仅变为可见、聚焦或悬停
  时，选择器绝不写入持久值。
- 筛选尽可能按稳定身份保留游标，否则使用列表回退。加载、没有源条目、无匹配、失败和禁用结果
  使用不同的本地化呈现。
- 页脚派生自当前选择器模式和有效绑定。它始终保留退出路径，其次是提交或切换动作，然后才在
  空间允许时显示可选导航帮助。
- 紧凑或嵌入式呈现可以移除外层模态框，但保留相同状态、列表轨道、取消和提交边界。

## 模态窗口

紧凑上下文菜单使用 [`overlays-and-status.md`](overlays-and-status.md#覆盖层组合) 中的专用组合，
不借用模态框的标题、关闭控件或页脚；行及捕获 owner 仍保留全部输入守卫。

共享模态框组件实现 [`overlays-and-status.md`](overlays-and-status.md#覆盖层组合) 定义的槽位。
它拥有完整外层表面、框架、标题、可选 Tab、关闭动作、内容矩形和页脚；功能内容只在返回的内容
槽位内渲染。

- 在子内容之前绘制并清空完整模态表面，避免底层帧或此前更大模态框的单元格透出。
- 每帧根据获准区域计算所有槽位。新请求的模态框无法满足最小可用几何时，通过所属表面拒绝该请求，
  且不为该请求发布任何命中区域。已打开模态框变得放不下时，把同一个实例暂停到所属“过小”状态，
  保留其模型、已接受提交和等待中的工作，只发布有效的返回、退出或恢复目标；几何恢复后继续该实例。
  两条路径都清除陈旧的模态框和子级命中区域。
- 关闭控件是有本地化名称和有效取消绑定的纯图标动作。它按
  [`overlays-and-status.md`](overlays-and-status.md#框架外观) 的定义位于框架右上边，并遵循与
  其他动作相同的悬停、按下、禁用和焦点规则。
- 同一时刻只有一个模态所有者活跃。嵌套任务在该所有者内替换内容、标题上下文和页脚动作；它
  不叠加另一个模态框，也不留下两个活跃页脚。
- 模态 chrome 统一处理取消、Tab、关闭和页脚动作意图。功能内容只接收该 chrome 未消费的事件。
- 打开时记录此前的焦点所有者。关闭或取消时恢复它，不把改变当前上下文、列表顺序或草稿状态
  当作附带效果。
- 命中测试遵循绘制顺序。即使主题使用终端默认背景，模态框和子区域仍遮挡所有底层目标。

## 快捷键栏与滚动条

- 一个快捷键条目是格式化按键加本地化动作标签的原子组合，分别使用 `hint-key` 和 `hint-label`。
  条目从有效绑定定义或结构化局部键位映射生成；不要在绑定所有者之外维护手写按键字符串。
- 快捷键栏反映当前输入所有者和模式。它先保留退出动作、主要动作和模式指示器，再保留可选导航
  提示，并且只按布局层级整项丢弃。
- 常驻 chrome 用中点分隔条目；覆盖层页脚用带空格的竖线分隔条目。
- 当表面获准使用滚动条且内容变化可能使溢出出现时，组件在该视图的整个生命周期内预留一条轨道。
  滑块出现时内容宽度不能跳动。
- 预留轨道使用组件基础表面，滑块静止时使用 `text-secondary`。悬停与按下分别在滑块的有效目标上
  应用 `surface-hover` 与 `surface-pressed`，同时保持其字形可见，包括所属 pane 未聚焦时。指针交互
  绝不成为唯一滚动路径。
- 滚动条几何根据总内容、视口和偏移量用饱和运算得出。空内容或完全可见内容不绘制滑块，也不
  暴露滚动条命中区域。

## 渲染与命中区域

- 布局在渲染前返回组件矩形和相对轨道。渲染只绘制这些矩形，并从同一几何记录命中区域；输入
  绝不重建布局。
- 每次渲染都构建全新的候选命中注册表，并且只与成功刷写的帧一同发布。隐藏、裁剪、当前层级
  不可用、被遮挡或因尺寸被拒绝的目标，在该候选映射中都没有命中区域。
- 有效命中矩形与悬停样式覆盖相同单元格。只有组件拥有并绘制额外单元格时才能增加指针留白；
  禁止不可见目标。
- 重叠区域从最后绘制的子级向父级解析。辅助动作、关闭动作或滚动条在其矩形内优先；周围的行或
  模态框接收剩余单元格。
- 渲染完整绘制每个自有背景，包括内边距和空白单元格。它不执行效果、不读取时间、不查询终端，
  也不修改权威领域状态。
- 指针决策使用最后一个成功刷写帧的映射。resize 与结构性布局替换在下一次输入决策前使该映射
  失效，并在新映射发布前丢弃事件。当稳定目标身份及交互修订号保持相同时，仅视觉或无关重绘保留
  已武装手势。几何、可用性、遮挡、归属、接受的手势或语义目标变化会修订目标并取消该手势。

| 变更               | 必需证据                                                                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新增组件或状态变更 | 渲染静止、悬停、按下、聚焦、禁用、等待和结果；包含当前 + 焦点、当前 + 悬停、已勾选 + 临时选择、禁用 + 当前、禁用 + 已勾选、禁用 + 结果，以及等待 + 焦点的组合，同时次要层级保持次要 |
