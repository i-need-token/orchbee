# TUI 键盘输入

## 权威性和范围

本标准拥有 Orchbee 自有终端界面的按键解码、绑定模型、输入归属层、编辑约定和快捷键发现。具体
绑定、模式名称和前缀组合键属于所属应用的指南；本标准定义它们必须满足的形状。宿主键盘协议协商
遵循 [`terminal-environment.md`](terminal-environment.md)；指针输入遵循
[`mouse-input.md`](mouse-input.md)。

[`frontend/keyboard-shortcuts.md`](../frontend/keyboard-shortcuts.md) 中的前端契约约束浏览器和
Desktop 绑定。按 [`INTERFACE-DESIGN.md`](../INTERFACE-DESIGN.md) 一起选择 TUI 绑定和对应 GUI
绑定：保留动作的语义作用域、本地化名称与助记键，再按下述输入规则适配修饰键、前缀或模式。

## 解码

- 在任何所有者看到之前，先把宿主原始字节流解码为类型化按键事件。所有者匹配类型化事件，绝不
  匹配字节。
- 用能保持输入法组合正常工作的 flag 请求键盘协议消歧：消歧转义码、报告事件类型和报告备用键。
  默认不要请求把所有键作为转义码报告；只有在有证据表明每个受支持宿主上的组合仍然正常时才
  启用。
- 只对按下和重复事件采取动作。释放事件被消费且绝不分派。
- 匹配前先归一化：无修饰符的原始 C0 控制字符即对应的 `Ctrl` 组合键；大写字母隐含 `Shift`；旧式
  `Ctrl+5` 即 `Ctrl+]`。原始 `ESC`（`0x1b`）和 `DEL`（`0x7f`）绝不归一化为 `Ctrl` 组合键。
- 只有在宿主不做消歧时，才用有界等待把单独的 `ESC` 与 `Alt` 前缀区分开。等待绝不超过一个输入
  轮询间隔，也绝不延迟已消歧的事件。
- 括号粘贴始终启用。一次粘贴作为一个原子文本事件到达，绝不与绑定匹配，并按原始顺序恰好交付
  给一个所有者。
- 多字节 UTF-8 片段和被拆开的转义序列在分派前重新组装。读取边界处被截断的序列在有界窗口内等待
  下一次读取。

## 绑定模型

一个规范绑定是一个键码加一个完整的修饰符集合。匹配和展示都从该值派生；任何表面都不单独存储
标签字符串。

| 关注点 | 规则                                                                                                              |
| ------ | ----------------------------------------------------------------------------------------------------------------- |
| 匹配   | 归一化后的事件等于归一化后的绑定；修饰符的超集不匹配                                                              |
| 备选   | 一个动作可以列出多个绑定；第一个是展示的提示，顺序不承载分派优先级                                                |
| 标签   | 修饰符按 `Ctrl`、`Alt`、`Shift`、`Super` 顺序排列，用 `+` 与键连接                                                |
| 键名   | `Enter`、`Esc`、`Tab`、`Space`、`Backspace`、`Delete`、`Home`、`End`、`PageUp`、`PageDown`、`F1`…`F12`、`↑ ↓ ← →` |
| 平台   | 在 Apple 宿主上把 `Alt` 显示为 `⌥`；由客户端操作系统决定，而不是服务端                                            |
| 组合   | 前缀后跟一个键时，显示为用一个空格分开的两个标签                                                                  |
| 回退   | 简化字形下箭头字形使用 `Up`、`Down`、`Left`、`Right`                                                              |

除非 `Shift` 是绑定的一部分，字母以小写显示。数字范围显示为 `1..9`，绝不显示为九个条目。

## 输入归属

每个按键事件恰好有一个所有者，按以下顺序解析：

1. 独占捕获，例如行编辑器或确认。
2. 当前命名模式。
3. 已激活的前缀层。
4. 向聚焦终端 pane 的原样透传。

归属规则：

- 没有任何所有者消费的字节原样、按序到达聚焦终端。Client 绝不重排、合并或丢弃透传输入。
- 在独占捕获或模式之外，Client 不绑定任何无修饰符的可打印键，不绑定裸 `Enter`、`Tab`、`Esc` 或
  `Backspace`，也不绑定 `Ctrl+C`、`Ctrl+D` 或 `Ctrl+Z`。前缀组合键是唯一的默认无条件拦截，连按两次
  转发字面组合键。
  用户显式配置可在捕获与模式归属之后添加安全直达按键；上述可打印字符、编辑键及信号键
  排除规则仍适用，发现提示必须显示实际绑定。
- 已激活的前缀没有超时。`Esc` 撤销它。前缀后的未绑定键撤销前缀、不转发任何内容，并显示一条
  指明帮助绑定的瞬时通知。
- 命名模式为一个领域重新绑定键盘。进入模式后，其整个持续期间在状态行可见；`Esc` 总是返回普通
  层；每个键最多解析为一个意图；模式未绑定的键被忽略，绝不转发。
- 模式不嵌套。从一个模式进入另一个模式会替换它。
- 独占捕获消费每个键，包括前缀组合键，直到提交或取消。只有独占捕获可以绑定无修饰符的可打印键。
- 归属是对当前输入状态和一个事件的纯决策。时间、宿主和网络状态不改变谁拥有某个键。

## 编辑约定

每个内联文本编辑器都遵守这组约定。编辑器可以增加绑定；绝不重新绑定这些键。

| 键                             | 行为                           |
| ------------------------------ | ------------------------------ |
| `Enter`                        | 草稿有效时提交；否则在页脚说明 |
| `Esc`                          | 取消并恢复之前的值             |
| `Backspace`                    | 删除光标前的一个字素           |
| `Delete`                       | 删除光标后的一个字素           |
| `← →`                          | 移动一个字素                   |
| `Home` `End` `Ctrl+A` `Ctrl+E` | 移动到开头或结尾               |
| `Ctrl+W`                       | 删除光标前的一个词             |
| `Ctrl+U`                       | 清空草稿                       |
| 粘贴                           | 在光标处原子插入               |

- 草稿有以 Unicode 标量计的已记录最大长度。超出的输入以可见通知拒绝；绝不静默截断。
- 编辑器预填当前值，并把光标放在其末尾。
- 通过输入法的组合必须正常工作：编辑器绝不在组合期间消费事件，也绝不以会遮住组合候选行的
  方式重绘。
- 破坏性确认只接受其精确的确认键和 `Esc`。它捕获包含该决定的整个输入包，尾随字节绝不到达
  终端，且其默认结果是取消。

## 发现

- 前缀层默认把 `?` 绑定到快捷键帮助；用户覆盖后提示必须反映实际绑定。帮助从绑定注册表列出当前所有者的每个绑定；绝不是手工维护的
  字符串列表。
- 在模式内，帮助先显示该模式的绑定，最后显示退出绑定。
- 状态行通过 [`layout.md`](layout.md#尺寸层级) 中的层级显示当前所有者最有用的提示；提示使用
  上文的绑定标签格式化器。
- 禁用的动作连同其本地化原因保留在帮助中。
- 具体绑定记录在所属应用指南中，可行时从同一注册表生成，绝不在本标准中重复。

## 验证

| 变更       | 必需检查                                                                         |
| ---------- | -------------------------------------------------------------------------------- |
| 解码器变更 | 测试覆盖每个 C0 归一化、大写隐含 `Shift`、`Ctrl+]`、单独 `ESC`、拆开的序列和粘贴 |
| 新增绑定   | 测试证明匹配、带额外修饰符时不匹配，以及在 Apple 和非 Apple 宿主上的展示标签     |
| 归属变更   | 表驱动测试证明每对所有者的优先级，以及未消费字节按序透传                         |
| 新增模式   | 测试证明指示器可见、`Esc` 退出、未绑定键被忽略，以及模式不嵌套                   |
| 新增编辑器 | 测试覆盖每个编辑键、长度上限、预填和原子粘贴                                     |
| 新增确认   | 测试证明决定包中的尾随字节不会到达终端                                           |
