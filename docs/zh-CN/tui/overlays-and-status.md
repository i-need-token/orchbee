# TUI 覆盖层与状态

## 权威性和范围

本标准拥有 Orchbee 自有终端界面的表面选择、覆盖层组合、输入捕获、确认、状态行、提示、瞬时通知
和等待指示。几何遵循 [`layout.md`](layout.md#覆盖层)；颜色和层级遵循
[`visual-foundations.md`](visual-foundations.md)；按键归属遵循
[`keyboard-input.md`](keyboard-input.md#输入归属)。

[`frontend/dialogs-and-forms.md`](../frontend/dialogs-and-forms.md#中断预算) 中的中断预算原样
适用：从没有表面、没有问题开始，只询问结果所需的信息，绝不为后台状态抢夺焦点。

## 表面选择

| 表面         | 使用场景                                               | 禁止使用的场景                           |
| ------------ | ------------------------------------------------------ | ---------------------------------------- |
| 状态通知     | 结果、状态变化或拒绝可以一行说清，且不需要回应         | 用户必须选择或输入                       |
| 状态行编辑器 | 一个短值在状态行中就地编辑                             | 值很长、多字段，或需要周围上下文才能判断 |
| 非捕获覆盖层 | 帮助或 navigator 预览等参考内容，同时输入继续到达 pane | 内容必须先处理，pane 才能继续            |
| 捕获覆盖层   | 选择、选择器或多值草稿需要独占键盘归属                 | 一行状态或状态行编辑器已经足够           |
| 确认         | 一个简短决定先于不易撤销的效果                         | 效果可撤销，或表面只是报告信息           |

无论尺寸或名称，任何消费每个键的表面都是捕获型的。表面在打开期间绝不改变捕获类型。

## 覆盖层组合

覆盖层是一个带边框的区域，按顺序包含以下槽位：

| 槽位 | 契约                                                 |
| ---- | ---------------------------------------------------- |
| 头部 | 位于框架顶边或第一行的一个本地化标题；可选的一行说明 |
| 内容 | 任务表示：列表、编辑器、提示、文本或进度；过高时滚动 |
| 页脚 | 始终显示退出绑定，然后是主绑定，再最多两个次要绑定   |
| 动作 | 可选的一行可选动作，仅当仅靠按键会产生歧义时使用     |

- 同一时刻只打开一个覆盖层。子任务在同一所有者下替换当前内容和页脚；绝不在第一个覆盖层之上
  打开第二个。
- 头部说明覆盖层关于什么，而不仅是动作名称。确认的头部指明受影响的对象。
- 非捕获覆盖层在页脚说明输入会到达 pane。
- 内容依赖远端状态的覆盖层显示内容的时效或刷新绑定；绝不在没有指示的情况下把过期内容当作
  最新内容呈现。
- 关闭覆盖层把焦点和布局恢复到打开之前的状态。覆盖层不会在关闭时附带重排 pane 或改变选择。

## 确认

- 在销毁保留状态、结束进程或影响其他已附加 Client 的效果之前必须确认。确认用一句话指明后果
  及其范围。
- 确认键是一个精确的键；`Esc` 取消；默认结果是取消。不解释任何其他键，决定包按
  [`keyboard-input.md`](keyboard-input.md#编辑约定) 所述捕获。
- 可撤销效果、常规编辑或信息不使用确认。优先直接执行并给出通知。
- 在当前几何下无法绘制的确认以状态通知拒绝；效果不执行。

## 状态行

状态行是一行覆盖层，在存在输入归属者、有意义的通知、恢复信息或释放指针捕获等显式模式时显示。
普通透传态没有常驻状态行或提示。打开与关闭都不改变终端几何，关闭时恢复被覆盖的单元格。
显示期间位于其他覆盖层之上。其段从左到右为：

| 段         | 契约                                                             |
| ---------- | ---------------------------------------------------------------- |
| 输入指示器 | 已激活的前缀、当前模式、捕获类型或已释放的指针捕获；普通层下为空 |
| 上下文     | 当前位置，如 workspace 和 tab；宽度不足时先丢弃可选细节          |
| 通知       | 最近的瞬时或持久通知；显示期间替换上下文细节                     |
| 提示       | 当前所有者的按键提示，右对齐，按层级缩短或丢弃                   |

- 只要透传之外的任何所有者持有键盘，输入指示器就是必需的。它是最后被丢弃的段。
- 各段按 [`layout.md`](layout.md#尺寸层级) 中记录的顺序坍缩。绝不绘制残缺的段；要么丢弃，
  要么替换为其已记录的更短形式。
- 状态文本像每个外部字符串一样在绘制前净化。

## 通知

| 类型 | 生命周期                               | 呈现                           |
| ---- | -------------------------------------- | ------------------------------ |
| 瞬时 | 已记录的时长，然后由计划的重绘移除     | `text-secondary`               |
| 持久 | 直到下一个改变状态的按键事件或显式关闭 | 与其含义匹配的 `status-*` 角色 |

- 最多显示一条通知。较新的通知替换较旧的；持久错误不会被瞬时通知替换。
- 到期会计划一次重绘；通知绝不因界面空闲而滞留。
- 通知说明结果，以及在用户可以行动时说明执行动作的绑定。它绝不包含原始错误文本；失败映射为
  带稳定代码的本地化消息。
- 通知绝不阻塞输入，也绝不移动布局。

## 等待与进度

- 未在已记录的短延迟内完成的操作，在受影响区域或状态行显示等待指示器。在此延迟之前什么都不
  改变。
- 等待指示器是一个固定宽度的字形序列加一个本地化动词。它绝不阻塞其他区域的绘制或输入。
- 有截止时间的操作显示截止时间对完成的影响：成功、确定的失败，或带恢复绑定的未知结果。未知就
  呈现为未知，绝不呈现为成功或失败。
- 可以在后台继续的进度不打开覆盖层。

## 空状态

- 没有内容可显示的内容区域绘制一条本地化的原因说明，以及创建或加载内容的绑定。它绝不绘制无
  标签的空白区域。
- 空状态使用 `text-secondary`，绝不使用状态角色。

## 验证

| 变更       | 必需检查                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------- |
| 新增覆盖层 | 按 [`verification.md`](verification.md#渲染证据) 中每个必需几何渲染；页脚显示退出绑定；测试捕获类型 |
| 新增确认   | 测试证明只有精确键确认、`Esc` 取消，以及被拒绝几何路径不执行效果                                    |
| 状态段变更 | 测试覆盖每个层级，并证明输入指示器存活到最小层级                                                    |
| 通知变更   | 注入时间的测试证明到期会计划重绘，且持久错误不被替换                                                |
| 等待指示器 | 测试证明延迟之前什么都不绘制，且指示器在各帧间宽度恒定                                              |
