# TUI 覆盖层与状态

## 权威性和范围

本标准拥有 Orchbee 自有终端界面的表面选择、覆盖层组合、输入捕获、交互生命周期、确认、状态行、
提示、瞬时通知和异步结果呈现。几何遵循 [`layout.md`](layout.md#覆盖层)；颜色和层级遵循
[`visual-foundations.md`](visual-foundations.md)；按键归属遵循
[`keyboard-input.md`](keyboard-input.md#输入归属)；可复用覆盖层外壳和控件遵循
[`components.md`](components.md)。

这些规则是新增和实质性变更 TUI 行为的必需契约；写入本标准不代表每个现有 Client 已经符合。
运行时采用须由源码和 [`verification.md`](verification.md#契约评审) 要求的证据建立。分阶段缺口记录
负责人和完成条件。

[`frontend/dialogs-and-forms.md`](../frontend/dialogs-and-forms.md#中断预算) 中的中断预算原样
适用：从没有表面、没有问题开始，只询问结果所需的信息，绝不为后台状态抢夺焦点。

## 表面选择

| 表面         | 使用场景                                           | 禁止使用的场景                           |
| ------------ | -------------------------------------------------- | ---------------------------------------- |
| 状态通知     | 结果、状态变化或拒绝可以一行说清，且不需要回应     | 用户必须选择或输入                       |
| 状态行编辑器 | 一个短值在状态行中就地编辑                         | 值很长、多字段，或需要周围上下文才能判断 |
| 非捕获覆盖层 | 被动预览，同时输入继续到达 pane                    | 内容必须先处理，pane 才能继续            |
| 捕获覆盖层   | 选择、选择器、草稿或不得把按键送到 pane 的参考表面 | 一行状态或状态行编辑器已经足够           |
| 确认         | 一个简短决定先于不易撤销的效果                     | 效果可撤销，或表面只是报告信息           |

无论尺寸或名称，任何消费每个键的表面都是捕获型的。表面在打开期间绝不改变捕获类型。

## 覆盖层组合

覆盖层是一个带边框的区域，使用下列可复用槽位。必需槽位始终存在；可选槽位可省略，但不得改变
其余槽位的顺序，也不得在内容中临时重建它们。

上下文菜单改用紧凑组合：矩形边框、动作行及 owner 要求的原因行；省略标题、头部关闭控件、
页脚提示和位置计数。可见菜单继续独占输入；Esc 关闭根菜单，Left 或 Esc 返回父菜单，点击外部
通过准确准入的菜单表面关闭。子菜单继承根菜单的组合策略。下列通用模态槽位继续约束表单、
选择器、确认及全局动作发现界面。

| 槽位 | 要求 | 契约                                                                         |
| ---- | ---- | ---------------------------------------------------------------------------- |
| 头部 | 必需 | 一个本地化任务标题；可选的一行说明指明目标或后果                             |
| 导航 | 可选 | 同一任务内的返回路径、面包屑或 Tab                                           |
| 查询 | 可选 | 搜索或筛选编辑器；查询文本是草稿状态，不是已提交的领域值                     |
| 状态 | 可选 | 当前任务的校验、时效、等待、失败或恢复信息                                   |
| 内容 | 必需 | 列表、编辑器、提示、参考文本或进度；默认仅此槽位滚动                         |
| 动作 | 可选 | 当仅靠页脚绑定会产生歧义时显示的可选动作                                     |
| 页脚 | 必需 | 先显示退出或返回，再显示主绑定，然后最多两个次要绑定；决策按钮可承载这些提示 |

- 同一时刻只打开一个覆盖层。子任务在同一捕获所有者下替换外壳的任务槽位；绝不在第一个覆盖层
  之上打开第二个。
- 捕获型覆盖层可以通过既有动作所有者准入配置的全局前缀，用于关闭或切换表面。模态任务和确认
  保留优先归属；其他按键和粘贴仍归覆盖层所有，绝不到达其下方的 pane。
- 头部说明覆盖层关于什么，而不仅是动作名称。确认的头部指明受影响的对象。
- 非捕获覆盖层在页脚说明输入会到达 pane。
- 内容依赖远端状态的覆盖层显示内容的时效或刷新绑定；绝不在没有指示的情况下把过期内容当作
  最新内容呈现。
- 头部、导航、查询、状态、动作和页脚保持固定，内容独立滚动。如果固定槽位导致内容小于
  [`layout.md`](layout.md#覆盖层) 规定的最小尺寸，则拒绝新请求的覆盖层；已打开覆盖层进入暂停状态，
  不得隐藏返回或主控件。

### 内容层级

- 任务标题只绘制一次，使用标题文字，可放在头部内部或边框上。辅助目标上下文和说明使用次要
  文字；执行动作所需的值、精确决策目标和后果使用主要文字。不得将全部正文加粗或染成强调色。
- 正文和字段组对齐到声明的内容轨道。表单字段标签紧贴其边界上方；紧凑编辑器可以保留行内标签。
  字段帮助紧贴其下方。空间允许时，在头部、字段组和页脚之间留一空行；先缩减这些间距，
  再移除有用内容。字段的活动边界和
  光标持续可见，并独立于行导航或选择。
- 校验和恢复信息留在受影响的任务或字段旁。状态角色只着色字形或状态词，解释正文保持其阅读
  层级。不可用控件保留 text-disabled 角色和原因；错误或选择都不得把辅助元数据变成标题。
- 按可读的任务内容和完整的必需控件确定表面尺寸。可选帮助不得撑宽表单。在牺牲目标、字段、
  退出或主动作前，先按所属布局策略折行正文、缩短辅助上下文。无法使用的任务应被拒绝或暂停，
  不得绘制残缺的必需控件。
- 每个绑定在页脚中只显示一次。动作有按钮时，将格式化按键放入按钮共享的快捷键槽，省去重复
  的按键与动词提示。固定按钮行位于次要编辑或导航提示之后；提示只按完整记录舍弃。按钮标签
  保留主要、次要、破坏性或不可用角色，快捷键文字保持弱化。

## 生命周期与返回

- 打开覆盖层时记录调用区域和焦点身份。进入子任务时还要记录父级的焦点、选择、查询或筛选、
  视口锚点、草稿和可逆预览。只要存在该父级状态，就提供可见的返回动作；紧凑上下文菜单例外，
  仅使用 Left/Esc 返回绑定，不增加额外构件。
- 从子任务返回时恢复已记录的父级状态。关闭根覆盖层时，如果调用者仍然存在，则恢复到调用者；
  否则先聚焦同一区域中最近的存续项，再使用该区域已记录的默认焦点。两条路径都不得附带重排
  pane 或改变领域选择；已经越过提交边界的选择仍然保持已提交。
- `Esc` 执行由当前表面状态推导出的下一个局部返回步骤。该步骤可以是关闭已完成反馈、离开编辑、
  清除临时选择、还原预览、从子任务返回或关闭根表面；由表面模型决定当前步骤，而不是套用一套
  通用取消顺序。每一步都恢复该层进入时的状态。`Esc`、返回和关闭表面绝不取消正在运行的工作；
  取消运行中工作是一个独立且明确命名的领域动作。
- 关闭只丢弃当前层中尚未提交的 UI 状态。已经越过声明提交边界的即时设置或其他操作不会因此回滚。
  在已接受提交后隐藏或关闭表面，既不会撤销提交，也不会取消由它启动的工作。
- 替换或关闭表面时，先释放捕获，再恢复焦点。包含该决定的已解码输入包在结束前仍归原所有者，
  因而其尾随字节绝不到达新所有者。只有后续单独解码的输入事件才由新所有者解析，并且绝不传给
  已关闭的表面。
- 可见弹窗可以准入外侧蒙层关闭。其功能所有者可以不开放这一路径，以保留活动草稿、子任务、
  必需决定或待完成操作，同时保持显式关闭或返回路径。已准入的关闭复用精确的已绘制关闭动作，
  遵守当前捕获所有者，并消费完整手势和输入包尾部。正文留白与滚轮报告不会关闭，也不会穿透。
  已准入关闭的草稿和已接受工作遵循关闭动作原有策略。
  没有关闭控件的紧凑上下文菜单改用准确且成功绘制的表面、目标与 token 证明完成同一本地关闭，
  绝不构造不可见的 X 目标。
- 已打开表面在尺寸变化后放不下时进入暂停状态，不会被隐式关闭。保留其父级状态、草稿、必需决定、
  已接受提交、等待中的工作和恢复路径。“过小”状态只提供当前有效的返回、退出或恢复绑定，绝不
  接受不可见的提交或确认；几何恢复到足够尺寸后，继续使用同一表面实例。必需决定遵循所属操作的
  停放或拒绝关闭策略。

## 预览与提交

- 输入查询只改变可见结果集合。移动焦点或选择仅可在预览可逆时预览某项；两者都不会激活该项，
  也不会写入领域状态。
- 每个编辑器、选择器和设置通过其领域所有者声明提交边界。即时设置在自身控件上提交；原子性分阶段
  草稿提供一个按结果命名的主动作。不得因为使用覆盖层就推断存在全页“保存”动作。
- 只有当前校验通过后，激活才接受焦点选项并越过该表面声明的边界。由所有者决定这次接受是更新
  父级草稿还是提交领域状态。返回或 `Esc` 只恢复当前尚未接受的可逆预览。选项一旦被接受，后续
  返回或 `Esc` 会保留父级草稿或领域中的编辑，只关闭当前未提交层。
- 异步校验和预览结果绑定到产生它的精确目标与草稿修订。旧草稿的结果不得启用提交或替换当前反馈。

## 确认

- 在销毁保留状态、结束进程或影响其他已附加 Client 的效果之前必须确认。确认用一句话指明后果
  及其范围。
- 无修饰的 `Enter` 确认；`Esc` 取消；默认结果是取消。弱化的按键提示位于对应按钮方括号内，
  不再另设重复页脚行。不解释任何其他键，决定包按
  [`keyboard-input.md`](keyboard-input.md#编辑与草稿) 所述捕获。
- 可撤销效果、常规编辑或信息不使用确认。优先直接执行并给出通知。
- 请求确认时，如果当前几何无法绘制，则以状态通知拒绝，效果不执行。已经在等待决定的确认改为
  遵循暂停契约。

## 状态行

状态行是一行覆盖层，在存在输入归属者、有意义的通知、恢复信息或释放指针捕获等显式模式时显示。
普通透传态没有常驻状态行或提示。打开与关闭都不改变终端几何，关闭时恢复被覆盖的单元格。
显示期间位于其他覆盖层之上。其段从左到右为：

| 段         | 契约                                                             |
| ---------- | ---------------------------------------------------------------- |
| 输入指示器 | 已激活的前缀、当前模式、捕获类型或已释放的指针捕获；普通层下为空 |
| 上下文     | 当前位置，如 workspace 和 tab；宽度不足时先丢弃可选细节          |
| 通知       | 最近的瞬时或持久通知；显示期间替换上下文细节                     |
| 提示       | 当前所有者的按键提示，右对齐，按层级缩短或丢弃                   |

- 只要透传之外的任何所有者持有键盘，输入指示器就是必需的。它是最后被丢弃的段。
- 前缀模式下，首先显示当前生效的取消绑定，之后依次显示帮助、可用时的操作菜单、新建标签页、
  拆分、Agent 看板和分离操作的生效提示。宽度不足时按优先级整条丢弃后续提示。
- 各段按 [`layout.md`](layout.md#尺寸层级) 中记录的顺序坍缩。绝不绘制残缺的段；要么丢弃，
  要么替换为其已记录的更短形式。
- 状态文本像每个外部字符串一样在绘制前净化。

## 通知

| 类型 | 生命周期                               | 呈现                           |
| ---- | -------------------------------------- | ------------------------------ |
| 瞬时 | 已记录的时长，然后由计划的重绘移除     | `text-secondary`               |
| 持久 | 直到下一个改变状态的按键事件或显式关闭 | 与其含义匹配的 `status-*` 角色 |

- 最多显示一条通知。较新的通知替换较旧的；持久错误不会被瞬时通知替换。
- 到期会计划一次重绘；通知绝不因界面空闲而滞留。
- 通知说明结果，以及在用户可以行动时说明执行动作的绑定。它绝不包含原始错误文本；失败映射为
  带稳定代码的本地化消息。
- 通知绝不阻塞输入，也绝不移动布局。

## 等待、完成与注意力

- 已接纳的前台意图会在下一个可用帧中，于发起控件或预期位置显示本地接纳反馈。它不等待后台准备、
  完成或进度指示器的延迟。接纳投影不得虚构权威资源；仅凭接纳不能证明已经提交、就绪或成功。
- 未在已记录的短延迟内完成的操作，还会在受影响区域或状态行显示等待指示器。此延迟抑制不必要的
  进度动画，而不延迟接纳反馈。本地接纳、进度、首个有用内容和权威完成仍是各自独立的观察点。
- 等待指示器是一个固定宽度的字形序列加一个本地化动词。它绝不阻塞其他区域的绘制或输入。
- 表面请求携带表面实例、目标身份和请求代次。只有三者仍然匹配的完成结果才能改变选择、预览、
  等待状态或可见反馈。替换或关闭表面会使其呈现所有权失效，但不会取消领域工作。效果所有者仍可
  把结果结算到权威领域状态，但该完成结果不得重新打开表面，也不得改变替代它的新表面实例。
- 有截止时间的操作显示截止时间对完成的影响：成功、确定的失败，或带恢复绑定的未知结果。未知就
  呈现为未知，绝不呈现为成功或失败。
- 失败反馈放在受影响的任务或控件旁，保留可重试的非敏感草稿状态，并提供本地化恢复动作。原始
  错误不会成为产品文案。
- 注意力优先级依次为：当前正在向用户捕获的决定、当前任务的恢复、当前任务的其他状态，最后是
  后台或未读状态。低优先级反馈不得取代必需决定或持久失败。
- 可以在后台继续的进度与完成结果不会打开覆盖层、移动焦点或选择、替换当前草稿，也不会切换
  上下文。在用户导航过去之前，它们只更新所属区域或未读／状态指示。

## 空状态

- 没有内容可显示的内容区域绘制一条本地化的原因说明，以及创建或加载内容的绑定。它绝不绘制无
  标签的空白区域。
- 空状态使用 `text-secondary`，绝不使用状态角色。

## 验证

| 变更             | 必需检查                                                                                                                                              |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新增覆盖层       | 按 [`verification.md`](verification.md#渲染证据) 中每个必需几何渲染；固定槽位和页脚顺序保持可见；测试新建尺寸拒绝、已打开尺寸暂停与恢复，以及捕获类型 |
| 子任务或关闭流程 | 测试恢复焦点、选择、查询、视口锚点、草稿和预览；每次 `Esc` 只退出一层，且不影响运行中的工作                                                           |
| 预览或提交流程   | 测试区分焦点、尚未接受的可逆预览、校验、激活、即时提交、分阶段提交和取消；取消只还原当前尚未接受的预览，并保留已接受的父级草稿或领域值                |
| 新增确认         | 测试证明只有精确键确认、`Esc` 取消，以及被拒绝几何路径不执行效果                                                                                      |
| 状态段变更       | 测试覆盖每个层级，并证明输入指示器存活到最小层级                                                                                                      |
| 通知变更         | 注入时间的测试证明到期会计划重绘，且持久错误不被替换                                                                                                  |
| 异步操作         | 测试后台完成前的本地接纳、延迟进度、当前代次完成、过期结果拒绝、取消／所有权撤销、确定失败、未知结果恢复，以及后台完成不会获得焦点                    |
